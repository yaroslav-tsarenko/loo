# Levelup — дуелі персонажів (ескіз)

> Статус: **дизайн, не реалізовано.** Фундамент уже є: персонаж Loo (`src/game/character.ts`, `src/game/skills.ts`),
> еволюція (`src/game/ranks.ts`) і стабільний знімок `characterSnapshot(userId)` (`src/server/game/character.ts`).

## Ідея
Покрокова дуель двох персонажів, де кожен «удар» — це правильна відповідь на питання. Перемагає знання, а не гроші:
атрибути й навички лише трохи підсилюють, вирішальні — відповіді, перевірені сервером.

## Знімок персонажа (вхід дуелі)
`characterSnapshot(userId)` → `{ version, form, tier, step, title, attributes{intellect,speed,memory,craft,resilience,stamina}, skills[], power }`.
Ключі в сталому порядку, навички відсортовані (сила ↓, id ↑) — знімок можна зберегти в історії бою й порівнювати.
`power` = Σ рівнів атрибутів × (1 + крок еволюції / 21) + 10·√(Σ сили навичок) — для матчмейкінгу.

## Хід бою
1. **Матчмейкінг**: суперник з близьким рейтингом (Elo) і `power` ±20%; спільні курси — обовʼязково (питання тільки зі спільних тем).
2. **Арена**: 5 раундів × 1 питання; обидва бачать те саме питання, яке сервер вибрав зі спільних тем/рівнів.
3. **Навички як ходи**: перед раундом гравець може зіграти карту навички, якщо питання з її теми/розділу
   (напр. «Майстер замикань» на питання про замикання): ×1.5 урону, одна карта — один раз за бій.
4. **Модифікатори атрибутів** (невеликі, ≤ 15%):
   ⚡ Швидкість — бонус за відповідь швидше суперника; 🧠 Інтелект — шанс «критичного» удару за складні питання;
   💾 Памʼять — підказка-виключення одного варіанта раз на бій; 🔧 Майстерність — бонус на `order`/`fill`;
   🛡️ Стійкість — блокує частину урону за помилку; 🔥 Витривалість — +1 хід у нічийному фіналі.
5. **HP** = 100; удар = 20 × модифікатори; помилка — суперник не отримує урону, але ти втрачаєш темп (його бонус швидкості).

## Чесність
- Питання й вердикти — тільки з сервера (`answerQuiz`-подібна дія з контекстом бою): ключ не йде в клієнт, перша відповідь фіксується.
- Обидва гравці отримують ідентичні питання; таймер рахує сервер (час відповіді = серверні мітки, не клієнтські).
- Навички й атрибути беруться зі знімка на старті бою (не змінюються під час бою).
- Rate limit, анти-фарм: XP і 💎 за дуелі — з денним лімітом (як `XP_DAILY_CAP`), без бонусу за перемогу над тим самим суперником частіше ніж раз на добу.

## Рейтинг
Elo-подібний: старт 1000, K = 32 для перших 20 боїв, далі 16; очікування `E = 1 / (1 + 10^((Rb − Ra)/400))`.
Сезони = ліги (тижневі групи вже є); рейтинг дуелей окремий від тижневого XP.

## Дані (майбутня міграція)
`duels(id, a_user, b_user, a_snapshot jsonb, b_snapshot jsonb, questions jsonb, state, winner, created_at, finished_at)` —
спільна, лише сервер; `duel_moves(duel_id, user_id, round, answer jsonb, correct, ms, skill_id)`; `duel_ratings(user_id, rating, games)`.
Читання суперника — тільки знімок (display name + аватар + знімок), без доступу до його прогресу.
