# AI-перевірка письма й говоріння (IELTS) — план і кошторис

> **Статус: план, нічого не ввімкнено.** За рішенням власника платне вмикаємо лише після його підтвердження
> (docs/ROADMAP.md «Фінальний етап»). Ціни — публічний каталог Vercel AI Gateway
> (`https://ai-gateway.vercel.sh/v1/models`), знято 2026-10-17; перед запуском звірити ще раз.

## Що отримає учень

- **Writing Task 1 / Task 2 / GT-лист**: орієнтовний бал за чотирма критеріями IELTS (Task Achievement / Response,
  Coherence & Cohesion, Lexical Resource, Grammatical Range & Accuracy) + загальний, пояснення українською, 3–5
  конкретних правок «що підняти до наступного бала», переписаний фрагмент на бал вище, помилки → «Мої помилки».
- **Speaking Part 1–3**: транскрипт відповіді, бал за Fluency & Coherence, Lexical Resource, Grammar, Pronunciation
  (обережно — див. «Обмеження»), поради й зразкова відповідь на бал вище.
- Бал завжди «орієнтовно» з діапазоном (як CEFR → IELTS у курсі); офіційний бал ставить лише екзаменатор.

## Як це влаштовано (у межах нинішньої архітектури)

1. Сервер-екшн `checkWriting` / `checkSpeaking` (`src/server/actions/`), `requireUser` + `limitUser(user, 'ai')`;
   оцінювання **лише на сервері**, ключі не йдуть у клієнт (правило проєкту).
2. AI SDK через **Vercel AI Gateway** рядком `"anthropic/claude-sonnet-5.5"` (на Vercel — OIDC, локально
   `AI_GATEWAY_API_KEY` у `.env.local`; ключі інших проєктів не використовуємо). Відповідь — структурований
   обʼєкт (zod-схема: бали по критеріях, цитати з тексту, правки), промпт — публічні band descriptors своїми
   словами + рубрика; рубрика кешується (prompt caching), тож платимо переважно за текст учня й відгук.
3. Мовлення: браузер записує аудіо (MediaRecorder, opus) → сервер → транскрипція → оцінка. Аудіо **не
   зберігаємо** (обробили й викинули) — Supabase Storage не потрібен; зберігаємо лише транскрипт і бали.
4. Результат — у `attempts` (як відповіді на тести) + помилки в «Мої помилки»; ліміти й облік вартості — у
   `user_settings`/лічильнику на користувача.
5. Захист від зловживань: ліміт довжини (Task 2 ≤ 450 слів, Speaking ≤ 2.5 хв), ліміт перевірок на добу,
   ZDR-провайдери в Gateway, жодних персональних даних у промпті.

навіть при максимальному використанні.

## Обмеження (чесно)

- **Pronunciation** за транскриптом не оцінити: текст не містить вимови. Варіанти — аудіо-модель (gemini-3.5-transcribe,
  дорожче) або показувати Pronunciation як «не оцінено» й лишити `[!speak]` (безкоштовно, браузер) для тренування.
- Модель може помилятися на ±0.5–1 бала. Калібрування: 20–30 власних зразків із відомим балом (зразки Band 6–9 з
  курсу C1-20, C2-15), перевірка розкиду до запуску; бал показуємо діапазоном.
- Браузерне розпізнавання (нинішній безкоштовний `[!speak]`) лишається; платна транскрипція — лише для Speaking-оцінки.

## Етапи запуску (кожен — після підтвердження)

1. **Writing, лише для власника** (ліміт 3/добу, Sonnet 5.5): ≈ $1–2 / міс. Калібрування на зразках курсу.
2. **Speaking Part 2, лише для власника** (+ транскрипція): ще ≈ $0.5–1 / міс.
3. **Для всіх учнів** із денним лімітом і лічильником витрат; поріг-запобіжник у Gateway (бюджет на місяць).

**Потрібне рішення власника:** чи вмикати етап 1 (≈ $1–2 / міс при твоєму використанні), яку модель (рекомендую
Sonnet 5.5 для оцінки) і чи оцінювати Pronunciation аудіо-моделлю.
