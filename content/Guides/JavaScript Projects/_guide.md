# JavaScript: проєкти

Теорію ти знаєш з [[JavaScript - 01. Як JS виконує код|посібника «JavaScript: глибоке розуміння»]], руку набив на [[JavaScript Katas - 01. Рядки та масиви|катах]]. Тут — **проєкти**: кожен розділ будує один реальний міні-застосунок або бібліотеку від порожнього файлу до робочої версії, яку можна відкрити в браузері.

## 🧭 Як влаштований кожен розділ

1. **🎯 Що збудуємо** — мета й ASCII-схема архітектури: які модулі, хто кого викликає.
2. **🧭 План кроків** — 5–7 кроків і посилання на теорію, яку варто освіжити.
3. **🛠️ Кроки** — кожен крок є задачею з автотестами. **Заготовка кроку N = еталон кроку N−1 + каркас нового коду.** Тобто ти щоразу продовжуєш *свій* проєкт, а не починаєш з нуля. Застряг — візьми еталон попереднього кроку, він уже в заготовці.
4. **🎤 Як би ти масштабував…** — питання співбесіди про те, що буде, коли проєкт виросте в 100 разів.
5. **🧠 Закріплення** — картки про **дизайн-рішення**: чому саме так, а не інакше.
6. **🖥️ Зібрати в браузері** — повний HTML-файл: протестована логіка + тонкий шар DOM. Скопіюй у `index.html`, відкрий у браузері — і проєкт живий.

> [!tip] Чому логіка без DOM
> Тести запускаються у Web Worker — там немає `document`, `window` і мережі. Це не обмеження, а **архітектурний урок**: бізнес-логіка, яка не знає про DOM, тестується за мілісекунди, переноситься в Node, React чи React Native. DOM — лише тонкий «адаптер» наприкінці. Так само влаштовані Redux, TanStack Query, Preact Signals.

> [!important] Як проходити
> - Пиши код сам, навіть якщо криво. Червоний тест — це підказка, *що саме* ще не працює.
> - Підказки відкривай по одній. Еталон — після зелених тестів або чесного «здаюсь».
> - Після розділу збери браузерну версію: побачити свій код живим — найкраща нагорода.
