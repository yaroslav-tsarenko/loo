# Ваш перший компонент

## Вступ

*Компоненти* є одним з основних концептів React. Вони є фундаментом, на якому ви будуєте інтерфейси користувача (UI), що робить їх ідеальним місцем для початку вашої подорожі з React!

### Ви дізнаєтесь

* Що таке компонент
* Яку роль компоненти відіграють у додатку React
* Як написати свій перший компонент React

## Компоненти: будівельні блоки UI

У вебі HTML дозволяє створювати багаті структуровані документи з вбудованим набором тегів, таких як `<h1>` та `<li>`:

```html
<article>
  <h1>My First Component</h1>
  <ol>
    <li>Components: UI Building Blocks</li>
    <li>Defining a Component</li>
    <li>Using a Component</li>
  </ol>
</article>
```

Ця розмітка представляє статтю `<article>`, її заголовок `<h1>` та (скорочений) зміст як впорядкований список `<ol>`. Розмітка подібна до цієї, у поєднанні з CSS для стилю та JavaScript для інтерактивності, лежить за кожною бічною панеллю, аватаром, модальним вікном, випадаючим списком — за кожним елементом UI, який ви бачите у вебі.

React дозволяє об'єднувати вашу розмітку, CSS та JavaScript у користувацькі "компоненти", **багаторазово використовувані елементи UI для вашого додатку.** Код змісту, який ви бачили вище, можна перетворити на компонент `<TableOfContents />`, який можна рендерити на кожній сторінці. Під капотом він все ще використовує ті самі HTML-теги, такі як `<article>`, `<h1>` тощо.

Так само як і з HTML-тегами, ви можете компонувати, впорядковувати та вкладати компоненти для проектування цілих сторінок. Наприклад, сторінка документації, яку ви читаєте, складається з компонентів React:

```js
<PageLayout>
  <NavigationHeader>
    <SearchBar />
    <Link to="/docs">Docs</Link>
  </NavigationHeader>
  <Sidebar />
  <PageContent>
    <TableOfContents />
    <DocumentationText />
  </PageContent>
</PageLayout>
```

Із зростанням вашого проекту ви помітите, що багато ваших дизайнів можна створити, перевикористовуючи компоненти, які ви вже написали, прискорюючи розробку. Наш зміст вище можна додати на будь-який екран за допомогою `<TableOfContents />`! Ви навіть можете прискорити старт проекту з тисячами компонентів, що їх розповсюджує спільнота React з відкритим кодом, такими як [Chakra UI](https://chakra-ui.com/) та [Material UI](https://material-ui.com/).

## Визначення компонента

Традиційно при створенні вебсторінок розробники розмічали контент, а потім додавали інтерактивність, додаючи трохи JavaScript. Це чудово працювало, коли інтерактивність була приємним доповненням у вебі. Тепер вона очікується для багатьох сайтів і всіх додатків. React ставить інтерактивність на перше місце, використовуючи ту саму технологію: **компонент React — це функція JavaScript, яку ви можете _наповнити розміткою_.** Ось як це виглядає:

```js
export default function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/MK3eW3Am.jpg"
      alt="Katherine Johnson"
    />
  )
}
```

### Крок 1: Експорт компонента

Префікс `export default` — це [стандартний синтаксис JavaScript](https://developer.mozilla.org/docs/web/javascript/reference/statements/export) (не специфічний для React). Він дозволяє позначити головну функцію у файлі, щоб потім можна було імпортувати її з інших файлів.

### Крок 2: Визначення функції

За допомогою `function Profile() { }` ви визначаєте функцію JavaScript з іменем `Profile`.

> **Увага:** Компоненти React є звичайними функціями JavaScript, але **їхні імена повинні починатися з великої літери**, інакше вони не працюватимуть!

### Крок 3: Додавання розмітки

Компонент повертає тег `<img />` з атрибутами `src` та `alt`. `<img />` написаний як HTML, але насправді це JavaScript під капотом! Цей синтаксис називається JSX, і він дозволяє вбудовувати розмітку в JavaScript.

Оператори return можна писати в одному рядку, як у цьому компоненті:

```js
return <img src="https://react.dev/images/docs/scientists/MK3eW3As.jpg" alt="Katherine Johnson" />;
```

Але якщо ваша розмітка не вся на тому самому рядку, що й ключове слово `return`, ви повинні обгорнути її парою дужок:

```js
return (
  <div>
    <img src="https://react.dev/images/docs/scientists/MK3eW3As.jpg" alt="Katherine Johnson" />
  </div>
);
```

> **Увага:** Без дужок будь-який код на рядках після `return` [буде проігноровано](https://stackoverflow.com/questions/2846283/what-are-the-rules-for-javascripts-automatic-semicolon-insertion-asi)!

## Використання компонента

Тепер, коли ви визначили свій компонент `Profile`, ви можете вкласти його в інші компоненти. Наприклад, ви можете експортувати компонент `Gallery`, який використовує кілька компонентів `Profile`:

```js
function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/MK3eW3As.jpg"
      alt="Katherine Johnson"
    />
  );
}

export default function Gallery() {
  return (
    <section>
      <h1>Amazing scientists</h1>
      <Profile />
      <Profile />
      <Profile />
    </section>
  );
}
```

### Що бачить браузер

Зверніть увагу на різницю у регістрі:

* `<section>` написано малими літерами, тому React знає, що ми посилаємося на HTML-тег.
* `<Profile />` починається з великої `P`, тому React знає, що ми хочемо використати наш компонент під назвою `Profile`.

А `Profile` містить ще більше HTML: `<img />`. Зрештою, ось що бачить браузер:

```html
<section>
  <h1>Amazing scientists</h1>
  <img src="https://react.dev/images/docs/scientists/MK3eW3As.jpg" alt="Katherine Johnson" />
  <img src="https://react.dev/images/docs/scientists/MK3eW3As.jpg" alt="Katherine Johnson" />
  <img src="https://react.dev/images/docs/scientists/MK3eW3As.jpg" alt="Katherine Johnson" />
</section>
```

### Вкладення та організація компонентів

Компоненти є звичайними функціями JavaScript, тому ви можете тримати кілька компонентів в одному файлі. Це зручно, коли компоненти відносно маленькі або тісно пов'язані один з одним. Якщо цей файл стає переповненим, ви завжди можете перемістити `Profile` в окремий файл. Ви дізнаєтесь, як це зробити, незабаром на [[Importing and Exporting Components|сторінці про імпорти]].

Оскільки компоненти `Profile` рендеряться всередині `Gallery` — навіть кілька разів! — ми можемо сказати, що `Gallery` є **батьківським компонентом**, який рендерить кожен `Profile` як "дитину". Це частина магії React: ви можете визначити компонент один раз, а потім використовувати його в будь-яких місцях і будь-яку кількість разів.

> **Увага:** Компоненти можуть рендерити інші компоненти, але **ви ніколи не повинні вкладати їхні визначення:**
>
> ```js
> export default function Gallery() {
>   // 🔴 Ніколи не визначайте компонент всередині іншого компонента!
>   function Profile() {
>     // ...
>   }
>   // ...
> }
> ```
>
> Наведений вище фрагмент коду є [дуже повільним і спричиняє помилки](/learn/preserving-and-resetting-state#different-components-at-the-same-position-reset-state). Замість цього визначайте кожен компонент на верхньому рівні:
>
> ```js
> export default function Gallery() {
>   // ...
> }
>
> // ✅ Оголошуйте компоненти на верхньому рівні
> function Profile() {
>   // ...
> }
> ```
>
> Коли дочірньому компоненту потрібні деякі дані від батьківського, [передайте їх через props](/learn/passing-props-to-a-component) замість вкладення визначень.

## Компоненти до самого кінця

Ваш додаток React починається з "кореневого" компонента. Зазвичай він створюється автоматично, коли ви починаєте новий проект. Наприклад, якщо ви використовуєте [CodeSandbox](https://codesandbox.io/) або фреймворк [Next.js](https://nextjs.org/), кореневий компонент визначається у `pages/index.js`. У цих прикладах ви експортували кореневі компоненти.

Більшість додатків React використовують компоненти до самого кінця. Це означає, що ви використовуватимете компоненти не лише для багаторазово використовуваних елементів, як-от кнопки, але й для більших частин, як-от бічні панелі, списки та, зрештою, цілі сторінки! Компоненти — це зручний спосіб організації UI-коду та розмітки, навіть якщо деякі з них використовуються лише один раз.

Фреймворки на основі React йдуть ще далі. Замість використання порожнього HTML-файлу і дозволу React "перехопити" управління сторінкою за допомогою JavaScript, вони також автоматично генерують HTML з ваших компонентів React. Це дозволяє вашому додатку показувати певний контент до того, як JavaScript-код завантажиться.

Проте, багато вебсайтів використовують React лише для додавання інтерактивності до існуючих HTML-сторінок. Вони мають багато кореневих компонентів замість одного для всієї сторінки. Ви можете використовувати стільки React, скільки вам потрібно — або мало.

## Підсумок

Ви щойно отримали перше враження від React! Давайте підсумуємо деякі ключові моменти.

* React дозволяє створювати компоненти, **багаторазово використовувані елементи UI для вашого додатку.**
* У додатку React кожен елемент UI є компонентом.
* Компоненти React є звичайними функціями JavaScript, за винятком того, що:
  1. Їхні імена завжди починаються з великої літери.
  2. Вони повертають розмітку JSX.

## Завдання

### Завдання 1: Експортуйте компонент

Ця пісочниця не працює, тому що кореневий компонент не експортовано:

```js
function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/lICfvbD.jpg"
      alt="Aklilu Lemma"
    />
  );
}
```

**Рішення:** Додайте `export default` перед визначенням функції:

```js
export default function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/lICfvbD.jpg"
      alt="Aklilu Lemma"
    />
  );
}
```

Вам може бути цікаво, чому одного `export` недостатньо для виправлення цього прикладу. Ви можете дізнатися різницю між `export` та `export default` у [[Importing and Exporting Components|Імпорт та експорт компонентів]].

### Завдання 2: Виправте оператор return

Щось не так з цим оператором `return`. Чи можете ви це виправити?

```js
export default function Profile() {
  return
    <img src="https://react.dev/images/docs/scientists/jA8hHMpm.jpg" alt="Katsuko Saruhashi" />;
}
```

**Підказка:** Ви можете отримати помилку "Unexpected token" під час спроби виправити це. У такому випадку перевірте, що крапка з комою стоїть *після* закриваючої дужки. Залишення крапки з комою всередині `return ( )` спричинить помилку.

**Рішення:** Ви можете виправити цей компонент, перемістивши оператор return в один рядок:

```js
export default function Profile() {
  return <img src="https://react.dev/images/docs/scientists/jA8hHMpm.jpg" alt="Katsuko Saruhashi" />;
}
```

Або обгорнувши повернену JSX-розмітку в дужки, які відкриваються відразу після `return`:

```js
export default function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/jA8hHMpm.jpg"
      alt="Katsuko Saruhashi"
    />
  );
}
```

### Завдання 3: Знайдіть помилку

Щось не так з тим, як компонент `Profile` оголошено та використано. Чи можете ви помітити помилку? (Спробуйте згадати, як React відрізняє компоненти від звичайних HTML-тегів!)

```js
function profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/QIrZWGIs.jpg"
      alt="Alan L. Hart"
    />
  );
}

export default function Gallery() {
  return (
    <section>
      <h1>Amazing scientists</h1>
      <profile />
      <profile />
      <profile />
    </section>
  );
}
```

**Рішення:** Імена компонентів React повинні починатися з великої літери.

Змініть `function profile()` на `function Profile()`, а потім кожен `<profile />` на `<Profile />`:

```js
function Profile() {
  return (
    <img
      src="https://react.dev/images/docs/scientists/QIrZWGIs.jpg"
      alt="Alan L. Hart"
    />
  );
}

export default function Gallery() {
  return (
    <section>
      <h1>Amazing scientists</h1>
      <Profile />
      <Profile />
      <Profile />
    </section>
  );
}
```

### Завдання 4: Ваш власний компонент

Напишіть компонент з нуля. Ви можете дати йому будь-яке допустиме ім'я та повернути будь-яку розмітку. Якщо у вас немає ідей, ви можете написати компонент `Congratulations`, який показує `<h1>Good job!</h1>`. Не забудьте його експортувати!

**Рішення:**

```js
export default function Congratulations() {
  return (
    <h1>Good job!</h1>
  );
}
```
