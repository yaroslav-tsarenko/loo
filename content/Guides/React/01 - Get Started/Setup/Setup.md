# Налаштування

React інтегрується з інструментами, такими як редактори, TypeScript, розширення браузера та компілятори. Цей розділ допоможе вам налаштувати ваше середовище.

---

## Налаштування редактора

Дивіться наші [рекомендовані редактори](/learn/editor-setup) та дізнайтеся, як налаштувати їх для роботи з React.

---

## Використання TypeScript

TypeScript — це популярний спосіб додавання визначень типів до кодових баз JavaScript. [Дізнайтеся, як інтегрувати TypeScript у ваші проєкти React](/learn/typescript).

---

## React Developer Tools

React Developer Tools — це розширення браузера, яке може інспектувати компоненти React, редагувати props та state, та ідентифікувати проблеми продуктивності. Дізнайтеся, як встановити його [тут](/learn/react-developer-tools).

---

## React Compiler

React Compiler — це інструмент, який автоматично оптимізує ваш застосунок React. [Дізнайтеся більше](/learn/react-compiler).

---

## Наступні кроки

Перейдіть до гайду [Швидкий старт](/learn) для ознайомлення з найважливішими концепціями React, які ви будете використовувати щодня.
