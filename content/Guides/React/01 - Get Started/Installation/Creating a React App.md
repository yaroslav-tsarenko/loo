# Створення застосунку React

## Вступ

Якщо ви хочете створити новий застосунок або вебсайт з React, рекомендується почати з фреймворку.

Якщо ваш застосунок має обмеження, які погано обслуговуються існуючими фреймворками, ви віддаєте перевагу створенню власного фреймворку або просто хочете вивчити основи застосунку React, ви можете [створити застосунок React з нуля](/learn/build-a-react-app-from-scratch).

---

## Повноцінні фреймворки

Ці рекомендовані фреймворки підтримують усі функції, необхідні для розгортання та масштабування вашого застосунку у продакшені. Вони інтегрували найновіші функції React та використовують переваги архітектури React.

### Примітка: Повноцінні фреймворки не вимагають сервера

Усі фреймворки на цій сторінці підтримують:
- **Рендеринг на стороні клієнта (CSR)**
- **Односторінкові застосунки (SPA)**
- **Генерація статичних сайтів (SSG)**

Ці застосунки можна розгортати на CDN або сервісі статичного хостингу без сервера. Крім того, ці фреймворки дозволяють додавати серверний рендеринг на основі маршрутів, коли це має сенс для вашого випадку використання.

Це дозволяє почати з клієнтського застосунку, і якщо ваші потреби зміняться пізніше, ви можете підключити серверні функції на окремих маршрутах без переписування застосунку. Дивіться документацію вашого фреймворку для налаштування стратегії рендерингу.

### Next.js (App Router)

**[App Router Next.js](https://nextjs.org/docs) — це фреймворк React, який повною мірою використовує архітектуру React для створення повноцінних застосунків React.**

```bash
npx create-next-app@latest
```

Next.js підтримується [Vercel](https://vercel.com/). Ви можете [розгорнути застосунок Next.js](https://nextjs.org/docs/app/building-your-application/deploying) на будь-якому хостинг-провайдері, що підтримує Node.js або Docker-контейнери, або на власному сервері. Next.js також підтримує [статичний експорт](https://nextjs.org/docs/app/building-your-application/deploying/static-exports), який не вимагає сервера.

---

### React Router (v7)

**[React Router](https://reactrouter.com/start/framework/installation) — найпопулярніша бібліотека маршрутизації для React, яка може бути поєднана з Vite для створення повноцінного фреймворку React.** Він акцентує увагу на стандартних Web API та має кілька [готових до розгортання шаблонів](https://github.com/remix-run/react-router-templates) для різних JavaScript-середовищ та платформ.

Для створення нового проєкту з фреймворком React Router виконайте:

```bash
npx create-react-router@latest
```

React Router підтримується [Shopify](https://www.shopify.com).

---

### Expo (для нативних застосунків)

**[Expo](https://expo.dev/) — це фреймворк React, який дозволяє створювати універсальні застосунки для Android, iOS та вебу з по-справжньому нативним інтерфейсом.** Він надає SDK для [React Native](https://reactnative.dev/), що спрощує використання нативних частин.

Для створення нового проєкту Expo виконайте:

```bash
npx create-expo-app@latest
```

Якщо ви новачок у Expo, перегляньте [підручник Expo](https://docs.expo.dev/tutorial/introduction/).

Expo підтримується [Expo (компанією)](https://expo.dev/about). Створення застосунків з Expo безкоштовне, і ви можете подавати їх у Google та Apple магазини без обмежень. Expo додатково надає платні хмарні сервіси за бажанням.

## Інші фреймворки

Існують інші перспективні фреймворки, які працюють над реалізацією повноцінного бачення React:

- **[TanStack Start (Бета)](https://tanstack.com/start/):** TanStack Start — це повноцінний фреймворк React на базі TanStack Router. Він забезпечує повний SSR, стрімінг, серверні функції, бандлінг та інше за допомогою інструментів на кшталт Nitro та Vite.
- **[RedwoodSDK](https://rwsdk.com/):** Redwood — це повноцінний фреймворк React з багатьма попередньо встановленими пакетами та конфігурацією, що спрощує створення повноцінних веб-застосунків.

## Поглиблене вивчення: Бачення архітектури повноцінного стеку від команди React

### Які функції складають бачення архітектури повноцінного стеку від команди React?

Бандлер App Router Next.js повністю реалізує офіційну [специфікацію React Server Components](https://github.com/reactjs/rfcs/blob/main/text/0188-server-components.md). Це дозволяє змішувати компоненти часу збірки, серверні та інтерактивні компоненти в одному дереві React.

#### Приклад: Серверний компонент

```javascript
// Цей компонент виконується *лише* на сервері (або під час збірки).
async function Talks({ confId }) {
  // 1. Ви на сервері, тому можете звертатися до рівня даних. API-ендпоінт не потрібен.
  const talks = await db.Talks.findAll({ confId });

  // 2. Додайте будь-яку кількість логіки рендерингу. Це не збільшить ваш JavaScript-бандл.
  const videos = talks.map(talk => talk.video);

  // 3. Передайте дані вниз компонентам, які будуть виконуватися в браузері.
  return <SearchableVideoList videos={videos} />;
}
```

#### Інтеграція Server Components та Suspense

App Router Next.js також інтегрує [завантаження даних із Suspense](/blog/2022/03/29/react-v18#suspense-in-data-frameworks). Це дозволяє вказати стан завантаження (наприклад, скелетон-заповнювач) для різних частин інтерфейсу безпосередньо у вашому дереві React:

```javascript
<Suspense fallback={<TalksLoading />}>
  <Talks confId={conf.id} />
</Suspense>
```

**Важлива примітка:** Server Components та Suspense — це функції React, а не Next.js. Однак їх впровадження на рівні фреймворку вимагає значних зусиль з імплементації. На даний момент App Router Next.js — це найповніша реалізація. Команда React працює з розробниками бандлерів, щоб зробити ці функції простішими для впровадження в наступному поколінні фреймворків.

## Почніть з нуля

Якщо ваш застосунок має обмеження, які погано обслуговуються існуючими фреймворками, ви віддаєте перевагу створенню власного фреймворку або просто хочете вивчити основи застосунку React, є інші варіанти для початку проєкту React з нуля.

Початок з нуля дає більше гнучкості, але вимагає прийняття рішень щодо інструментів для маршрутизації, завантаження даних та інших поширених патернів використання. Це схоже на створення власного фреймворку замість використання існуючого. [Рекомендовані фреймворки](#повноцінні-фреймворки) мають вбудовані рішення для цих проблем.

Якщо ви хочете створити власні рішення, дивіться гайд [створення застосунку React з нуля](/learn/build-a-react-app-from-scratch) для інструкцій з налаштування нового проєкту React починаючи з інструменту збірки:

- [Vite](https://vite.dev/)
- [Parcel](https://parceljs.org/)
- [RSbuild](https://rsbuild.dev/)
