# React Compiler

## Вступ

Дізнайтеся, [що робить React Compiler](/learn/react-compiler/introduction) та як він автоматично оптимізує ваш застосунок React, обробляючи мемоїзацію за вас, усуваючи потребу в ручних `useMemo`, `useCallback` та `React.memo`.

---

## Встановлення

Почніть з [встановлення React Compiler](/learn/react-compiler/installation) та дізнайтеся, як налаштувати його з вашими інструментами збірки.

---

## Поступове впровадження

Дізнайтеся про [стратегії поступового впровадження React Compiler](/learn/react-compiler/incremental-adoption) у вашу існуючу кодову базу, якщо ви ще не готові увімкнути його скрізь.

---

## Налагодження та усунення неполадок

Коли щось працює не так, як очікувалося, використовуйте наш [гайд з налагодження](/learn/react-compiler/debugging), щоб зрозуміти різницю між помилками компілятора та проблемами під час виконання, ідентифікувати поширені проблемні патерни та дотримуватися систематичного робочого процесу налагодження.

---

## Підсумок

Ця сторінка документації надає огляд та навігаційний гайд для ресурсів React Compiler. Вона охоплює:

- **Основна функціональність**: Автоматична оптимізація мемоїзації, що усуває ручні `useMemo`, `useCallback` та `React.memo`
- **Ключові теми**: Встановлення, поступове впровадження, налагодження та конфігурація
- **Довідкові матеріали**: Опції конфігурації, директиви для контролю на рівні функцій та гайд з компіляції бібліотек
- **Ресурси спільноти**: Посилання на React Compiler Working Group для додаткових обговорень
