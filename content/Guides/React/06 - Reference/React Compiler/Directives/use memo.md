# "use memo"

## Вступ

`"use memo"` позначає функцію для оптимізації React Compiler.

> **Примітка:** У більшості випадків вам не потрібен `"use memo"`. Він переважно потрібен у режимі `annotation`, де ви повинні явно позначати функції для оптимізації. У режимі `infer` компілятор автоматично виявляє компоненти та хуки за їхніми патернами іменування (PascalCase для компонентів, префікс `use` для хуків). Якщо компонент або хук не компілюється в режимі `infer`, вам слід виправити його конвенцію іменування, а не примусово компілювати за допомогою `"use memo"`.

---

## Довідка

### `"use memo"`

Додайте `"use memo"` на початку функції, щоб позначити її для оптимізації React Compiler.

```js
function MyComponent() {
  "use memo";
  // ...
}
```

Коли функція містить `"use memo"`, React Compiler проаналізує та оптимізує її під час збірки. Компілятор автоматично мемоїзує значення та компоненти для запобігання непотрібних перерахунків та повторних рендерів.

#### Застереження

* `"use memo"` повинен бути на самому початку тіла функції, перед будь-якими імпортами або іншим кодом (коментарі допускаються)
* Директива повинна бути записана в подвійних або одинарних лапках, не у зворотних
* Директива повинна точно відповідати `"use memo"`
* Обробляється лише перша директива у функції; додаткові директиви ігноруються
* Ефект директиви залежить від вашого налаштування `compilationMode`

### Як `"use memo"` позначає функції для оптимізації

У React додатку, що використовує React Compiler, функції аналізуються під час збірки для визначення, чи можна їх оптимізувати. За замовчуванням компілятор автоматично виводить, які компоненти мемоїзувати, але це може залежати від вашого налаштування `compilationMode`.

`"use memo"` явно позначає функцію для оптимізації, перевизначаючи поведінку за замовчуванням:

* **У режимі `annotation`:** Оптимізуються лише функції з `"use memo"`
* **У режимі `infer`:** Компілятор використовує евристику, але `"use memo"` примусово вмикає оптимізацію
* **У режимі `all`:** Все оптимізується за замовчуванням, що робить `"use memo"` надлишковим

Директива створює чітку межу у вашій кодовій базі між оптимізованим та неоптимізованим кодом, надаючи вам тонкий контроль над процесом компіляції.

### Коли використовувати `"use memo"`

#### Ви використовуєте режим Annotation

У `compilationMode: 'annotation'` директива необхідна для кожної функції, яку ви хочете оптимізувати:

```js
// ✅ Цей компонент буде оптимізовано
function OptimizedList() {
  "use memo";
  // ...
}

// ❌ Цей компонент не буде оптимізовано
function SimpleWrapper() {
  // ...
}
```

#### Ви поступово впроваджуєте React Compiler

Почніть з режиму `annotation` та вибірково оптимізуйте стабільні компоненти:

```js
// Почніть з оптимізації leaf компонентів
function Button({ onClick, children }) {
  "use memo";
  // ...
}

// Поступово рухайтеся вгору по дереву, перевіряючи поведінку
function ButtonGroup({ buttons }) {
  "use memo";
  // ...
}
```

## Використання

### Робота з різними режимами компіляції

Поведінка `"use memo"` змінюється залежно від конфігурації компілятора:

```js
// babel.config.js
module.exports = {
  plugins: [
    ['babel-plugin-react-compiler', {
      compilationMode: 'annotation' // або 'infer' або 'all'
    }]
  ]
};
```

#### Режим Annotation

```js
// ✅ Оптимізовано за допомогою "use memo"
function ProductCard({ product }) {
  "use memo";
  // ...
}

// ❌ Не оптимізовано (без директиви)
function ProductList({ products }) {
  // ...
}
```

#### Режим Infer (за замовчуванням)

```js
// Автоматично мемоїзується, бо названо як компонент
function ComplexDashboard({ data }) {
  // ...
}

// Пропускається: не названо як компонент
function simpleDisplay({ text }) {
  // ...
}
```

У режимі `infer` компілятор автоматично виявляє компоненти та хуки за їхніми патернами іменування (PascalCase для компонентів, префікс `use` для хуків). Якщо компонент або хук не компілюється в режимі `infer`, вам слід виправити його конвенцію іменування, а не примусово компілювати за допомогою `"use memo"`.

## Усунення проблем

### Перевірка оптимізації

Щоб підтвердити, що ваш компонент оптимізується:

1. Перевірте скомпільований вивід у вашій збірці
2. Використовуйте React DevTools для перевірки наявності значка Memo ✨

### Дивіться також

* `"use no memo"` — відключення компіляції
* `compilationMode` — налаштування поведінки компіляції
* React Compiler — посібник із початку роботи
