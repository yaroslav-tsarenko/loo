# Директиви React Compiler

## Огляд

Директиви React Compiler — це спеціальні рядкові літерали, які контролюють, чи буде конкретна функція скомпільована. Вони забезпечують тонкий контроль над тим, які функції оптимізуються компілятором, і розміщуються на початку тіла функції або на початку модуля.

## Доступні директиви

* **`"use memo"`** — вмикає компіляцію функції
* **`"use no memo"`** — вимикає компіляцію функції

### Швидке порівняння

| Директива | Призначення | Коли використовувати |
|-----------|------------|---------------------|
| `"use memo"` | Примусова компіляція | При використанні режиму `annotation` або для перевизначення евристики режиму `infer` |
| `"use no memo"` | Запобігання компіляції | Налагодження проблем або робота з несумісним кодом |

## Використання

### Директиви на рівні функцій

Розміщуйте директиви на початку функції для контролю її компіляції:

```js
// Увімкнути компіляцію
function OptimizedComponent() {
  "use memo";
  return <div>This will be optimized</div>;
}

// Вимкнути компіляцію
function UnoptimizedComponent() {
  "use no memo";
  return <div>This won't be optimized</div>;
}
```

### Директиви на рівні модуля

Розміщуйте директиви на початку файлу для впливу на всі функції в цьому модулі:

```js
// На самому початку файлу
"use memo";

// Усі функції в цьому файлі будуть скомпільовані
function Component1() {
  return <div>Compiled</div>;
}

function Component2() {
  return <div>Also compiled</div>;
}

// Можна перевизначити на рівні функції
function Component3() {
  "use no memo"; // Це перевизначає директиву модуля
  return <div>Not compiled</div>;
}
```

### Взаємодія з режимами компіляції

Директиви поводяться по-різному залежно від вашого `compilationMode`:

* **Режим `annotation`**: Компілюються лише функції з `"use memo"`
* **Режим `infer`**: Компілятор сам вирішує, що компілювати, директиви перевизначають рішення
* **Режим `all`**: Все компілюється, `"use no memo"` може виключити конкретні функції

## Найкращі практики

### Використовуйте директиви помірно

Директиви — це запасні виходи. Краще налаштовувати компілятор на рівні проєкту:

```js
// ✅ Добре — конфігурація на рівні проєкту
{
  plugins: [
    ['babel-plugin-react-compiler', {
      compilationMode: 'infer'
    }]
  ]
}

// ⚠️ Використовуйте директиви лише за потреби
function SpecialCase() {
  "use no memo"; // Задокументуйте, чому це потрібно
  // ...
}
```

### Документуйте використання директив

Завжди пояснюйте, чому використовується директива:

```js
// ✅ Добре — зрозуміле пояснення
function DataGrid() {
  "use no memo"; // TODO: Видалити після виправлення проблеми з динамічною висотою рядків (JIRA-123)
  // Складна реалізація таблиці
}

// ❌ Погано — без пояснення
function Mystery() {
  "use no memo";
  // ...
}
```

### Плануйте видалення

Директиви відключення повинні бути тимчасовими:

1. Додайте директиву з коментарем TODO
2. Створіть тікет для відстеження
3. Виправте основну проблему
4. Видаліть директиву

```js
function TemporaryWorkaround() {
  "use no memo"; // TODO: Видалити після оновлення ThirdPartyLib до v2.0
  return <ThirdPartyComponent />;
}
```

## Типові патерни

### Поступове впровадження

При впровадженні React Compiler у великій кодовій базі:

```js
// Почніть з режиму annotation
{
  compilationMode: 'annotation'
}

// Увімкніть для стабільних компонентів
function StableComponent() {
  "use memo";
  // Добре протестований компонент
}

// Пізніше перейдіть на режим infer та вимкніть для проблемних
function ProblematicComponent() {
  "use no memo"; // Виправити проблеми перед видаленням
  // ...
}
```

## Усунення проблем

### Типові проблеми

1. **Директива ігнорується**: Перевірте розміщення (повинна бути першою) та правопис
2. **Компіляція все одно відбувається**: Перевірте налаштування `ignoreUseNoForget`
3. **Директива модуля не працює**: Переконайтеся, що вона стоїть перед усіма імпортами

Для конкретних проблем з директивами дивіться розділи усунення проблем у документації окремих директив.

## Дивіться також

* `compilationMode` — налаштування того, як компілятор обирає, що оптимізувати
* `Configuration` — повні параметри конфігурації компілятора
* Документація React Compiler — посібник із початку роботи
