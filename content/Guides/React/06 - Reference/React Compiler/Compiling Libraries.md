# Компіляція бібліотек

## Вступ

Цей посібник допомагає авторам бібліотек зрозуміти, як використовувати React Compiler для публікації оптимізованого коду бібліотеки для своїх користувачів.

## Навіщо публікувати скомпільований код?

Як автор бібліотеки, ви можете скомпілювати код бібліотеки перед публікацією в npm. Це надає декілька переваг:

- **Покращення продуктивності для всіх користувачів** — Користувачі вашої бібліотеки отримують оптимізований код, навіть якщо вони ще не використовують React Compiler
- **Не потребує конфігурації від користувачів** — Оптимізації працюють з коробки
- **Послідовна поведінка** — Усі користувачі отримують однакову оптимізовану версію незалежно від їх налаштування збірки

## Налаштування компіляції

Додайте React Compiler до процесу збірки вашої бібліотеки:

```bash
npm install -D babel-plugin-react-compiler@latest
```

Налаштуйте ваш інструмент збірки для компіляції бібліотеки. Наприклад, з Babel:

```js
// babel.config.js
module.exports = {
  plugins: [
    'babel-plugin-react-compiler',
  ],
  // ... інша конфігурація
};
```

## Зворотна сумісність

Якщо ваша бібліотека підтримує версії React нижче 19, вам потрібна додаткова конфігурація:

### 1. Встановіть runtime пакет

Рекомендується встановити react-compiler-runtime як пряму залежність:

```bash
npm install react-compiler-runtime@latest
```

```json
{
  "dependencies": {
    "react-compiler-runtime": "^1.0.0"
  },
  "peerDependencies": {
    "react": "^17.0.0 || ^18.0.0 || ^19.0.0"
  }
}
```

### 2. Налаштуйте цільову версію

Встановіть мінімальну версію React, яку підтримує ваша бібліотека:

```js
{
  target: '17', // Мінімальна підтримувана версія React
}
```

## Стратегія тестування

Тестуйте вашу бібліотеку як з компіляцією, так і без неї для забезпечення сумісності. Запускайте наявний набір тестів на скомпільованому коді, а також створіть окрему тестову конфігурацію, яка обходить компілятор. Це допомагає виявити будь-які проблеми, що можуть виникнути внаслідок процесу компіляції, та забезпечує коректну роботу вашої бібліотеки у всіх сценаріях.

## Усунення проблем

### Бібліотека не працює зі старішими версіями React

Якщо ваша скомпільована бібліотека видає помилки в React 17 або 18:

1. Перевірте, що ви встановили `react-compiler-runtime` як залежність
2. Переконайтеся, що конфігурація `target` відповідає вашій мінімальній підтримуваній версії React
3. Переконайтеся, що runtime пакет включено до вашого опублікованого бандлу

### Конфлікти компіляції з іншими плагінами Babel

Деякі плагіни Babel можуть конфліктувати з React Compiler:

1. Розмістіть `babel-plugin-react-compiler` на початку списку плагінів
2. Вимкніть конфліктуючі оптимізації в інших плагінах
3. Ретельно протестуйте вивід збірки

### Модуль runtime не знайдено

Якщо користувачі бачать "Cannot find module 'react-compiler-runtime'":

1. Переконайтеся, що runtime зазначено в `dependencies`, а не `devDependencies`
2. Перевірте, що ваш бандлер включає runtime у вивід
3. Переконайтеся, що пакет опубліковано в npm разом з вашою бібліотекою

## Наступні кроки

- Дізнайтеся про техніки налагодження скомпільованого коду
- Ознайомтеся з параметрами конфігурації для всіх опцій компілятора
- Дослідіть режими компіляції для вибіркової оптимізації
