# Конфігурація React Compiler

## Огляд

На цій сторінці перелічені всі параметри конфігурації, доступні в React Compiler. Для більшості додатків параметри за замовчуванням працюють без додаткового налаштування. Розширені параметри доступні для спеціальних потреб.

### Базове налаштування

```js
// babel.config.js
module.exports = {
  plugins: [
    [
      'babel-plugin-react-compiler', {
        // параметри компілятора
      }
    ]
  ]
};
```

---

## Керування компіляцією

Ці параметри контролюють, *що* компілятор оптимізує і *як* він обирає компоненти та хуки для компіляції.

**`compilationMode`** — контролює стратегію вибору функцій для компіляції (наприклад, усі функції, лише анотовані або інтелектуальне виявлення).

```js
{
  compilationMode: 'annotation' // Компілювати лише функції з "use memo"
}
```

---

## Сумісність версій

Конфігурація версії React забезпечує генерацію компілятором коду, сумісного з вашою версією React.

**`target`** — вказує, яку версію React ви використовуєте (17, 18 або 19).

```js
// Для проєктів на React 18
{
  target: '18' // Також потребує пакет react-compiler-runtime
}
```

---

## Обробка помилок

Ці параметри контролюють, як компілятор реагує на код, який не дотримується Rules of React.

**`panicThreshold`** — визначає, чи зупиняти збірку, чи пропускати проблемні компоненти.

```js
// Рекомендовано для продакшену
{
  panicThreshold: 'none' // Пропускати компоненти з помилками замість зупинки збірки
}
```

---

## Налагодження

Параметри логування та аналізу допомагають зрозуміти, що робить компілятор.

**`logger`** — забезпечує користувацьке логування подій компіляції.

```js
{
  logger: {
    logEvent(filename, event) {
      if (event.kind === 'CompileSuccess') {
        console.log('Compiled:', filename);
      }
    }
  }
}
```

---

## Feature Flags

Умовна компіляція дозволяє контролювати, коли використовується оптимізований код.

**`gating`** — вмикає runtime feature flags для A/B тестування або поступового розгортання.

```js
{
  gating: {
    source: 'my-feature-flags',
    importSpecifierName: 'isCompilerEnabled'
  }
}
```

## Типові шаблони конфігурації

### Конфігурація за замовчуванням

Для більшості додатків на React 19 компілятор працює без конфігурації:

```js
// babel.config.js
module.exports = {
  plugins: [
    'babel-plugin-react-compiler'
  ]
};
```

### Проєкти на React 17/18

Старіші версії React потребують пакет runtime та конфігурацію target:

```bash
npm install react-compiler-runtime@latest
```

```js
{
  target: '18' // або '17'
}
```

### Поступове впровадження

Почніть з конкретних директорій та поступово розширюйте:

```js
{
  compilationMode: 'annotation' // Компілювати лише функції з "use memo"
}
```
