# target

## Огляд

Параметр `target` вказує, для якої версії React компілятор повинен генерувати код.

```js
{
  target: '19' // або '18', '17'
}
```

---

## Довідка

### `target`

Налаштовує сумісність з версією React для скомпільованого виводу.

#### Тип

```
'17' | '18' | '19'
```

#### Значення за замовчуванням

`'19'`

#### Допустимі значення

- **`'19'`**: Цільова версія React 19 (за замовчуванням). Додатковий runtime не потрібен.
- **`'18'`**: Цільова версія React 18. Потребує пакет `react-compiler-runtime`.
- **`'17'`**: Цільова версія React 17. Потребує пакет `react-compiler-runtime`.

#### Застереження

- Завжди використовуйте рядкові значення, а не числа (наприклад, `'17'`, а не `17`)
- Не вказуйте патч-версії (наприклад, використовуйте `'18'`, а не `'18.2.0'`)
- React 19 включає вбудовані runtime API компілятора
- React 17 та 18 потребують встановлення `react-compiler-runtime@latest`

---

## Використання

### Цільова версія React 19 (за замовчуванням)

Для React 19 спеціальна конфігурація не потрібна:

```js
{
  // за замовчуванням target: '19'
}
```

Компілятор буде використовувати вбудовані runtime API React 19:

```js
// Скомпільований вивід використовує нативні API React 19
import { c as _c } from 'react/compiler-runtime';
```

### Цільова версія React 17 або 18

Для проєктів на React 17 та React 18 потрібні два кроки:

1. Встановіть runtime пакет:

```bash
npm install react-compiler-runtime@latest
```

2. Налаштуйте target:

```js
// Для React 18
{
  target: '18'
}

// Для React 17
{
  target: '17'
}
```

Компілятор буде використовувати polyfill runtime для обох версій:

```js
// Скомпільований вивід використовує polyfill
import { c as _c } from 'react-compiler-runtime';
```

## Усунення проблем

### Runtime помилки про відсутній compiler runtime

Якщо ви бачите помилки на кшталт "Cannot find module 'react/compiler-runtime'":

1. Перевірте вашу версію React:
   ```bash
   npm why react
   ```

2. Якщо використовуєте React 17 або 18, встановіть runtime:
   ```bash
   npm install react-compiler-runtime@latest
   ```

3. Переконайтеся, що target відповідає вашій версії React:
   ```js
   {
     target: '18' // Повинен відповідати вашій мажорній версії React
   }
   ```

### Runtime пакет не працює

Переконайтеся, що runtime пакет:

1. Встановлено у вашому проєкті (не глобально)
2. Зазначено у `package.json` dependencies
3. Правильної версії (тег `@latest`)
4. Не у `devDependencies` (він потрібен під час виконання)

### Перевірка скомпільованого виводу

Для перевірки правильного runtime зверніть увагу на різні шляхи імпорту:

```js
// Для React 19 (вбудований runtime)
import { c } from 'react/compiler-runtime'
//                      ^

// Для React 17/18 (polyfill runtime)
import { c } from 'react-compiler-runtime'
//                      ^
```
