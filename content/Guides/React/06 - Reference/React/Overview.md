## React DOM

React DOM містить можливості, які підтримуються лише для веб-застосунків (що працюють у середовищі DOM браузера). Цей розділ поділяється на:

- **[Хуки](/reference/react-dom/hooks)** — Хуки для веб-застосунків, які працюють у середовищі DOM браузера.
- **[Компоненти](/reference/react-dom/components)** — React підтримує всі вбудовані HTML та SVG компоненти браузера.
- **[API](/reference/react-dom)** — Пакет `react-dom` містить методи, які підтримуються лише у веб-застосунках.
- **[Клієнтські API](/reference/react-dom/client)** — API `react-dom/client` дозволяють рендерити компоненти React на клієнті (у браузері).
- **[Серверні API](/reference/react-dom/server)** — API `react-dom/server` дозволяють рендерити компоненти React у HTML на сервері.
- **[Статичні API](/reference/react-dom/static)** — API `react-dom/static` дозволяють генерувати статичний HTML для компонентів React.

## Правила React

React має ідіоми — або правила — для вираження шаблонів у спосіб, який легко зрозуміти та створює високоякісні застосунки:

- **[Компоненти та хуки мають бути чистими](/reference/rules/components-and-hooks-must-be-pure)** — Чистота робить ваш код легшим для розуміння, налагодження та дозволяє React автоматично оптимізувати ваші компоненти та хуки.
- **[React викликає компоненти та хуки](/reference/rules/react-calls-components-and-hooks)** — React відповідає за рендеринг компонентів та хуків, коли це необхідно для оптимізації користувацького досвіду.
- **[Правила хуків](/reference/rules/rules-of-hooks)** — Хуки визначаються за допомогою функцій JavaScript, але вони представляють особливий тип повторно використовуваної логіки UI з обмеженнями щодо місця їх виклику.
