# Вбудовані компоненти React

## Вступ

React надає кілька вбудованих компонентів, які ви можете використовувати у вашому JSX.

## Вбудовані компоненти

- **[`<Fragment>`](/reference/react/Fragment)** — Альтернативний запис `<>...</>`, дозволяє групувати кілька JSX-вузлів разом.

- **[`<Profiler>`](/reference/react/Profiler)** — Дозволяє програмно вимірювати продуктивність рендерингу дерева React.

- **[`<Suspense>`](/reference/react/Suspense)** — Дозволяє відображати запасний варіант (fallback), поки дочірні компоненти завантажуються.

- **[`<StrictMode>`](/reference/react/StrictMode)** — Вмикає додаткові перевірки лише для розробки, які допомагають знаходити помилки на ранньому етапі.

- **[`<Activity>`](/reference/react/Activity)** — Дозволяє приховувати та відновлювати UI та внутрішній стан дочірніх компонентів.

## Ваші власні компоненти
