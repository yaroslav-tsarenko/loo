# Директиви

## Огляд

Директиви — це інструкції для бандлерів, сумісних з React Server Components. Вони спеціально призначені для використання в межах React Server Components.

## Директиви вихідного коду

### `'use client'`
Позначає код, що виконується на клієнті. Ця директива дозволяє визначити клієнтський код у вашому додатку.

**Довідка:** `'use client'`

### `'use server'`
Позначає серверні функції, які можуть бути викликані з клієнтського коду. Це дозволяє визначити серверну логіку, доступну з клієнта.

**Довідка:** `'use server'`

---

## Контекст

- Директиви працюють з бандлерами, сумісними з React Server Components
- Вони спеціально призначені для використання в React Server Components

---

## Пов'язані ресурси

- React Server Components — огляд серверних компонентів
- `'use client'` — детальна документація директиви
- `'use server'` — детальна документація директиви
