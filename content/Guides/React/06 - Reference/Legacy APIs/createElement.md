# createElement

## Вступ

`createElement` дозволяє створити React елемент. Служить альтернативою написанню JSX.

```js
const element = createElement(type, props, ...children)
```

---

## Довідка

### `createElement(type, props, ...children)`

Викликайте `createElement` для створення React елемента з заданими `type`, `props` та `children`.

```js
import { createElement } from 'react';

function Greeting({ name }) {
  return createElement(
    'h1',
    { className: 'greeting' },
    'Hello'
  );
}
```

#### Параметри

* **`type`**: Аргумент `type` повинен бути валідним типом React компонента. Наприклад, це може бути рядок з ім'ям тегу (як-от `'div'` або `'span'`) або React компонент (функція, клас або спеціальний компонент, як `Fragment`).

* **`props`**: Аргумент `props` повинен бути об'єктом або `null`. Якщо передати `null`, він буде оброблений так само, як порожній об'єкт. React створить елемент з props, що відповідають переданим `props`. Зверніть увагу, що `ref` та `key` з вашого об'єкта `props` є спеціальними і *не* будуть доступні як `element.props.ref` та `element.props.key` на поверненому `element`. Вони будуть доступні як `element.ref` та `element.key`.

* **`...children`** (необов'язково): Нуль або більше дочірніх вузлів. Вони можуть бути будь-якими React вузлами, включаючи React елементи, рядки, числа, portals, порожні вузли (`null`, `undefined`, `true` та `false`) та масиви React вузлів.

#### Повертає

`createElement` повертає об'єкт React елемента з декількома властивостями:

* `type`: Переданий `type`.
* `props`: Передані `props`, за винятком `ref` та `key`.
* `ref`: Переданий `ref`. Якщо відсутній — `null`.
* `key`: Переданий `key`, приведений до рядка. Якщо відсутній — `null`.

Зазвичай ви повертаєте елемент зі свого компонента або робите його дочірнім елементом іншого елемента. Хоча ви можете читати властивості елемента, найкраще розглядати кожен елемент як непрозорий після створення та лише рендерити його.

#### Застереження

* Ви повинні **розглядати React елементи та їхні props як незмінні** та ніколи не змінювати їх вміст після створення. У development режимі React заморозить повернутий елемент та його властивість `props` поверхнево для забезпечення цього.

* При використанні JSX **ви повинні починати тег з великої літери для рендерингу свого компонента.** Іншими словами, `<Something />` еквівалентний `createElement(Something)`, але `<something />` (з малої літери) еквівалентний `createElement('something')` (зверніть увагу, що це рядок, тому він розглядатиметься як вбудований HTML тег).

* Ви повинні **передавати children як множинні аргументи лише якщо вони всі статично відомі,** як `createElement('h1', {}, child1, child2, child3)`. Якщо children динамічні, передайте весь масив як третій аргумент: `createElement('ul', {}, listItems)`. Це забезпечить, що React попередить вас про відсутні `key` для динамічних списків.

## Використання

### Створення елемента без JSX

Якщо вам не подобається JSX або ви не можете використовувати його у своєму проєкті, ви можете використати `createElement` як альтернативу.

Для створення елемента без JSX викликайте `createElement` з **type**, **props** та **children**:

```js
import { createElement } from 'react';

function Greeting({ name }) {
  return createElement(
    'h1',
    { className: 'greeting' },
    'Hello ',
    createElement('i', null, name),
    '. Welcome!'
  );
}
```

Children є необов'язковими, і ви можете передати стільки, скільки потрібно (приклад вище має три children). Цей код відобразить заголовок `<h1>` з привітанням. Для порівняння, ось той самий приклад, переписаний з JSX:

```js
function Greeting({ name }) {
  return (
    <h1 className="greeting">
      Hello <i>{name}</i>. Welcome!
    </h1>
  );
}
```

Для рендерингу власного React компонента передайте функцію, як `Greeting`, як type замість рядка, як `'h1'`:

```js
export default function App() {
  return createElement(Greeting, { name: 'Taylor' });
}
```

З JSX це виглядало б так:

```js
export default function App() {
  return <Greeting name="Taylor" />;
}
```

Обидва стилі написання коду прийнятні, тому ви можете використовувати той, який вам більше подобається. Основна перевага використання JSX порівняно з `createElement` полягає в тому, що легко бачити, який закриваючий тег відповідає якому відкриваючому тегу.

### Що таке React елемент?

Елемент — це легковагий опис частини користувацького інтерфейсу. Наприклад, і `<Greeting name="Taylor" />`, і `createElement(Greeting, { name: 'Taylor' })` створюють об'єкт на кшталт цього:

```js
// Дещо спрощено
{
  type: Greeting,
  props: {
    name: 'Taylor'
  },
  key: null,
  ref: null,
}
```

**Зверніть увагу, що створення цього об'єкта не рендерить компонент `Greeting` та не створює жодних DOM елементів.**

React елемент більше схожий на опис — інструкцію для React щодо подальшого рендерингу компонента `Greeting`. Повертаючи цей об'єкт з вашого компонента `App`, ви повідомляєте React, що робити далі.

Створення елементів є надзвичайно дешевим, тому вам не потрібно намагатися оптимізувати або уникати цього.
