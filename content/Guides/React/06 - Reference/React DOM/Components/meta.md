# `<meta>`

## Вступ

Вбудований браузерний компонент `<meta>` дозволяє додавати метадані до документа.

```js
<meta name="keywords" content="React, JavaScript, semantic markup, html" />
```

---

## Довідка

### `<meta>`

Для додавання метаданих документа рендеріть вбудований браузерний компонент `<meta>`. Ви можете рендерити `<meta>` з будь-якого компонента, і React завжди розмістить відповідний DOM-елемент у head документа.

```js
<meta name="keywords" content="React, JavaScript, semantic markup, html" />
```

#### Props

`<meta>` підтримує всі загальні props елементів.

Він повинен мати *рівно один* з наступних props: `name`, `httpEquiv`, `charset`, `itemProp`. Компонент `<meta>` виконує різні дії залежно від того, який з цих props вказано.

* **`name`**: рядок. Визначає тип метаданих для документа.
* **`charset`**: рядок. Визначає набір символів документа. Єдине допустиме значення — `"utf-8"`.
* **`httpEquiv`**: рядок. Визначає директиву для обробки документа.
* **`itemProp`**: рядок. Визначає метадані про конкретний елемент документа, а не про документ в цілому.
* **`content`**: рядок. Визначає метадані при використанні з props `name` або `itemProp`, або поведінку директиви при використанні з `httpEquiv`.

#### Спеціальна поведінка рендерингу

React завжди розміщує DOM-елемент, що відповідає компоненту `<meta>`, у `<head>` документа, незалежно від місця в дереві React. `<head>` — єдине допустиме місце для `<meta>` в DOM, але зручно, якщо компонент, що представляє конкретну сторінку, може сам рендерити компоненти `<meta>`.

**Виняток**: Якщо `<meta>` має prop `itemProp`, спеціальної поведінки немає, оскільки в цьому випадку він представляє метадані про конкретну частину сторінки, а не про документ.

## Використання

### Анотація документа метаданими

Ви можете анотувати документ метаданими, такими як ключові слова, короткий опис або ім'я автора. React розмістить ці метадані у `<head>` документа незалежно від місця в дереві React.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

export default function SiteMapPage() {
  return (
    <ShowRenderedHTML>
      <meta name="keywords" content="React" />
      <meta name="description" content="A site map for the React website" />
      <h1>Site Map</h1>
      <p>...</p>
    </ShowRenderedHTML>
  );
}
```

### Анотація конкретних елементів документа

Ви можете використовувати компонент `<meta>` з prop `itemProp` для анотації конкретних елементів документа метаданими. У цьому випадку React *не* розмістить ці анотації у `<head>`, а розмістить їх як будь-який інший React-компонент.

```js
<section itemScope>
  <h3>Annotating specific items</h3>
  <meta itemProp="description" content="API reference for using <meta> with itemProp" />
  <p>...</p>
</section>
```
