# `<progress>`

## Вступ

Вбудований браузерний компонент `<progress>` дозволяє рендерити індикатор прогресу.

```js
<progress value={0.5} />
```

---

## Довідка

### `<progress>`

Щоб відобразити індикатор прогресу, рендеріть вбудований браузерний компонент [`<progress>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/progress).

```js
<progress value={0.5} />
```

#### Props

`<progress>` підтримує всі загальні props елементів.

Додатково `<progress>` підтримує такі props:

- **`max`**: Число. Визначає максимальне значення `value`. За замовчуванням `1`.
- **`value`**: Число між `0` та `max`, або `null` для невизначеного прогресу. Визначає, скільки було зроблено.

---

## Використання

### Керування індикатором прогресу

Щоб відобразити індикатор прогресу, рендеріть компонент `<progress>`. Ви можете передати числове значення `value` між `0` та значенням `max`, яке ви вказуєте. Якщо ви не передаєте значення `max`, за замовчуванням воно буде `1`.

Якщо операція не виконується, передайте `value={null}`, щоб перевести індикатор прогресу в невизначений стан.

#### Приклад

```js
export default function App() {
  return (
    <>
      <progress value={0} />
      <progress value={0.5} />
      <progress value={0.7} />
      <progress value={75} max={100} />
      <progress value={1} />
      <progress value={null} />
    </>
  );
}
```

```css
progress { display: block; }
```
