# `<title>`

## Огляд

Вбудований браузерний компонент `<title>` дозволяє визначити заголовок документа.

```js
<title>My Blog</title>
```

---

## Довідка

### `<title>`

Для визначення заголовка документа рендеріть вбудований браузерний компонент `<title>`. Ви можете рендерити `<title>` з будь-якого компонента, і React завжди розмістить відповідний DOM-елемент у head документа.

```js
<title>My Blog</title>
```

#### Props

`<title>` підтримує всі загальні props елементів.

* **`children`**: `<title>` приймає лише текст як дочірній елемент. Цей текст стане заголовком документа. Ви також можете передавати власні компоненти, якщо вони рендерять лише текст.

#### Спеціальна поведінка рендерингу

React завжди розміщує DOM-елемент, що відповідає компоненту `<title>`, у `<head>` документа, незалежно від місця в дереві React. `<head>` — єдине допустиме місце для `<title>` в DOM, але зручно, якщо компонент, що представляє конкретну сторінку, може сам рендерити свій `<title>`.

**Винятки зі спеціальної поведінки:**
1. Якщо `<title>` знаходиться всередині компонента `<svg>` — спеціальної поведінки немає, оскільки в цьому контексті він є анотацією доступності для SVG-графіки, а не заголовком документа.
2. Якщо `<title>` має prop `itemProp` — спеціальної поведінки немає, оскільки він представляє метадані про конкретну частину сторінки.

**Підводний камінь:** Рендеріть лише один `<title>` одночасно. Якщо більше одного компонента рендерить тег `<title>` одночасно, React розмістить усі ці заголовки в head документа. У такому випадку поведінка браузерів та пошукових систем не визначена.

## Використання

### Встановлення заголовка документа

Рендеріть компонент `<title>` з будь-якого компонента з текстом як дочірнім елементом. React розмістить DOM-вузол `<title>` у `<head>` документа.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

export default function ContactUsPage() {
  return (
    <ShowRenderedHTML>
      <title>My Site: Contact Us</title>
      <h1>Contact Us</h1>
      <p>Email us at support@example.com</p>
    </ShowRenderedHTML>
  );
}
```

### Використання змінних у заголовку

Дочірній елемент `<title>` повинен бути одним рядком тексту (або одним числом, або одним об'єктом з методом `toString`).

**Проблема:** Використання фігурних дужок JSX створює масив з двох елементів як дочірній:

```js
<title>Results page {pageNumber}</title> // Проблема: не один рядок
```

**Рішення:** Використовуйте інтерполяцію рядків для передачі одного рядка `<title>`:

```js
<title>{`Results page ${pageNumber}`}</title>
```
