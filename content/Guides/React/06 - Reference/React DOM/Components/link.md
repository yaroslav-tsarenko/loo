# `<link>`

## Вступ

Вбудований браузерний компонент `<link>` дозволяє використовувати зовнішні ресурси, такі як таблиці стилів, або анотувати документ метаданими посилань.

```js
<link rel="icon" href="favicon.ico" />
```

---

## Довідка

### `<link>`

Для підключення зовнішніх ресурсів, таких як таблиці стилів, шрифти та іконки, або для анотування документа метаданими посилань, рендеріть вбудований браузерний компонент `<link>`. Ви можете рендерити `<link>` з будь-якого компонента, і React у більшості випадків розмістить відповідний DOM-елемент у `<head>` документа.

```js
<link rel="icon" href="favicon.ico" />
```

#### Props

`<link>` підтримує всі загальні props елементів.

**Основні props:**
* `rel`: рядок, обов'язковий. Визначає [зв'язок з ресурсом](https://developer.mozilla.org/en-US/docs/Web/HTML/Attributes/rel). React обробляє посилання з `rel="stylesheet"` інакше, ніж інші.

**Props при `rel="stylesheet"`:**
* `precedence`: рядок. Вказує React, де розмістити DOM-вузол `<link>` відносно інших у `<head>` документа. Таблиці стилів з однаковим пріоритетом групуються разом.
* `media`: рядок. Обмежує таблицю стилів певним media query.
* `title`: рядок. Визначає назву альтернативної таблиці стилів.

**Props, що вимикають спеціальну обробку (при `rel="stylesheet"`):**
* `disabled`: булеве значення. Вимикає таблицю стилів.
* `onError`: функція. Викликається при невдалому завантаженні.
* `onLoad`: функція. Викликається після завершення завантаження.

**Props при `rel="preload"` або `rel="modulepreload"`:**
* `as`: рядок. Тип ресурсу. Можливі значення: `audio`, `document`, `embed`, `fetch`, `font`, `image`, `object`, `script`, `style`, `track`, `video`, `worker`.
* `imageSrcSet`: рядок. Застосовується лише при `as="image"`.
* `imageSizes`: рядок. Застосовується лише при `as="image"`.

**Props при `rel="icon"` або `rel="apple-touch-icon"`:**
* `sizes`: рядок. Розміри іконки.

**Props у всіх випадках:**
* `href`: рядок. URL пов'язаного ресурсу.
* `crossOrigin`: рядок. Політика CORS. Можливі значення: `anonymous` та `use-credentials`.
* `referrerPolicy`: рядок. Заголовок Referrer для відправки при завантаженні.
* `fetchPriority`: рядок. Пріоритет завантаження. Можливі значення: `auto` (за замовчуванням), `high`, `low`.
* `hrefLang`: рядок. Мова пов'язаного ресурсу.
* `integrity`: рядок. Криптографічний хеш ресурсу для верифікації автентичності.
* `type`: рядок. MIME-тип пов'язаного ресурсу.

**Props, не рекомендовані для використання з React:**
* `blocking`: рядок. Якщо встановлено в `"render"`, інструктує браузер не рендерити сторінку до завантаження таблиці стилів. React надає більш точний контроль за допомогою Suspense.

#### Спеціальна поведінка рендерингу

React завжди розміщує DOM-елемент, що відповідає компоненту `<link>`, у `<head>` документа, незалежно від того, де в дереві React він рендериться.

**Винятки:**
* Якщо `<link>` має prop `rel="stylesheet"`, він також повинен мати prop `precedence` для цієї спеціальної поведінки.
* Якщо `<link>` має prop `itemProp` — спеціальної поведінки немає.
* Якщо `<link>` має prop `onLoad` або `onError` — ви керуєте завантаженням вручну.

#### Спеціальна поведінка для таблиць стилів

React обробляє посилання `rel="stylesheet"` особливо:

* Компонент, що рендерить `<link>`, буде призупинений (suspend) під час завантаження таблиці стилів.
* Якщо кілька компонентів рендерять посилання на ту саму таблицю стилів, React дедуплікує їх і розмістить лише один link у DOM. Два посилання вважаються однаковими, якщо мають однаковий prop `href`.

**Застереження:**
* React ігнорує зміни props після рендерингу посилання (попереджає в режимі розробки).
* React може залишити посилання в DOM навіть після розмонтування компонента.

## Використання

### Підключення пов'язаних ресурсів

Ви можете анотувати документ посиланнями на пов'язані ресурси, такі як іконка, канонічний URL або pingback. React розмістить ці метадані у `<head>` документа незалежно від того, де в дереві React вони рендеряться.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

export default function BlogPage() {
  return (
    <ShowRenderedHTML>
      <link rel="icon" href="favicon.ico" />
      <link rel="pingback" href="http://www.example.com/xmlrpc.php" />
      <h1>My Blog</h1>
      <p>...</p>
    </ShowRenderedHTML>
  );
}
```

### Підключення таблиці стилів

Якщо компонент залежить від певної таблиці стилів для коректного відображення, ви можете рендерити посилання на цю таблицю стилів всередині компонента. Ваш компонент буде призупинений під час завантаження. Ви повинні надати prop `precedence`.

**Примітка:** Коли ви хочете використати таблицю стилів, може бути корисним викликати функцію `preinit`. Це може дозволити браузеру почати завантаження раніше, наприклад, відправивши HTTP Early Hints response.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

export default function SiteMapPage() {
  return (
    <ShowRenderedHTML>
      <link rel="stylesheet" href="sitemap.css" precedence="medium" />
      <p>...</p>
    </ShowRenderedHTML>
  );
}
```

### Керування пріоритетом таблиць стилів

React дозволяє контролювати порядок таблиць стилів за допомогою prop `precedence`. Таблиці стилів з однаковим пріоритетом групуються в `<head>`. Значення пріоритету довільні — React вважає, що значення, виявлені першими, є "нижчими", а виявлені пізніше — "вищими".

### Дедупліковане рендерення таблиць стилів

Якщо ви рендерите ту саму таблицю стилів з кількох компонентів, React розмістить лише один `<link>` у head документа.

### Анотація конкретних елементів документа

Ви можете використовувати компонент `<link>` з prop `itemProp` для анотації конкретних елементів документа посиланнями на пов'язані ресурси. У цьому випадку React *не* розмістить ці анотації у `<head>`, а розмістить їх як будь-який інший React-компонент.

```js
<section itemScope>
  <h3>Annotating specific items</h3>
  <link itemProp="author" href="http://example.com/" />
  <p>...</p>
</section>
```
