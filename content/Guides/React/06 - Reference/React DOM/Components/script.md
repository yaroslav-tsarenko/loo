# `<script>`

## Вступ

Вбудований браузерний компонент `<script>` дозволяє додавати скрипт до документа.

```js
<script> alert("hi!") </script>
```

---

## Довідка

### `<script>`

Рендеріть вбудований браузерний компонент `<script>` для додавання inline або зовнішніх скриптів до документа. Ви можете рендерити `<script>` з будь-якого компонента, і React розмістить відповідний DOM-елемент у head документа та дедуплікує ідентичні скрипти в певних випадках.

```js
<script> alert("hi!") </script>
<script src="script.js" />
```

#### Props

`<script>` підтримує всі загальні props елементів.

Він повинен мати *або* `children`, *або* prop `src`:

* **`children`**: рядок. Вихідний код inline-скрипта.
* **`src`**: рядок. URL зовнішнього скрипта.

Інші підтримувані props:

* **`async`**: булеве значення. Дозволяє браузеру відкласти виконання скрипта — краща поведінка для продуктивності.
* **`crossOrigin`**: рядок. Політика CORS. Можливі значення: `anonymous` та `use-credentials`.
* **`fetchPriority`**: рядок. Пріоритет завантаження. Значення: `"high"`, `"low"` або `"auto"` (за замовчуванням).
* **`integrity`**: рядок. Криптографічний хеш скрипта для верифікації автентичності.
* **`noModule`**: булеве значення. Вимикає скрипт у браузерах, що підтримують ES modules — дозволяє використовувати fallback для старих браузерів.
* **`nonce`**: рядок. Криптографічний nonce для Content Security Policy.
* **`referrer`**: рядок. Заголовок Referer для відправки при завантаженні.
* **`type`**: рядок. Визначає тип скрипта: класичний, ES module або import map.

Props, що вимикають спеціальну обробку React:

* **`onError`**: функція. Викликається при невдалому завантаженні скрипта.
* **`onLoad`**: функція. Викликається після завершення завантаження.

Props, **не рекомендовані** для використання з React:

* **`blocking`**: рядок. React надає більш точний контроль за допомогою Suspense.
* **`defer`**: рядок. Не сумісний з потоковим серверним рендерингом. Використовуйте `async` замість цього.

#### Спеціальна поведінка рендерингу

React може переміщати компоненти `<script>` до `<head>` документа та дедуплікувати ідентичні скрипти.

Щоб активувати цю поведінку, надайте props `src` та `async={true}`. React дедуплікує скрипти з однаковим `src`. Prop `async` повинен бути true для безпечного переміщення скриптів.

**Застереження:**

* React ігнорує зміни props після рендерингу скрипта (попереджає в режимі розробки).
* React може залишити скрипт у DOM навіть після розмонтування компонента (це не впливає, оскільки скрипти виконуються лише один раз при вставці в DOM).

## Використання

### Рендеринг зовнішнього скрипта

Якщо компонент залежить від певних скриптів для коректного відображення, ви можете рендерити `<script>` всередині компонента. React дедуплікує скрипти з однаковим `src`.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

function Map({lat, long}) {
  return (
    <>
      <script async src="map-api.js" onLoad={() => console.log('script loaded')} />
      <div id="map" data-lat={lat} data-long={long} />
    </>
  );
}

export default function Page() {
  return (
    <ShowRenderedHTML>
      <Map />
    </ShowRenderedHTML>
  );
}
```

**Примітка:** Коли ви хочете використати скрипт, може бути корисним викликати функцію [`preinit`](/reference/react-dom/preinit). Це може дозволити браузеру почати завантаження раніше, наприклад, відправивши [HTTP Early Hints response](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status/103).

### Рендеринг inline-скрипта

Для включення inline-скрипта рендеріть компонент `<script>` з вихідним кодом як дочірнім елементом. Inline-скрипти не дедуплікуються та не переміщуються до `<head>` документа.

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';

function Tracking() {
  return (
    <script>
      ga('send', 'pageview');
    </script>
  );
}

export default function Page() {
  return (
    <ShowRenderedHTML>
      <h1>My Website</h1>
      <Tracking />
      <p>Welcome</p>
    </ShowRenderedHTML>
  );
}
```
