# `<style>`

## Вступ

Вбудований браузерний компонент `<style>` дозволяє додавати inline CSS-таблиці стилів до документа.

```js
<style>{` p { color: red; } `}</style>
```

---

## Довідка

### `<style>`

Для додавання inline-стилів до документа рендеріть вбудований браузерний компонент `<style>`. Ви можете рендерити `<style>` з будь-якого компонента, і React розмістить відповідний DOM-елемент у head документа та дедуплікує ідентичні стилі (у певних випадках).

```js
<style>{` p { color: red; } `}</style>
```

#### Props

`<style>` підтримує всі загальні props елементів, а також:

* **`children`** (рядок, обов'язковий): Вміст таблиці стилів.
* **`precedence`** (рядок): Вказує React, де розмістити DOM-вузол `<style>` відносно інших у `<head>` документа, що визначає, яка таблиця стилів може перевизначити іншу. React вважає, що значення пріоритету, виявлені першими, є "нижчими", а виявлені пізніше — "вищими". Таблиці стилів з однаковим пріоритетом групуються разом, незалежно від того, це теги `<link>` чи inline `<style>`, або завантажені функціями `preinit`.
* **`href`** (рядок): Дозволяє React дедуплікувати стилі з однаковим `href`.
* **`media`** (рядок): Обмежує таблицю стилів певним media query.
* **`nonce`** (рядок): Криптографічний nonce для Content Security Policy.
* **`title`** (рядок): Визначає назву альтернативної таблиці стилів.

**Props, не рекомендовані для використання з React:**

* **`blocking`** (рядок): React надає більш точний контроль за допомогою Suspense.

#### Спеціальна поведінка рендерингу

React може переміщати компоненти `<style>` до `<head>` документа, дедуплікувати ідентичні таблиці стилів та призупиняти виконання під час завантаження.

Щоб активувати цю поведінку, надайте props `href` та `precedence`. React дедуплікує стилі з однаковим `href`.

**Застереження:**

1. React ігнорує зміни props після рендерингу стилю (попереджає в режимі розробки)
2. React видалить усі зайві props при використанні prop `precedence` (окрім `href` та `precedence`)
3. React може залишити стиль у DOM навіть після розмонтування компонента

## Використання

### Рендеринг inline CSS-таблиці стилів

Якщо компонент залежить від певних CSS-стилів для коректного відображення, ви можете рендерити inline-таблицю стилів всередині компонента.

Prop `href` повинен унікально ідентифікувати таблицю стилів, оскільки React дедуплікує таблиці стилів з однаковим `href`. Якщо ви надаєте prop `precedence`, React переупорядкує inline-таблиці стилів на основі порядку цих значень у дереві компонентів.

Inline-таблиці стилів не активують Suspense boundaries під час завантаження, навіть якщо вони завантажують async-ресурси, такі як шрифти або зображення.

#### Приклад

```js
import ShowRenderedHTML from './ShowRenderedHTML.js';
import { useId } from 'react';

function PieChart({data, colors}) {
  const id = useId();
  const stylesheet = colors.map((color, index) =>
    `#${id} .color-${index}: \{ color: "${color}"; \}`
  ).join();
  return (
    <>
      <style href={"PieChart-" + JSON.stringify(colors)} precedence="medium">
        {stylesheet}
      </style>
      <svg id={id}>
        ...
      </svg>
    </>
  );
}

export default function App() {
  return (
    <ShowRenderedHTML>
      <PieChart data="..." colors={['red', 'green', 'blue']} />
    </ShowRenderedHTML>
  );
}
```
