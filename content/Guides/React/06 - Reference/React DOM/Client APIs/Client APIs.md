# Клієнтські React DOM APIs

## Вступ

API `react-dom/client` дозволяють рендерити React-компоненти на клієнті (у браузері). Ці API зазвичай використовуються на верхньому рівні вашого застосунку для ініціалізації React-дерева. Фреймворк може викликати їх за вас. Більшість компонентів не потребують їх імпорту чи використання.

## Клієнтські APIs

### Доступні методи

- **`createRoot`** — дозволяє створити root для відображення React-компонентів всередині браузерного DOM-вузла.
- **`hydrateRoot`** — дозволяє відобразити React-компоненти всередині браузерного DOM-вузла, HTML-вміст якого був попередньо згенерований `react-dom/server`.

## Підтримка браузерів

React підтримує всі популярні браузери, включаючи Internet Explorer 9 і вище. Для старих браузерів, таких як IE 9 та IE 10, потрібні деякі polyfills.
