# React DOM APIs

## Вступ

Пакет `react-dom` містить методи, які підтримуються лише для веб-застосунків (які працюють у середовищі браузерного DOM). Вони не підтримуються для React Native.

---

## APIs

Ці API можна імпортувати з ваших компонентів. Вони використовуються рідко:

* **`createPortal`** — дозволяє рендерити дочірні компоненти в іншій частині DOM-дерева.
* **`flushSync`** — дозволяє примусити React виконати оновлення стану та оновити DOM синхронно.

---

## APIs попереднього завантаження ресурсів

Ці API можна використовувати для прискорення застосунків шляхом попереднього завантаження ресурсів, таких як скрипти, таблиці стилів та шрифти, як тільки ви дізнаєтесь, що вони потрібні, наприклад, перед навігацією на іншу сторінку, де ці ресурси будуть використовуватись.

React-based фреймворки часто обробляють завантаження ресурсів автоматично, тому вам може не знадобитися викликати ці API самостійно. Зверніться до документації вашого фреймворку.

* **`prefetchDNS`** — дозволяє попередньо отримати IP-адресу DNS-домену, до якого ви плануєте підключитися.
* **`preconnect`** — дозволяє підключитися до сервера, з якого ви плануєте запитувати ресурси, навіть якщо ви ще не знаєте, які саме ресурси будуть потрібні.
* **`preload`** — дозволяє завантажити таблицю стилів, шрифт, зображення або зовнішній скрипт, які ви плануєте використовувати.
* **`preloadModule`** — дозволяє завантажити ESM-модуль, який ви плануєте використовувати.
* **`preinit`** — дозволяє завантажити та виконати зовнішній скрипт або завантажити та вставити таблицю стилів.
* **`preinitModule`** — дозволяє завантажити та виконати ESM-модуль.

---

## Точки входу

Пакет `react-dom` надає дві додаткові точки входу:

* **`react-dom/client`** — містить API для рендерингу React-компонентів на клієнті (у браузері).
* **`react-dom/server`** — містить API для рендерингу React-компонентів на сервері.

---

## Видалені API

Ці API були видалені в React 19:

* **`findDOMNode`** — дивіться альтернативи в документації React 18
* **`hydrate`** — використовуйте `hydrateRoot` замість цього
* **`render`** — використовуйте `createRoot` замість цього
* **`unmountComponentAtNode`** — використовуйте `root.unmount()` замість цього
* **`renderToNodeStream`** — використовуйте API `react-dom/server` замість цього
* **`renderToStaticNodeStream`** — використовуйте API `react-dom/server` замість цього
