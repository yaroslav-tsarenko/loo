# preconnect

## Огляд

`preconnect` дозволяє завчасно підключитися до сервера, з якого ви плануєте завантажувати ресурси.

```js
preconnect("https://example.com");
```

---

## Довідка

### `preconnect(href)`

Для попереднього підключення до хоста викличте функцію `preconnect` з `react-dom`.

```js
import { preconnect } from 'react-dom';

function AppRoot() {
  preconnect("https://example.com");
  // ...
}
```

Функція `preconnect` надає браузеру підказку, що він повинен відкрити з'єднання з вказаним сервером. Якщо браузер вирішить це зробити, це може прискорити завантаження ресурсів з цього сервера.

#### Параметри

* `href`: рядок. URL сервера, до якого ви хочете підключитися.

#### Повертає

`preconnect` не повертає нічого.

#### Застереження

* Кілька викликів `preconnect` з тим самим сервером мають такий самий ефект, як один виклик.
* У браузері ви можете викликати `preconnect` у будь-якій ситуації: під час рендерингу, в Effect, в обробнику подій тощо.
* При серверному рендерингу або рендерингу Server Components `preconnect` має ефект лише при виклику під час рендерингу компонента або в async-контексті, що походить від рендерингу. Інші виклики ігноруються.
* Якщо ви знаєте конкретні ресурси, які вам знадобляться, можете викликати [інші функції](/reference/react-dom/#resource-preloading-apis), які почнуть завантаження негайно.
* Немає переваги у попередньому підключенні до того ж сервера, де розміщена сама веб-сторінка, оскільки з'єднання вже встановлено.

## Використання

### Попереднє підключення при рендерингу

Викликайте `preconnect` при рендерингу компонента, якщо ви знаєте, що його дочірні елементи завантажуватимуть зовнішні ресурси з цього хоста.

```js
import { preconnect } from 'react-dom';

function AppRoot() {
  preconnect("https://example.com");
  return ...;
}
```

### Попереднє підключення в обробнику подій

Викликайте `preconnect` в обробнику подій перед переходом на сторінку або стан, де знадобляться зовнішні ресурси. Це починає процес раніше, ніж виклик під час рендерингу нової сторінки.

```js
import { preconnect } from 'react-dom';

function CallToAction() {
  const onClick = () => {
    preconnect('http://example.com');
    startWizard();
  }
  return (
    <button onClick={onClick}>Start Wizard</button>
  );
}
```
