# prefetchDNS

## Вступ

`prefetchDNS` дозволяє завчасно отримати IP-адресу сервера, з якого ви плануєте завантажувати ресурси.

```js
prefetchDNS("https://example.com");
```

---

## Довідка

### `prefetchDNS(href)`

Для пошуку хоста викличте функцію `prefetchDNS` з `react-dom`.

```js
import { prefetchDNS } from 'react-dom';

function AppRoot() {
  prefetchDNS("https://example.com");
  // ...
}
```

Функція `prefetchDNS` надає браузеру підказку, що він повинен знайти IP-адресу вказаного сервера. Якщо браузер вирішить це зробити, це може прискорити завантаження ресурсів з цього сервера.

#### Параметри

* `href`: рядок. URL сервера, до якого ви хочете підключитися.

#### Повертає

`prefetchDNS` не повертає нічого.

#### Застереження

* Кілька викликів `prefetchDNS` з тим самим сервером мають такий самий ефект, як один виклик.
* У браузері ви можете викликати `prefetchDNS` у будь-якій ситуації: під час рендерингу, в Effect, в обробнику подій тощо.
* При серверному рендерингу або рендерингу Server Components `prefetchDNS` має ефект лише при виклику під час рендерингу компонента або в async-контексті. Інші виклики ігноруються.
* Якщо ви знаєте конкретні ресурси, які вам знадобляться, можете викликати інші функції, які почнуть завантаження негайно.
* Немає переваги у попередньому DNS-запиті для того ж сервера, де розміщена сама сторінка.
* Порівняно з `preconnect`, `prefetchDNS` може бути кращим вибором при спекулятивному підключенні до великої кількості доменів, оскільки накладні витрати preconnection можуть перевищувати переваги.

## Використання

### Попередній DNS-запит при рендерингу

Викликайте `prefetchDNS` при рендерингу компонента, якщо ви знаєте, що його дочірні елементи завантажуватимуть зовнішні ресурси з цього хоста.

```js
import { prefetchDNS } from 'react-dom';

function AppRoot() {
  prefetchDNS("https://example.com");
  return ...;
}
```

### Попередній DNS-запит в обробнику подій

Викликайте `prefetchDNS` в обробнику подій перед переходом на сторінку або стан, де знадобляться зовнішні ресурси. Це починає процес раніше, ніж виклик під час рендерингу нової сторінки.

```js
import { prefetchDNS } from 'react-dom';

function CallToAction() {
  const onClick = () => {
    prefetchDNS('http://example.com');
    startWizard();
  }
  return (
    <button onClick={onClick}>Start Wizard</button>
  );
}
```
