# ESLint Plugin React Hooks

## Огляд

`eslint-plugin-react-hooks` надає ESLint правила для забезпечення дотримання Rules of React.

Цей плагін допомагає виявляти порушення правил React під час збірки, забезпечуючи, що ваші компоненти та хуки дотримуються правил React для коректності та продуктивності. Lint правила охоплюють як фундаментальні патерни React (exhaustive-deps та rules-of-hooks), так і проблеми, виявлені React Compiler. Діагностика React Compiler автоматично показується цим ESLint плагіном і може використовуватися, навіть якщо ваш додаток ще не впровадив компілятор.

## Важлива примітка щодо React Compiler

> Коли компілятор повідомляє про діагностику, це означає, що компілятор зміг статично виявити патерн, який не підтримується або порушує Rules of React. Коли він це виявляє, він **автоматично** пропускає ці компоненти та хуки, зберігаючи решту вашого додатку скомпільованою. Це забезпечує оптимальне покриття безпечними оптимізаціями, які не зламають ваш додаток.
>
> Що це означає для лінтінгу — вам не потрібно виправляти всі порушення одразу. Виправляйте їх у своєму темпі, щоб поступово збільшувати кількість оптимізованих компонентів.

## Рекомендовані правила

Ці правила включені до пресету `recommended` в `eslint-plugin-react-hooks`:

- **`exhaustive-deps`** — Валідує, що масиви залежностей для React хуків містять усі необхідні залежності
- **`rules-of-hooks`** — Валідує, що компоненти та хуки дотримуються Rules of Hooks
- **`component-hook-factories`** — Валідує функції вищого порядку, що визначають вкладені компоненти або хуки
- **`config`** — Валідує параметри конфігурації компілятора
- **`error-boundaries`** — Валідує використання Error Boundaries замість try/catch для помилок дочірніх елементів
- **`gating`** — Валідує конфігурацію режиму gating
- **`globals`** — Валідує проти присвоєння/мутації глобальних змінних під час render
- **`immutability`** — Валідує проти мутації props, state та інших незмінних значень
- **`incompatible-library`** — Валідує проти використання бібліотек, несумісних з мемоїзацією
- **`preserve-manual-memoization`** — Валідує, що існуюча ручна мемоїзація зберігається компілятором
- **`purity`** — Валідує, що компоненти/хуки є чистими, перевіряючи відомі нечисті функції
- **`refs`** — Валідує коректне використання refs, не читання/запис під час render
- **`set-state-in-effect`** — Валідує проти синхронного виклику setState в effect
- **`set-state-in-render`** — Валідує проти встановлення стану під час render
- **`static-components`** — Валідує, що компоненти є статичними, не перестворюються кожен render
- **`unsupported-syntax`** — Валідує проти синтаксису, який React Compiler не підтримує
- **`use-memo`** — Валідує використання хука `useMemo` без повернутого значення
