# Аудіювання — фільми й серіали

> [!success] Після цієї теми ти зможеш
> - розуміти діалоги в природному темпі: з еліпсисом (*You okay?*, *Got a minute?*), перебиваннями й накладанням реплік;
> - відрізняти сказане від того, що мають на увазі: сарказм, іронію, применшення (*understatement*), *deadpan*-гумор;
> - упізнавати 20 розмовних виразів із серіалів: *my bad, I'm in, bail on, it's on me, you bet*;
> - дивитися серіали з користю: «драбина субтитрів», активний перегляд, shadowing;
> - переносити ці навички в IELTS Listening (питання про ставлення мовця) і говорити про фільми в IELTS Speaking.

## Передбач

> [!quiz] Персонаж серіалу заглядає в кімнату й каже: «Got a minute?» Що це повністю?
> level: B2 · id: en-b2-listen-films-q01
> - [ ] I've got a minute.
> - [x] Have you got a minute?
> - [ ] Did you get my minute?
> - [ ] It's got a minute.
>
> **Пояснення:** у живому мовленні початок питання часто «відпадає» — це **еліпсис**: *(Have you) got a minute?* — «Маєш хвилинку?». Граматично все на місці, просто невимовлене зрозуміло з ситуації.

## Пояснення

### Чому фільми складніші за підручник

Аудіо до підручників і навіть IELTS записують актори, які говорять чітко й по черзі. У кіно й серіалах — інакше:

- **швидкість:** у живому діалозі 180–220 слів на хвилину, у комедіях — ще швидше;
- **накладання й перебивання:** персонажі говорять одночасно, обривають думку, закінчують речення одне за одного;
- **еліпсис:** *You okay?*, *Sounds good*, *Want some?* — без підмета чи допоміжного дієслова;
- **гумор і підтекст:** сарказм, іронія, применшення — слова кажуть одне, а мається на увазі інше;
- **розмовна лексика й редукції:** *gonna*, *my bad*, *bail on* ([[English - B2 - 12. Розмовні скорочення — gonna, wanna, gotta, dunno]]);
- **шум, музика, акценти** — і жодної можливості попросити повторити (хіба що перемотати).

Гарна новина: усе це **передбачувано**. Еліпсис має правила, сарказм — інтонацію, перебивання — сталі фрази.

### Перебивання й накладання

| Що робить персонаж | Фрази |
|---|---|
| перебиває ввічливо | *Sorry, can I just jump in?* · *Sorry to interrupt, but…* · *Can I just say something?* |
| перебиває різко | *Hang on, hang on.* · *Wait, wait, wait.* · *Whoa, back up.* |
| тримає слово | *Let me finish.* · *I'm not done.* · *Just — hear me out.* |
| закінчує чуже речення | *A: I think we should… — B: …move the launch? Totally.* |
| обриває думку | *I just thought maybe… never mind.* · *It's not that I… forget it.* |

Коли персонаж обриває речення (*I just thought maybe…*), **недомовлене — найважливіше**: глядач має здогадатися сам.

### Сарказм, іронія, применшення

> [!diagram] Що кажуть і що мають на увазі
> ```yaml
> layout: compare
> columns: { say: "персонаж каже", mean: "насправді означає" }
> nodes:
>   - { id: s1, col: say, text: "Oh, great. Just what I needed.", note: "після поганої новини, рівна інтонація", tone: gray }
>   - { id: m1, col: mean, text: "Жахливо, тільки цього бракувало.", note: "сарказм", tone: red }
>   - { id: s2, col: say, text: "It's a bit chilly.", note: "у квартирі видно пару з рота", tone: gray }
>   - { id: m2, col: mean, text: "Тут страшенно холодно.", note: "understatement — применшення", tone: blue }
>   - { id: s3, col: say, text: "Funny. Your car was gone all evening.", note: "детектив на допиті", tone: gray }
>   - { id: m3, col: mean, text: "Я тобі не вірю.", note: "іронія: funny = дивно, підозріло", tone: orange }
> steps:
>   - { show: [s1, m1], note: "Сарказм: позитивні слова + негативна ситуація + рівна або перебільшено радісна інтонація. Слова кажуть «чудово», ситуація — «жах»." }
>   - { show: [s2, m2], note: "Understatement — улюблений британський прийом: про катастрофу кажуть a bit, slightly, not ideal. Чим спокійніше слово, тим гірша ситуація." }
>   - { show: [s3, m3], note: "Funny тут не «смішно», а «дивно». Детектив не звинувачує прямо — він ставить факт поруч із брехнею." }
> ```

**Deadpan** — гумор із камʼяним обличчям: смішне кажуть цілком серйозно, без усмішки й без зміни тону. Якщо персонаж каже абсурдну річ рівним голосом — це жарт.

### Як дивитися серіали з користю

> [!diagram] Драбина субтитрів
> ```yaml
> layout: flow
> nodes:
>   - { id: ua, label: "крок 1", text: "Українські субтитри", note: "лише для дуже складного", tone: gray }
>   - { id: en, label: "крок 2", text: "Англійські субтитри", note: "зʼєднують звук і слово", tone: blue }
>   - { id: none, label: "крок 3", text: "Без субтитрів", note: "епізод, який уже бачив", tone: violet }
>   - { id: shadow, label: "крок 4", text: "Shadowing", note: "повторюй репліки за героями", tone: green }
> steps:
>   - { focus: ua, note: "Українські субтитри — це читання, а не аудіювання. Користуйся ними лише для дуже складних серіалів або щоб зрозуміти сюжет." }
>   - { focus: en, note: "Англійські субтитри — головний режим на B2: бачиш, як написане «зʼїдається» в мовленні. Пауза → перемотай → послухай ще раз." }
>   - { focus: none, note: "Без субтитрів — спершу епізод, який ти вже бачив з англійськими. Сюжет знаєш, тож увесь ресурс іде на слух." }
>   - { focus: shadow, note: "Shadowing: обери сцену на 1–2 хвилини, повторюй репліки слідом за актором з тією самою інтонацією. Так сарказм і ритм переходять у твоє мовлення." }
> ```

Ще кілька порад:

- **Обирай за жанром.** Ситкоми (короткі серії, побутова лексика, багато повторів) — найлегший старт. Процедурали (детективи, лікарські драми) мають сталі сюжети й фрази. Історичні драми, фентезі, кримінальні серіали з акцентами — складніші.
- **Метод «5 хвилин».** Одна сцена: подивись із субтитрами → без них → випиши 3–5 фраз → повтори вголос. Краще 5 хвилин щодня, ніж сезон за вихідні без уваги.
- **Нотуй не слова, а фрази:** *bail on someone*, *it's on me*, *I'm in* — так вони потрапляють у твоє мовлення готовими блоками.

### Що з цього для IELTS

- **Listening.** IELTS не дає уривків із фільмів, але Part 1 і Part 3 — живі розмови: самовиправлення, ухильні відповіді, заперечення через *well…*. Питання на зразок *What is the speaker's attitude…?* перевіряють те саме вміння, що й сарказм у серіалі: розуміти **ставлення**, а не лише слова.
- **Speaking.** Фільми й серіали — часта тема Part 1 і Part 2. Розмовні фрази з серіалів додають природності, але сленг і лайку на іспиті не вживай.

> [!example] IELTS Speaking Part 2 — картка
> **Describe a TV series you enjoyed watching.**
> You should say:
> - what it was about
> - when and how you watched it
> - why you liked it
>
> and explain what you learned from it.
>
> *Зразок початку (≈ band 6.5):* *I'd like to talk about a British comedy series I binge-watched last winter. It's set in a small office, and the humour is very deadpan — the characters say ridiculous things with a completely straight face. I watched it with English subtitles at first, which really helped, because they speak incredibly fast and talk over each other all the time…*

## Приклади

- *You okay? You look exhausted.* — У тебе все гаразд? Виглядаєш виснаженим. (*Are you okay?*)
- *Want some? — I'm good, thanks.* — Будеш? — Ні, дякую. (*I'm good* = «мені не треба»)
- *Oh, great. The printer's broken again.* — О, чудово. Принтер знову зламався. (сарказм)
- *Sorry, can I just jump in here?* — Перепрошую, можна я вклинюся?
- *Hang on, let me finish.* — Стривай, дай договорити.
- *Let me guess — you're bailing on me again.* — Дай вгадаю: ти знову мене кидаєш.
- *My bad, I totally forgot.* — Моя провина, я геть забув.
- *Dinner's on me tonight.* — Вечеря сьогодні за мій рахунок.
- *We're going bowling. You in? — You bet!* — Ми йдемо на боулінг. Ти з нами? — Ще б пак!
- *It's a bit awkward, isn't it?* — Якось незручно вийшло, правда?

## Слухаємо

Шість сцен, як у серіалі: квартира, офіс, допит, сімейна вечеря, телефонна розмова. Слухай не лише слова, а й **ставлення**: хто жартує, хто сердиться, хто бреше. Усі сцени й персонажі вигадані для курсу.

### Сцена 1. Ситком: сусіди по квартирі

> [!listen] Чому Сем такий утомлений?

## Типові помилки українців

> [!pitfall] Сприймати сарказм буквально
> *Oh, great. Just what I needed* — після поганої новини це не радість. *Big deal* з рівною інтонацією — не «велика справа», а «теж мені подія». Українці часто чекають сарказму в словах, а англійці ховають його в **інтонації й ситуації**. Питай себе: чи пасують слова до того, що сталося?

> [!pitfall] Вічні українські субтитри
> З українськими субтитрами ти **читаєш**, а англійська йде фоном — слух не тренується. І навпаки — одразу без субтитрів на складному серіалі: розумієш 30 % і кидаєш. Йди драбиною: англійські субтитри → без субтитрів на знайомому епізоді → shadowing.

> [!pitfall] Сленг із серіалу — у формальну розмову
> *My bad* керівнику, *Chill out* клієнту, лайка «бо в серіалі всі так кажуть» — звучить грубо або награно. Серіальні фрази чудові з друзями; на співбесіді, в листі й на IELTS обирай нейтральне: *I'm sorry, that was my mistake*, *Don't worry*.

> [!pitfall] Чекати «правильної» граматики
> *You okay? Want some? Been there.* — учні думають, що це помилки, або не розпізнають питання. Це нормальний еліпсис живої мови. Розгортай подумки: *(Are) you okay? (Do you) want some? (I've) been there.* Сам у формальному мовленні вживай повні форми.

> [!quiz] Які репліки — природний розмовний еліпсис? Обери всі.

> - [ ] Me want go.

> **Пояснення:** еліпсис прибирає **початок** речення, коли він очевидний: *(Do you want) coffee?*, *(I've) been there*. *Is good* — так не кажуть: *It's good* скорочують до простого *Good*; а *Me want go* — граматично зламана фраза.

> - [ ] Я не купуватиму цю книжку.
>
> **Пояснення:** *buy a story* — повірити історії. *Not for a second* — «ані на мить».

> [!quiz] Які фрази допомагають перебити або втримати слово? Обери всі.
> level: B2 · type: multi · id: en-b2-listen-films-q11
> - [x] Hang on, let me finish.
> - [x] Sorry to interrupt, but…
> - [x] Can I just say something?
> - [x] Hear me out.
> - [ ] Nice to meet you.
> - [ ] You bet!
>
> **Пояснення:** *Sorry to interrupt / Can I just say…* — перебити; *Let me finish / Hear me out* — втримати слово. *You bet* — «ще б пак», реакція.

> [!quiz] Що таке deadpan-гумор?
> level: B2 · id: en-b2-listen-films-q12
> - [ ] гумор про смерть
> - [x] жарт, сказаний цілком серйозно, з камʼяним обличчям
> - [ ] гучний фізичний гумор
> - [ ] сміх за кадром
>
> **Пояснення:** *deadpan* — без тіні усмішки й без зміни тону. Тому його легко сприйняти буквально: стеж за абсурдністю змісту.

> [!quiz] IELTS Listening Part 3. Студентка про статтю: «Well, it was… interesting. Not really my thing, but interesting.» Яке в неї ставлення?
> level: B2 · id: en-b2-listen-films-q13
> - [ ] у захваті від статті
> - [x] стаття їй не дуже сподобалась, але вона висловлюється ввічливо
> - [ ] вона її не читала
> - [ ] вона вважає статтю найкращою в курсі
>
> **Пояснення:** пауза, *well* і *not really my thing* — ознаки стриманої, ввічливої незгоди. Питання IELTS про *attitude* перевіряють саме це: не слова (*interesting*), а ставлення.

> [!quiz] Склади репліку «Дай вгадаю: ти знову мене кидаєш».
> level: B2 · type: order · id: en-b2-listen-films-q14
>
> ```text order
> Let me guess,
> you're
> bailing
> on
> me
> again.
> ```
>
> **Пояснення:** *bail on someone* — кинути, не прийти. *Let me guess* — іронічний вступ: «я так і знав».

> [!quiz] «Funny. Your car was gone all evening», — каже детективка. Що означає funny?
> level: B2 · id: en-b2-listen-films-q15
> - [ ] смішно
> - [x] дивно, підозріло
> - [ ] весело
> - [ ] цікаво для преси
>
> **Пояснення:** *funny* має два значення: «смішний» і «дивний». *That's funny…* у детективі — сигнал підозри: факти не сходяться.

> [!quiz] «What's up with Tom? He's been quiet all day.» Що питає мовець?
> level: B2 · id: en-b2-listen-films-q16
> - [ ] Куди пішов Том?
> - [x] Що з Томом таке?
> - [ ] Чи прокинувся Том?
> - [ ] Чому Том нагорі?
>
> **Пояснення:** *What's up with someone?* — «що з ним?», коли людина поводиться незвично. *What's up?* без *with* — «як справи?».

## Фішки

> [!reel] 😂 Сміх за кадром — це винахід
> На початку 1950-х звукоінженер Чарлі Дуглас створив «Laff Box» — пристрій із записами сміху. Відтоді закадровий сміх підказує глядачам ситкомів, де жарт. Він і тобі допоможе: сміх = тут був гумор, перемотай і зрозумій.

> [!reel] 🧗 Чому кінцівка серії — «cliffhanger»
> Слово повʼязують із романом Томаса Гарді *A Pair of Blue Eyes* (1873), який виходив частинами: один розділ закінчується тим, що герой висить на краю скелі. Читачі мусили чекати наступного номера — як ми чекаємо нової серії.

> [!reel] ⏱️ 200 мілісекунд на відповідь
> Дослідження розмов десятьма мовами (2009) показало: між репліками людей минає в середньому близько 0,2 секунди. Ми плануємо відповідь, ще слухаючи співрозмовника, — тому в кіно репліки накладаються.

> [!important] Підсумок
> - Живий діалог: швидкий темп, накладання, перебивання й еліпсис (*You okay? Got a minute? Sounds good*).
> - Підтекст: сарказм (позитивні слова + погана ситуація), understatement (*a bit chilly*), іронія (*Funny…*), deadpan.
> - Перебивання й утримання слова: *Can I just jump in? · Hang on, let me finish.*
> - Дивись драбиною: англійські субтитри → без субтитрів → shadowing; записуй фрази, а не окремі слова.
> - IELTS: питання про ставлення мовця перевіряють те саме вміння; серіальний сленг — не для іспиту.
