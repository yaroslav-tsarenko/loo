# Аудіювання — інтервʼю й розмови носіїв

> [!success] Після цієї теми ти зможеш
> - розуміти інтервʼю: головну думку, факти й ставлення мовця;
> - стежити за розмовою 2–3 людей, коли вони перебивають одне одного, недоговорюють і змінюють думку;
> - відрізняти факт від думки й чути згоду, сумнів, незгоду й сарказм;
> - не губитися через «сміття» живого мовлення: *well, you know, I mean, kind of*;
> - робити короткі нотатки й виконувати завдання IELTS Listening Part 3: вибір, нотатки, matching.

## Передбач

> [!quiz] Ти питаєш друга: «Did you like the film?» Він відповідає: «Well… the actors were good». Що він, найімовірніше, думає?
> level: B1 · id: en-b1-listen-interviews-q01
> - [ ] фільм йому дуже сподобався
> - [x] фільм загалом не сподобався, але він не хоче казати прямо
> - [ ] він не дивився фільм
> - [ ] йому сподобалися лише актори, і це головне
>
> **Пояснення:** протяжне *Well…* на початку відповіді часто сигналізує «не зовсім так, як ти думаєш». А похвала лише одній деталі — ввічлива форма незгоди. У живій розмові важливі не лише слова, а й *як* їх сказано.

## Пояснення

### Чим жива розмова відрізняється від новин

Новини читають за текстом, а інтервʼю й розмови — **спонтанні**. Тому в них є речі, яких немає в підручнику:

| Явище | Приклад | Що робити |
|---|---|---|
| слова-паузи (*fillers*) | *well, um, you know, I mean, like, kind of* | ігнорувати — змісту в них немає |
| фальстарти й самовиправлення | *We went on — sorry, we left on Friday.* | чекати остаточного варіанта |
| пропуск слів (*ellipsis*) | *Coming?* = *Are you coming?* · *Got a minute?* | добудовувати за контекстом |
| реакції слухача | *Mm-hm. · Right. · Really? · No way!* | це «я тебе слухаю», а не відповідь |
| перебивання й накладання | *— So I think… — Sorry, can I just say…* | стежити, хто говорить і чи погоджується |

### Факт чи думка

У Part 3 IELTS і в інтервʼю часто питають не «що сталося», а **що мовець думає**. Думку видають сигнальні слова:

- **думка:** *I reckon…*, *I'd say…*, *Personally,…*, *If you ask me,…*, *To be honest,…*, *On the whole,…* (загалом);
- **з чужих слів:** *Apparently,…* (кажуть, начебто), *According to…*, *I heard that…*;
- **сумнів:** *I'm not sure about that.*, *I doubt it.*, *Maybe, but…*;
- **згода:** *Exactly.*, *That's a fair point.*, *I'm with Sara on this.* (я на боці Сари);
- **незгода (ввічлива):** *I see what you mean, but…*, *I take your point, but…*, *Well…*.

> [!important] Справжня думка — після «but»
> *It's a nice idea, **but** it's too expensive.* Перша частина — ввічливість, друга — позиція. В IELTS дистрактори часто стоять **до** *but*, а правильна відповідь — **після**. Те саме з *actually*: *It's not the phone, **actually**. It's…* — далі піде виправлення.

### Що кажуть і що мають на увазі

Британці часто говорять **стримано** (*understatement*) або з іронією. Інтонація підказує більше, ніж слова.

> [!diagram] Що кажуть — і що мають на увазі
> ```yaml

> columns: { said: "кажуть", meant: "мають на увазі" }
> nodes:

>   - { id: m1, col: meant, text: "Фільм мені загалом не сподобався.", tone: orange }
>   - { id: s2, col: said, text: "That's an interesting idea…", tone: gray }
>   - { id: m2, col: meant, text: "Я сумніваюся. Мабуть, ні.", tone: orange }
>   - { id: s3, col: said, text: "Not bad at all!", tone: gray }
>   - { id: m3, col: meant, text: "Дуже добре!", tone: green }
>   - { id: s4, col: said, text: "Oh, brilliant. The train's late again.", tone: gray }
>   - { id: m4, col: meant, text: "Сарказм: це жахливо.", tone: red }

>   - { show: [s2, m2], note: "Interesting з паузою після нього — часто ввічливе «ні». Слухай, що буде далі: зазвичай іде but." }

> ```

### Нотатки: швидко й коротко

Записуй лише **змістові слова** й цифри, решту — символами:

| Символ | Значення | Приклад |
|---|---|---|
| → | веде до, призводить | *no bike lanes → few cyclists* |
| ↑ / ↓ | зростає / падає | *prices ↑ 10%* |
| = / ≠ | те саме / не те саме | *online survey ≠ all ages* |
| + / – | плюс, перевага / мінус | *+ quick, – only young people* |
| b/c | because | *late b/c traffic* |
| e.g. | наприклад | *e.g. Lisbon, Kraków* |
| ? | сумнів, не впевнений | *cost? — check* |

### IELTS Listening Part 3: навчальна розмова

У Part 3 говорять **2–4 людини** — зазвичай студенти й викладач (*tutor*) обговорюють проєкт, дослідження чи завдання (*assignment*). Типові завдання: вибір відповіді, нотатки, **matching** (зіставити людей і думки). Головна складність — думки змінюються в ході розмови.

> [!diagram] Як слухати дискусію в Part 3
> ```yaml
> layout: flow
> nodes:
>   - { id: who, label: "1", text: "Хто говорить?", note: "імена, ролі: студент, tutor", tone: blue }
>   - { id: what, label: "2", text: "Хто що думає?", note: "I reckon, I'd say, but…", tone: violet }
>   - { id: change, label: "3", text: "Чи змінилася думка?", note: "actually, OK, fair point", tone: orange }
>   - { id: decide, label: "4", text: "Що вирішили?", note: "So let's…, OK then…", tone: green }
> steps:
>   - { focus: who, note: "Перед записом подивись, скільки людей і хто вони. Імена з питань почуєш у перших репліках." }
>   - { focus: what, note: "Лови сигнали думки. Факт (we got 140 responses) і думка (I wasn't surprised) — різні речі." }
>   - { focus: change, note: "Хтось каже Actually… або That's a fair point — позиція зсувається. Перша думка може бути дистрактором." }
>   - { focus: decide, note: "Питання «What do they decide…?» — відповідь наприкінці фрагмента: So let's…, OK, then we'll…" }
> ```

## Приклади

- *Well, it wasn't planned at all.* — Ну, це зовсім не планувалося.
- *Honestly? Not for a second.* — Чесно? Ані на мить.
- *I see what you mean, but I'm not so sure.* — Розумію, що ти маєш на увазі, але я не впевнений.
- *I'm with Sara on this one.* — Тут я на боці Сари.
- *Apparently, the café is closing next month.* — Кажуть, кафе наступного місяця закривається.
- *A hundred and forty, actually.* — Насправді сто сорок.
- *That's a fair point.* — Слушне зауваження.
- *Coming to the gym later? — Can't, sorry. Got a deadline.* — Підеш пізніше в спортзал? — Не можу, вибач. Маю дедлайн.
- *On the whole, the project went well.* — Загалом проєкт пройшов добре.
- *It depends on the person, I reckon.* — Гадаю, це залежить від людини.

## Слова

> [!word] point of view
> ipa: /ˌpɔɪnt əv ˈvjuː/ · pos: noun · level: B1 · id: en-b1-listen-interviews-w01
> uk: точка зору
> example: From my **point of view**, it's too expensive. — З моєї точки зору, це задорого.

> [!word] sceptical
> ipa: /ˈskeptɪkəl/ · pos: adj · level: B1 · id: en-b1-listen-interviews-w02
> uk: скептичний; недовірливий
> example: She was **sceptical** about the plan. — Вона скептично ставилася до плану.
> note: US — skeptical. sc читається /sk/: «СКЕП-ті-кел».

> [!word] enthusiastic
> ipa: /ɪnˌθjuːziˈæstɪk/ · ipa-us: /ɪnˌθuːziˈæstɪk/ · pos: adj · level: B1 · id: en-b1-listen-interviews-w03
> uk: захоплений; сповнений ентузіазму
> example: The students were very **enthusiastic** about the trip. — Студенти були в захваті від поїздки.
> note: enthusiastic about something; th — /θ/.

> [!word] apparently
> ipa: /əˈpærəntli/ · ipa-us: /əˈperəntli/ · pos: adv · level: B1 · id: en-b1-listen-interviews-w04
> uk: кажуть; начебто; судячи з усього
> example: **Apparently**, the shop is closing. — Кажуть, магазин закривається.
> note: мовець переказує чуже — не «очевидно» (це obviously)!

> [!word] on the whole
> ipa: /ˌɒn ðə ˈhəʊl/ · ipa-us: /ˌɑːn ðə ˈhoʊl/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w05
> uk: загалом; в цілому
> example: **On the whole**, I enjoyed the course. — Загалом мені сподобався курс.
> note: whole звучить як hole — /həʊl/, w німе.

> [!word] it depends
> ipa: /ɪt dɪˈpendz/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w06
> uk: залежить (від обставин)
> example: Is it a good idea? — **It depends** on the price. — Це хороша ідея? — Залежить від ціни.
> note: depends ON — не «from».

> [!word] I reckon
> ipa: /aɪ ˈrekən/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w07
> uk: я гадаю; мені здається (розмовне)
> example: **I reckon** it'll rain later. — Гадаю, пізніше буде дощ.
> note: дуже британське розмовне; у формальному тексті — I think.

> [!word] to be fair
> ipa: /tə bi ˈfeə/ · ipa-us: /tə bi ˈfer/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w08
> uk: справедливості заради; якщо чесно
> example: The food was slow, but **to be fair**, it was very busy. — Їжу несли довго, але, справедливості заради, було дуже людно.

> [!word] I suppose
> ipa: /aɪ səˈpəʊz/ · ipa-us: /aɪ səˈpoʊz/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w09
> uk: мабуть; я так думаю (без ентузіазму)
> example: Is it worth it? — **I suppose** so. — Воно того варте? — Мабуть, так.
> note: часто звучить як неохоча, слабка згода.

> [!word] convinced
> ipa: /kənˈvɪnst/ · pos: adj · level: B1 · id: en-b1-listen-interviews-w10
> uk: переконаний
> example: I'm not **convinced** it will work. — Я не переконаний, що це спрацює.
> note: одним складом у кінці: /vɪnst/, без «-ед».

> [!word] hesitate
> ipa: /ˈhezɪteɪt/ · pos: verb · level: B1 · id: en-b1-listen-interviews-w11
> uk: вагатися; зволікати
> example: She **hesitated** before answering. — Вона завагалася, перш ніж відповісти.
> note: Don't hesitate to ask. — Не соромтеся питати.

> [!word] by the way
> ipa: /ˌbaɪ ðə ˈweɪ/ · pos: phrase · level: B1 · id: en-b1-listen-interviews-w12
> uk: до речі; між іншим
> example: **By the way**, did you call Mum? — До речі, ти подзвонив мамі?
> note: сигнал зміни теми; у чатах — BTW.

> [!word] assignment
> ipa: /əˈsaɪnmənt/ · pos: noun · level: B1 · id: en-b1-listen-interviews-w13
> uk: завдання (навчальне); письмова робота
> example: The **assignment** is due on Friday. — Роботу треба здати в пʼятницю.
> note: g німе: «е-САЙН-мент».

> [!word] tutor
> ipa: /ˈtjuːtə/ · ipa-us: /ˈtuːt̬ɚ/ · pos: noun · level: B1 · id: en-b1-listen-interviews-w14
> uk: викладач (який веде групу чи студента); репетитор
> example: Our **tutor** gave us feedback on the project. — Наш викладач дав відгук про проєкт.

> [!word] response
> ipa: /rɪˈspɒns/ · ipa-us: /rɪˈspɑːns/ · pos: noun · level: B1 · id: en-b1-listen-interviews-w15
> uk: відповідь; реакція; відгук
> example: We got 140 **responses** to our questionnaire. — Ми отримали 140 відповідей на анкету.
> note: дієслово — respond (to).

## Слухаємо

### Радіоінтервʼю з шеф-кухаркою

> [!listen] Як Марта почала готувати?
> level: B1 · type: answer · id: en-b1-listen-interviews-l01
> audio: Host: So, Marta, how did you get into cooking?
> audio: Marta: Well, it wasn't planned at all. I was studying law, and I took a part-time job in a café to pay the rent. Within a month, I knew law wasn't for me.
> - [ ] вона з дитинства мріяла бути кухаркою
> - [x] підробляла в кафе під час навчання на юриста — і зрозуміла, що право не для неї
> - [ ] вона закінчила кулінарну школу
>
> **Пояснення:** *get into* — почати займатися. *It wasn't planned at all* — зовсім не планувала.

> [!listen] Що Марта думає про свою колишню професію?
> level: B1 · type: answer · id: en-b1-listen-interviews-l02
> audio: Host: Do you ever miss law?
> audio: Marta: Honestly? Not for a second. I mean, the money was better, I suppose, but I'd never go back.
> - [ ] сумує за нею й хоче повернутися
> - [x] не шкодує, хоча визнає, що заробляла більше
> - [ ] ще не вирішила
>
> **Пояснення:** *Not for a second* — ані на мить. *I suppose* — неохоче визнання. Позиція — після *but*: *I'd never go back*.

> [!listen] Що найважче в ресторанному бізнесі, на думку Марти?

> audio: Host: What's the hardest part of running a restaurant?
> audio: Marta: People think it's the long hours, but you get used to those. For me, it's finding good staff and keeping them.
> - [ ] довгий робочий день
> - [x] знайти хороших працівників і втримати їх
> - [ ] високі ціни на продукти
>
> **Пояснення:** *People think…, but…* — спершу чужа думка (дистрактор), потім своя.

> [!listen] Чого Марта радить НЕ робити молодим кухарям?
> level: B1 · type: answer · id: en-b1-listen-interviews-l04
> audio: Host: Any advice for young chefs?
> audio: Marta: Travel. Eat everywhere. And don't be in a hurry to open your own place. Work for other people first and make your mistakes on their money!
> - [ ] подорожувати
> - [x] поспішати з відкриттям власного ресторану
> - [ ] працювати на інших
>
> **Пояснення:** *don't be in a hurry to…* — не поспішай. Решта — те, що вона якраз радить робити.

### Розмови друзів

>
> **Пояснення:** *I'm with Sara* — я на боці Сари. *Fine, fine* — Том неохоче погоджується, але ставить умову.

> - [x] скептичне
> - [ ] байдуже
>
> **Пояснення:** *In October?* з подивом, потім *maybe, but…* — Оля сумнівається. Ден, навпаки, — за.

> [!listen] Чому B не піде в спортзал?
> level: B1 · type: answer · id: en-b1-listen-interviews-l07

>
> **Пояснення:** розмовні скорочення: *Coming…?* = *Are you coming…?*, *Got a deadline* = *I've got a deadline*.

> [!listen] Що думає B?
> level: B1 · type: answer · id: en-b1-listen-interviews-l08

> audio: B: Hmm, I see what you mean, but I'm not sure it's for everyone. I'd rather schools taught people how to manage money.

> - [x] частково не погоджується й пропонує вчити фінансової грамотності
> - [ ] вважає, що програмування треба вчити всіх
>
> **Пояснення:** *I see what you mean, but…* — ввічлива незгода. *I'd rather…* — «я б волів, щоб…».

> [!listen] Що відчуває мовець?
> level: B1 · type: answer · id: en-b1-listen-interviews-l09

> level: B1 · type: answer · id: en-b1-listen-interviews-l10

> audio: B: Well… the actors were good, I suppose. But it was far too long.

>
> **Пояснення:** *Well…* + *I suppose* + *But…* — класична ввічлива незгода.

### IELTS Part 3 — студенти й викладач

> audio: Mark: A hundred and forty, actually. Twenty more came in last night.
> - [ ] 120
> - [x] 140

> [!speak] Ввічливо не погодься

## Типові помилки українців

> [!pitfall] Actually ≠ «актуально»
> *Actually* означає «насправді», «взагалі-то» і часто вводить **виправлення**: *A hundred and forty, actually.* «Актуальний» англійською — *relevant* або *up to date*. Почув *actually* — чекай, що зараз попередню інформацію виправлять.

> [!pitfall] Перша думка — не остаточна
> У розмові люди сперечаються й змінюють позицію: *Charts, definitely. — OK, but let's put the tables in the report.* В IELTS Part 3 питання «What do they decide?» — про **кінець** обміну репліками. Не записуй першу почуту пропозицію.

> [!pitfall] Розуміти стриманість буквально
> *Not bad* — це добре. *I suppose so* — слабке «так». *That's an interesting idea…* — часто «ні». Українці, які чують лише слова, роблять неправильні висновки про ставлення мовця. Слухай інтонацію і те, що йде після *but*.

> [!pitfall] Перекладати кожне «you know» і «like»
> *Fillers* — це паузи, а не зміст: *It was, like, you know, kind of amazing* = *It was amazing*. Намагаючись їх «зрозуміти», губиш головне. Відфільтровуй.

## Практика

> [!quiz] Що зазвичай робить «I mean» у розмові?
> level: B1 · id: en-b1-listen-interviews-q02
> - [ ] означає «я маю на увазі гроші»
> - [x] уточнює або пояснює щойно сказане
> - [ ] показує згоду
> - [ ] завершує розмову
>
> **Пояснення:** *I mean* — «тобто», «я хочу сказати». *Not for a second. I mean, the money was better, but…* — уточнення.

> [!quiz] Які фрази вводять думку мовця? Обери всі.
> level: B1 · type: multi · id: en-b1-listen-interviews-q03
> - [x] I reckon…
> - [x] Personally,…
> - [x] If you ask me,…
> - [ ] It was built in 1990.
> - [x] I'd say…
> - [ ] The meeting starts at ten.
>
> **Пояснення:** *I reckon, personally, if you ask me, I'd say* — думка. Дата будівництва й час зустрічі — факти.

> [!quiz] «Apparently, the shop is closing.» Що це означає?
> level: B1 · id: en-b1-listen-interviews-q04
> - [ ] Очевидно, що магазин закривається.
> - [x] Кажуть (я чув), що магазин закривається.
> - [ ] Магазин точно закривається, я бачив оголошення.
> - [ ] Магазин не закривається.
>
> **Пояснення:** *apparently* — переказ чужої інформації. «Очевидно» — *obviously*.

> [!quiz] Друг з рівною інтонацією каже: «Yeah, right». Що він має на увазі?
> level: B1 · id: en-b1-listen-interviews-q05
> - [ ] повністю погоджується
> - [x] не вірить тобі (сарказм)
> - [ ] просить повторити
> - [ ] каже «праворуч»
>
> **Пояснення:** *Yeah, right* з рівною або іронічною інтонацією — «ага, звісно» (не вірю). Два позитивні слова дають негативний зміст.

> [!quiz] Як ввічливо не погодитися? Обери всі.
> level: B1 · type: multi · id: en-b1-listen-interviews-q06
> - [x] I see what you mean, but…
> - [x] I'm not so sure about that.
> - [ ] You're wrong.
> - [x] I take your point, but…
> - [ ] That's nonsense.
>
> **Пояснення:** спершу визнай думку співрозмовника, потім — своя позиція. *You're wrong* і *That's nonsense* звучать різко.

> [!quiz] Що таке IELTS Listening Part 3?
> level: B1 · id: en-b1-listen-interviews-q07
> - [ ] монолог гіда
> - [x] розмова 2–4 людей у навчальному контексті: студенти й викладач
> - [ ] телефонна розмова про бронювання
> - [ ] лекція
>
> **Пояснення:** Part 3 — навчальна дискусія. Треба розуміти думки, згоду, незгоду й рішення.

> [!quiz] Розстав репліки розмови в логічному порядку

> [!quiz] У нотатках студент написав «bike use ↓». Що це означає?
> level: B1 · id: en-b1-listen-interviews-q11
> - [ ] велосипеди дорожчають
> - [x] велосипедами користуються менше (падіння)
> - [ ] велосипедів стало більше
> - [ ] велосипедні доріжки внизу міста
>
> **Пояснення:** ↑ — зростання, ↓ — падіння. Символи економлять час: аудіо не чекатиме, поки ти допишеш речення.

> [!quiz] Анна каже «about 120», Марк відповідає: «A hundred and forty, actually». Яку роль тут грає actually?
> level: B1 · id: en-b1-listen-interviews-q12
> - [ ] «актуально, зараз»
> - [x] вводить виправлення: «насправді»
> - [ ] показує, що Марк згоден
> - [ ] означає «приблизно»
>
> **Пояснення:** *actually* — «насправді». Почув його — попередню інформацію, найімовірніше, виправлять.

> [!quiz] «Got a minute?» — що це в повній формі?
> level: B1 · id: en-b1-listen-interviews-q13
> - [x] Have you got a minute?
> - [ ] I got a minute.
> - [ ] Did you get a minute?
> - [ ] Got it in a minute.
>
> **Пояснення:** у розмові допоміжне дієслово й підмет часто випадають: *Coming?* = *Are you coming?*, *Sounds good* = *That sounds good*.

> [!quiz] Які реакції показують, що слухач стежить за розмовою (а не відповідає по суті)? Обери всі.
> level: B1 · type: multi · id: en-b1-listen-interviews-q14
> - [x] Mm-hm.
> - [x] Right.
> - [x] Really?
> - [ ] I disagree, because the data shows…
> - [x] No way!
>
> **Пояснення:** це *back-channelling* — сигнали «я слухаю». Вони не змінюють зміст розмови, тож в IELTS їх можна не записувати.

## Фішки

> [!reel] 🫖 «Not bad» — найвища британська похвала
> Британці славляться стриманістю: *not bad* — добре, *quite good* — іноді «так собі», *I'll bear it in mind* — найімовірніше, ні. Тому слухай інтонацію й контекст, а не лише слова.

> [!reel] 🗣️ Um чи uh — це не випадковість
> Психолінгвісти Герберт Кларк і Жан Фокс Трі (2002) показали: носії англійської обирають *uh* перед короткою паузою, а *um* — перед довшою. Тож навіть «паузи» щось кажуть слухачу.

> [!reel] 👂 Мовчазний слухач — підозрілий
> В англійській розмові слухач щокілька секунд вставляє *mm-hm*, *yeah*, *right*. Якщо мовчати, співрозмовник може подумати, що ти не слухаєш або не згоден. Ці звуки — частина ввічливості.
