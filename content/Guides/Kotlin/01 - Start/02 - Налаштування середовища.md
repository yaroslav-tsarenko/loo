# Налаштування середовища

## Ціль уроку

Підготувати середовище для запуску Kotlin-коду локально: IDE, JDK, Gradle і простий проєкт.

## Варіанти запуску Kotlin

### Kotlin Playground

Найшвидший старт без встановлення: відкрий Kotlin Playground і запускай приклади в браузері. Це добре для синтаксису, але погано для реального Gradle-проєкту.

### IntelliJ IDEA

Найзручніший варіант для JVM/backend/KMP. Kotlin-плагін входить у сучасні версії IntelliJ IDEA.

### Android Studio

Найкращий варіант для Android і Jetpack Compose.

### CLI

Можна встановити Kotlin compiler і запускати `.kt` файли з терміналу, але для навчального курсу краще Gradle-проєкт.

## Мінімальні вимоги

- JDK 17 або новіший для більшості сучасних JVM-проєктів.
- IntelliJ IDEA або Android Studio.
- Gradle wrapper у проєкті.
- Kotlin plugin version у `build.gradle.kts`.

## Створення JVM-проєкту

У IntelliJ IDEA:

1. File -> New -> Project.
2. Language: Kotlin.
3. Build system: Gradle.
4. DSL: Kotlin.
5. Target: JVM.
6. JDK: 17+.
7. Створи `src/main/kotlin/Main.kt`.

Приклад `build.gradle.kts`:

```kotlin
plugins {
    kotlin("jvm") version "2.4.0"
    application
}

repositories {
    mavenCentral()
}

application {
    mainClass.set("MainKt")
}
```

Приклад `Main.kt`:

```kotlin
fun main() {
    println("Hello, Kotlin")
}
```

Запуск:

```bash
./gradlew run
```

## Структура проєкту

```text
project/
  build.gradle.kts
  settings.gradle.kts
  src/
    main/
      kotlin/
        Main.kt
    test/
      kotlin/
        MainTest.kt
```

## Типові проблеми

- IDE бачить стару версію Kotlin: онови IDE або Kotlin plugin.
- JDK не налаштований: перевір Project SDK.
- Gradle sync падає: перевір версію Kotlin, Gradle і доступ до Maven Central.
- `mainClass` не знаходиться: для top-level `fun main()` клас зазвичай має назву `MainKt`.

## Вправа

1. Створи JVM Gradle-проєкт.
2. Додай `Main.kt`.
3. Виведи своє ім'я, поточну тему курсу й результат простого обчислення.
4. Запусти через IDE і через `./gradlew run`.
