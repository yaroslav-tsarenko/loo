# Перша програма і структура файлів

## Ціль уроку

Навчитися читати базову Kotlin-програму, розуміти top-level declarations, packages, imports і entry point.

## Entry point

Точка входу в Kotlin-програму - функція `main`.

```kotlin
fun main() {
    println("Hello, Kotlin")
}
```

Варіант з аргументами:

```kotlin
fun main(args: Array<String>) {
    println(args.joinToString())
}
```

## Top-level declarations

У Kotlin функції, константи й класи можна оголошувати на верхньому рівні файлу, без wrapper-класу.

```kotlin
const val APP_NAME = "Budget CLI"

fun main() {
    printWelcome()
}

fun printWelcome() {
    println("Welcome to $APP_NAME")
}
```

## Packages

Package задає логічний namespace.

```kotlin
package com.example.budget

fun main() {
    println("Budget app")
}
```

Файл може лежати не в ідеально відповідній папці, але на практиці краще тримати шлях схожим на package:

```text
src/main/kotlin/com/example/budget/Main.kt
```

## Imports

Import підключає класи, функції або top-level declarations з інших packages.

```kotlin
import kotlin.math.roundToInt

fun main() {
    println(3.7.roundToInt())
}
```

## String templates

```kotlin
val name = "Yaroslav"
val lessons = 24

println("Student: $name")
println("Lessons left: ${lessons - 1}")
```

## Коментарі

```kotlin
// Однорядковий коментар

/*
 Багаторядковий коментар
*/
```

## Мініпрактика

Створи програму `Profile.kt`:

```kotlin
package course.start

const val COURSE = "Kotlin"

fun main() {
    val name = "Student"
    val currentModule = 1

    println("Name: $name")
    println("Course: $COURSE")
    println("Module: $currentModule")
}
```
