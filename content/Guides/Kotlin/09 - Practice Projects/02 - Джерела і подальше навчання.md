## Що читати після курсу

### Якщо ціль Android

1. Jetpack Compose state і side effects.
2. ViewModel + StateFlow.
3. Navigation.
4. Room.
5. Retrofit/Ktor Client.
6. Hilt або Koin.
7. UI і ViewModel testing.

### Якщо ціль backend

1. Ktor або Spring Boot з Kotlin.
2. Serialization.
3. Database access: Exposed, jOOQ або JDBC.
4. Coroutines на server side.
5. Authentication.
6. Observability.
7. Integration tests.

### Якщо ціль KMP

1. Source sets.
2. expect/actual.
3. Common tests.
4. Ktor Client.
5. SQLDelight або інше shared persistence рішення.
6. Compose Multiplatform, якщо потрібен shared UI.
7. Version compatibility.

## Як підтримувати знання актуальними

- Перед стартом нового проєкту перевіряй Kotlin release notes.
- Для Android перевіряй сумісність Kotlin, AGP, Compose compiler/plugin і Gradle.
- Для KMP перевіряй Kotlin, Xcode, Gradle і platform target support.
- Для coroutines перевіряй версію `kotlinx.coroutines`.
- Для backend перевіряй Ktor release notes і Gradle dependency versions.

## Завершення курсу

Після завершення повернися до [[Guides/Kotlin/Зміст|змісту]] і простав для себе статус кожного модуля:

- `read`
- `coded`
- `tested`
- `project done`
