# Функції параметри і області видимості

## Ціль уроку

Навчитися писати функції, використовувати default/named parameters, single-expression functions і розуміти scope.

## Базова функція

```kotlin
fun greet(name: String): String {
    return "Hello, $name"
}
```

Виклик:

```kotlin
val message = greet("Alex")
println(message)
```

## Single-expression function

```kotlin
fun square(x: Int): Int = x * x
```

Тип можна опустити, якщо він очевидний:

```kotlin
fun square(x: Int) = x * x
```

## Default parameters

```kotlin
fun connect(host: String, port: Int = 5432, useSsl: Boolean = true) {
    println("$host:$port ssl=$useSsl")
}

connect("localhost")
connect("localhost", port = 15432)
```

## Named arguments

```kotlin
connect(
    host = "db.example.com",
    port = 5432,
    useSsl = true
)
```

Named arguments особливо корисні, коли є кілька параметрів одного типу.

## Vararg

```kotlin
fun sum(vararg numbers: Int): Int {
    return numbers.sum()
}

println(sum(1, 2, 3))
```

## Scope

Змінна доступна в межах блоку, де її оголошено.

```kotlin
fun printUser(isAdmin: Boolean) {
    val role = if (isAdmin) {
        val label = "administrator"
        label.uppercase()
    } else {
        "user"
    }

    println(role)
}
```

`label` не доступна поза `if` блоком.

## Local functions

Функцію можна оголосити всередині іншої функції.

```kotlin
fun validateEmail(email: String): Boolean {
    fun hasAt() = "@" in email
    fun hasDomain() = email.substringAfter("@").contains(".")

    return hasAt() && hasDomain()
}
```

## Вправа

Створи функції:

1. `calculateTotal(price: Double, quantity: Int, discount: Double = 0.0): Double`
2. `formatReceipt(product: String, total: Double): String`
3. `printReceipt(...)`, яка друкує результат.

Використай named arguments у хоча б одному виклику.

## Типові помилки

- Робити функцію з 6-8 параметрами замість data class.
- Не використовувати named arguments для boolean-параметрів.
- Писати довгу функцію замість кількох коротких.
- Повертати `Unit`, коли функція має обчислювати значення.
