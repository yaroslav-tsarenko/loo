# Змінні типи і базовий синтаксис

## Ціль уроку

Навчитися оголошувати змінні, читати типи, користуватися базовими операторами й розуміти type inference.

## `val` і `var`

`val` - read-only reference. Після присвоєння посилання не можна змінити.

```kotlin
val name = "Alex"
// name = "Sam" // помилка
```

`var` - змінна reference.

```kotlin
var age = 25
age += 1
```

Правило: починай з `val`, переходь на `var` тільки коли значення справді має змінюватися.

## Type inference

Kotlin часто сам виводить тип.

```kotlin
val city = "Kyiv"      // String
val count = 10         // Int
val price = 19.99      // Double
val isActive = true    // Boolean
```

Тип можна вказати явно:

```kotlin
val usersCount: Long = 10L
val rating: Float = 4.8f
```

## Базові типи

- `Int`, `Long`, `Short`, `Byte`
- `Double`, `Float`
- `Boolean`
- `Char`
- `String`
- `Unit`
- `Nothing`

У Kotlin усе поводиться як об'єкт: можна викликати methods/properties на значеннях.

```kotlin
val text = "kotlin"
println(text.uppercase())
println(42.toString())
```

## Арифметика і порівняння

```kotlin
val total = 10 + 5
val average = total / 2
val hasAccess = total > 10
val isSame = total == 15
val isDifferent = total != 15
```

`==` перевіряє структурну рівність, `===` - referential equality.

```kotlin
val a = "Kotlin"
val b = "Kotlin"

println(a == b)   // true
println(a === b)  // залежить від посилань
```

## Перетворення типів

Kotlin не робить неявні widening conversions між number types.

```kotlin
val small: Int = 10
val big: Long = small.toLong()
```

## `Unit`

`Unit` означає "функція нічого корисного не повертає".

```kotlin
fun log(message: String): Unit {
    println(message)
}
```

`Unit` зазвичай не пишуть явно:

```kotlin
fun log(message: String) {
    println(message)
}
```

## Вправа

Напиши програму, яка:

1. Зберігає назву товару, ціну, кількість.
2. Рахує total.
3. Друкує рядок: `Order: 3 x Book = 450`.
4. Використовує `val` всюди, де можливо.

## Типові помилки

- Надмірне використання `var`.
- Очікування, що `Int` автоматично стане `Long`.
- Плутанина між `==` і `===`.
- Явне написання типів там, де type inference робить код читабельнішим.
