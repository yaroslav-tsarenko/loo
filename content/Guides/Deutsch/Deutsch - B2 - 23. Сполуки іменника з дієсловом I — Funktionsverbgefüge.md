# Сполуки іменника з дієсловом I — Funktionsverbgefüge

> [!success] Після цієї теми ти зможеш
> - пояснити, що таке *Funktionsverbgefüge* (FVG): абстрактний іменник + «слабке» дієслово, яке лише додає граматику (*eine Entscheidung treffen*);
> - уживати близько 50 корисних FVG зі словників і формальних текстів: *in Frage kommen, zur Verfügung stehen, Kritik üben, Stellung nehmen, in Kraft treten*;
> - підбирати правильне дієслово, прийменник і відмінок, а не калькувати з української (*~~eine Entscheidung machen~~* → *treffen*);
> - розрізняти початок, стан і кінець дії: *in Kraft treten — in Kraft sein — außer Kraft setzen*.

## Передбач

> [!quiz] «Приймати рішення» німецькою — як правильно?
> level: B2 · type: single · id: de-b2-nvv-q01
> - [ ] eine Entscheidung machen
> - [ ] eine Entscheidung nehmen
> - [x] eine Entscheidung treffen
> - [ ] eine Entscheidung geben
>
> **Пояснення:** з іменником *Entscheidung* ужито дієслово ***treffen***: *eine Entscheidung treffen*. Українське «приймати» і англійське *make* тут не допомагають: ~~eine Entscheidung machen~~, ~~nehmen~~ або ~~geben~~ німці не кажуть. Ці сполуки треба вчити цілком, як одне слово.

## Пояснення

### Що таке Funktionsverbgefüge

*Das Funktionsverbgefüge* (FVG) — стійка сполука **абстрактного іменника** (часто з прийменником) і **дієслова**, яке майже втратило власне значення. Значення несе іменник, а дієслово виконує «функцію»: показує час, особу, початок чи кінець дії.

| Одне дієслово | Funktionsverbgefüge |
|---|---|
| entscheiden | **eine Entscheidung treffen** |
| helfen | **Hilfe leisten** |
| kritisieren | **Kritik üben** |
| fragen | **eine Frage stellen** |
| gelten ab | **in Kraft treten** |
| berücksichtigen | **in Betracht ziehen** |

> nodes:

>   - { id: v2, col: v, label: "helfen", text: "Sie helfen uns.", note: "коротко", tone: yellow }
>   - { id: f2, col: f, label: "Hilfe leisten", text: "Sie leisten uns Hilfe.", note: "можна: schnelle Hilfe leisten", tone: pink }
>   - { id: v3, col: v, label: "kritisieren", text: "Er kritisiert den Plan.", note: "прямо", tone: yellow }
>   - { id: f3, col: f, label: "Kritik üben (an + Dat)", text: "Er übt scharfe Kritik am Plan.", note: "можна додати: scharf, heftig, berechtigt", tone: pink }
> steps:
>   - { focus: [v1, f1], note: "entscheiden і eine Entscheidung treffen означають те саме. Сполука довша, але до іменника можна додати прикметник: eine schwere, eine richtige Entscheidung treffen." }
>   - { focus: [v2, f2], note: "helfen — просто «допомагати». Hilfe leisten — урочистіше, і Hilfe можна уточнити: schnelle, erste Hilfe leisten." }
>   - { focus: [v3, f3], note: "Kritik üben an + Dativ. Знову іменник можна уточнити: scharfe Kritik üben. Одним дієсловом kritisieren цього не скажеш так лаконічно." }
> ```
> Жовтий — одне дієслово, рожевий — FVG; текстова мітка є в кожному блоці.

Чому німці вживають FVG, хоч є коротше дієслово?

1. **Прикметник.** До іменника можна додати означення: *eine schwere Entscheidung treffen*, *scharfe Kritik üben*.
2. **Нюанс.** *Zur Verfügung stellen* — не те саме, що *geben*.
3. **Стиль.** FVG типові для **Behörde, закону, газети, наукового тексту** (номінальний стиль, *Nominalstil*), а в розмові з друзями дієслово природніше.
4. **Часта потреба.** Деякі FVG не мають однослівного відповідника: *in Frage kommen*, *zur Verfügung stehen*.

### Фіксований склад

Склад FVG стійкий: **дієслово, іменник, прийменник і форма артикля** не міняємо.

- *zur Verfügung stehen*, не ~~zu Verfügung~~ (злите *zur = zu + der*);
- *in Frage kommen*, без артикля (за новою орфографією також *infrage kommen*);
- *in Kraft treten*, не ~~im Kraft treten~~;
- *Stellung nehmen **zu** + Dat*, *Rücksicht nehmen **auf** + Akk*, *Kritik üben **an** + Dat*, *Einfluss nehmen **auf** + Akk*, *Wert legen **auf** + Akk*.

Прийменник часто береться від того, що можна сказати про іменник: *Einfluss **auf** etwas*, *Kritik **an** etwas*.

### Початок, стан, кінець: три дієслова

Дієслово в FVG показує **Aktionsart** (фазу дії):

> [!diagram] Три фази: in Kraft treten, in Kraft sein, außer Kraft setzen
> ```yaml
> layout: flow
> nodes:
>   - { id: a, label: "початок", text: "in Kraft treten", note: "Das Gesetz tritt am 1. Januar in Kraft.", tone: yellow }
>   - { id: b, label: "стан", text: "in Kraft sein / bleiben", note: "Das Gesetz ist seit Jahren in Kraft.", tone: pink }
>   - { id: c, label: "кінець", text: "außer Kraft setzen / treten", note: "Das Gesetz wird außer Kraft gesetzt.", tone: gray }
> edges:
>   - { from: a, to: b, label: "потім" }
>   - { from: b, to: c, label: "зрештою" }
> steps:
>   - { focus: a, note: "Початок: in Kraft treten — набути чинності. Підмет — закон, правило, договір. Допоміжне sein: Das Gesetz ist in Kraft getreten." }
>   - { focus: b, note: "Стан: in Kraft sein (бути чинним), in Kraft bleiben. Тут уже немає руху, просто «діє»." }
>   - { focus: c, note: "Кінець: außer Kraft setzen — скасувати (хтось скасовує закон), außer Kraft treten — втратити чинність (закон сам перестає діяти)." }
> ```

Так само працюють пари *bringen — kommen* і *stellen — stehen*:

| Причина (хтось робить) | Результат (сам стається) |
|---|---|
| etwas **zur Verfügung stellen** | etwas **steht zur Verfügung** |
| etwas **zum Einsatz bringen** | etwas **kommt zum Einsatz** |
| etwas **in Betrieb nehmen** | etwas **ist in Betrieb** |
| etwas **in Bewegung setzen** | etwas **kommt in Bewegung** |

### FVG і пасив

Пасив у FVG часто обмежений: *Eine Entscheidung wird getroffen* — можливо, але ~~Das Gesetz wird in Kraft getreten~~ — ні. Коли хочеш пасивне значення, використовуй інше дієслово: *Die Hilfe wird geleistet. Das Gesetz wird in Kraft gesetzt* (для актів).

## Приклади

- *Die Stadt hat **Maßnahmen ergriffen**, um den Lärm zu senken.* — Місто вжило заходів, щоб знизити шум.
- *Wir haben **einen Beschluss gefasst**.* — Ми ухвалили рішення.
- *Ich möchte dazu **Stellung nehmen**.* — Я хочу висловити свою позицію щодо цього.
- *Der Raum **steht** Ihnen ab 9 Uhr **zur Verfügung**.* — Приміщення у вашому розпорядженні з девʼятої.
- *Er **übt** scharfe **Kritik** am Gesetz.* — Він гостро критикує закон.
- *Das Gesetz **tritt** am 1. Januar **in Kraft**.* — Закон набуває чинності першого січня.
- *Diese Kandidatin **kommt** für die Stelle **in Frage**.* — Ця кандидатка підходить на посаду.
- *Wir **nehmen** die Wartezeit **in Kauf**.* — Ми миримося з очікуванням.
- *Bitte **nehmen** Sie Rücksicht auf Ihre Nachbarn.* — Будь ласка, зважайте на сусідів.
- *Das Team hat sein Können **unter Beweis gestellt**.* — Команда довела свою кваліфікацію.
- *Ich lege großen **Wert** auf Pünktlichkeit.* — Я надаю великого значення пунктуальності.
- *Er hat **von seinem Recht Gebrauch gemacht**.* — Він скористався своїм правом.

## Слова

### Рішення, питання, критика

> [!word] eine Entscheidung treffen
> ipa: /ˈaɪ̯nə ɛntˈʃaɪ̯dʊŋ ˈtʁɛfn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w01
> uk: прийняти рішення
> example: Wir müssen bis Freitag **eine Entscheidung treffen**. — Ми мусимо ухвалити рішення до пʼятниці.
> note: = entscheiden. treffen → traf → hat getroffen; er trifft. Не: ~~machen~~, ~~nehmen~~. Схожа: eine Wahl treffen (зробити вибір).

> [!word] einen Beschluss fassen
> ipa: /ˈaɪ̯nən bəˈʃlʊs ˈfasn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w02
> uk: ухвалити постанову; вирішити (колегіально)
> example: Der Gemeinderat hat **einen Beschluss gefasst**. — Рада громади ухвалила постанову.
> note: = beschließen. fassen → fasste → hat gefasst. Про органи й збори, не про особисте рішення.

> [!word] Maßnahmen ergreifen
> ipa: /ˈmaːsnaːmən ɛɐ̯ˈɡʁaɪ̯fn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w03
> uk: вжити заходів
> example: Die Firma muss sofort **Maßnahmen ergreifen**. — Фірма має негайно вжити заходів.
> note: ergreifen → ergriff → hat ergriffen. Не: ~~Maßnahmen nehmen~~. Die Maßnahme, die Maßnahmen.

> [!word] eine Frage stellen
> ipa: /ˈaɪ̯nə ˈfʁaːɡə ˈʃtɛlən/ · pos: phrase · level: B2 · id: de-b2-nvv-w04
> uk: поставити питання
> example: Darf ich Ihnen **eine Frage stellen**? — Можна поставити вам питання?
> note: = fragen. Не: ~~eine Frage geben~~, ~~machen~~. Також Fragen stellen (в мн.). Іменник: die Fragestellung (постановка питання).

> [!word] Kritik üben
> ipa: /kʁiˈtiːk ˈyːbn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w05
> uk: критикувати; висловлювати критику
> example: Der Verband **übt** scharfe **Kritik** an dem Gesetz. — Спілка гостро критикує закон.
> note: = kritisieren. Kritik üben **an + Dat**. üben → übte → hat geübt. Не: ~~Kritik machen~~.

> [!word] Hilfe leisten
> ipa: /ˈhɪlfə ˈlaɪ̯stn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w06
> uk: надавати допомогу
> example: Die Nachbarn **leisteten** den Verletzten erste **Hilfe**. — Сусіди надали потерпілим першу допомогу.
> note: = helfen. leisten → leistete → hat geleistet. Урочистіше, ніж helfen. Часто: erste Hilfe leisten.

> [!word] Widerstand leisten
> ipa: /ˈviːdɐʃtant ˈlaɪ̯stn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w07
> uk: чинити опір
> example: Die Bevölkerung **leistete** dem Plan **Widerstand**. — Населення чинило опір цьому плану.
> note: = sich widersetzen. Dativ: dem Plan. Іменник der Widerstand, зазвичай в однині.

> [!word] Einspruch erheben
> ipa: /ˈaɪ̯nʃpʁʊx ɛɐ̯ˈheːbn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w08
> uk: подати заперечення; заявити протест
> example: Er **erhob** gegen den Bescheid **Einspruch**. — Він подав заперечення проти рішення.
> note: erheben → erhob → hat erhoben. Einspruch erheben **gegen + Akk**. Також Widerspruch einlegen (B1-26).

> [!word] Anspruch erheben
> ipa: /ˈanʃpʁʊx ɛɐ̯ˈheːbn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w09
> uk: заявити право (на що)
> example: Die Erben **erheben Anspruch** auf das Haus. — Спадкоємці заявляють права на будинок.
> note: Anspruch erheben **auf + Akk**. Не плутай з Anspruch haben auf (мати право).

> [!word] Anspruch haben
> ipa: /ˈanʃpʁʊx ˈhaːbn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w10
> uk: мати право (на що)
> example: Sie **hat Anspruch** auf zwei Wochen Urlaub. — Вона має право на два тижні відпустки.
> note: Anspruch haben **auf + Akk**. Der Anspruch, die Ansprüche. Формальне.

### Позиція, вплив, увага

> [!word] Stellung nehmen
> ipa: /ˈʃtɛlʊŋ ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w11
> uk: висловити позицію
> example: Der Minister **nahm** zu den Vorwürfen **Stellung**. — Міністр висловив позицію щодо звинувачень.
> note: Stellung nehmen **zu + Dat**. nehmen → nahm → hat genommen; er nimmt. Іменник: die Stellungnahme (висловлена позиція, заява).

> [!word] Einfluss nehmen
> ipa: /ˈaɪ̯nflʊs ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w12
> uk: впливати
> example: Die Medien wollen **Einfluss** auf die Wahl **nehmen**. — Медіа хочуть вплинути на вибори.
> note: Einfluss nehmen **auf + Akk**; Einfluss haben auf. Der Einfluss, die Einflüsse.

> [!word] Abschied nehmen
> ipa: /ˈapʃiːt ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w13
> uk: прощатися
> example: Sie **nahm** von ihrer Heimat **Abschied**. — Вона попрощалася з батьківщиною.
> note: Abschied nehmen **von + Dat**; = sich verabschieden. Урочисто, зворушливо.

> [!word] Kontakt aufnehmen
> ipa: /kɔnˈtakt ˈaʊ̯fneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w14
> uk: встановити контакт; звʼязатися
> example: Bitte **nehmen** Sie mit uns **Kontakt auf**. — Будь ласка, звʼяжіться з нами.
> note: aufnehmen — відокремлюване: nimmt auf, nahm auf, hat aufgenommen. Kontakt aufnehmen **mit + Dat**. Шаблон у листах.

> [!word] Verantwortung tragen
> ipa: /fɛɐ̯ˈʔantvɔʁtʊŋ ˈtʁaːɡn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w15
> uk: нести відповідальність
> example: Der Geschäftsführer **trägt** die **Verantwortung** für den Fehler. — Керівник несе відповідальність за помилку.
> note: Verantwortung tragen **für + Akk**. tragen → trug → hat getragen; er trägt. Також Verantwortung übernehmen (взяти на себе).

> [!word] Wert legen
> ipa: /veːɐ̯t ˈleːɡn̩/ · pos: phrase · level: B2 · id: de-b2-nvv-w16
> uk: надавати значення; вважати важливим
> example: Ich **lege** großen **Wert** auf gute Kommunikation. — Я надаю великого значення доброму спілкуванню.
> note: Wert legen **auf + Akk**. legen → legte → hat gelegt. Не: ~~Wert geben~~.

> [!word] Bilanz ziehen
> ipa: /biˈlants ˈtsiːən/ · pos: phrase · level: B2 · id: de-b2-nvv-w17
> uk: підбити підсумок
> example: Am Jahresende **ziehen** wir **Bilanz**. — Наприкінці року підбиваємо підсумок.
> note: ziehen → zog → hat gezogen. Bilanz ziehen aus + Dat: aus dem Jahr Bilanz ziehen. Іменник die Bilanz, die Bilanzen.

> [!word] in Frage kommen
> ipa: /ɪn ˈfʁaːɡə ˈkɔmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w18
> uk: бути можливим; підходити
> example: Für diese Stelle **kommt** nur eine erfahrene Person **in Frage**. — На цю посаду підходить лише досвідчена людина.
> note: за новою орфографією також infrage kommen. kommen → kam → ist gekommen. Заперечення: nicht in Frage kommen — виключено.

> [!word] in Betracht ziehen
> ipa: /ɪn bəˈtʁaxt ˈtsiːən/ · pos: phrase · level: B2 · id: de-b2-nvv-w19
> uk: брати до уваги; розглядати
> example: Wir **ziehen** auch andere Lösungen **in Betracht**. — Ми розглядаємо й інші рішення.
> note: = erwägen. Пасив: Das wird in Betracht gezogen. Також in Betracht kommen (можливий).

> [!word] in Erwägung ziehen
> ipa: /ɪn ɛɐ̯ˈvɛːɡʊŋ ˈtsiːən/ · pos: phrase · level: B2 · id: de-b2-nvv-w20
> uk: взяти до розгляду; обмірковувати
> example: Die Regierung **zieht** eine Steuersenkung **in Erwägung**. — Уряд розглядає зниження податків.
> note: = erwägen; офіційніше, ніж in Betracht ziehen. Ä довге: [ɛː].

> [!word] in Anspruch nehmen
> ipa: /ɪn ˈanʃpʁʊx ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w21
> uk: скористатися (послугою, допомогою)
> example: Viele Patienten **nehmen** psychologische Hilfe **in Anspruch**. — Багато пацієнтів користуються психологічною допомогою.
> note: Hilfe, Leistung, Rat, Urlaub in Anspruch nehmen. Також: jemanden in Anspruch nehmen — займати чийсь час.

> [!word] in Kauf nehmen
> ipa: /ɪn kaʊ̯f ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w22
> uk: миритися (з недоліком); йти на ризик
> example: Für den günstigen Preis **nehme** ich lange Wartezeiten **in Kauf**. — Заради вигідної ціни я мирюся з довгим очікуванням.
> note: Nachteile / Risiken / Verspätungen in Kauf nehmen. Не про «купівлю».

> [!word] zur Kenntnis nehmen
> ipa: /tsuːɐ̯ ˈkɛntnɪs ˈneːmən/ · pos: phrase · level: B2 · id: de-b2-nvv-w23
> uk: взяти до відома
> example: Bitte **nehmen** Sie die neue Regelung **zur Kenntnis**. — Будь ласка, візьміть до відома нове правило.
> note: часто в листах: Wir haben Ihr Schreiben zur Kenntnis genommen. Не плутай з Kenntnis haben (знати).

### Наявність, розпорядження, чинність

> [!word] zur Verfügung stehen
> ipa: /tsuːɐ̯ fɛɐ̯ˈfyːɡʊŋ ˈʃteːən/ · pos: phrase · level: B2 · id: de-b2-nvv-w24
> uk: бути у розпорядженні
> example: Das Auto **steht** Ihnen den ganzen Tag **zur Verfügung**. — Автомобіль у вашому розпорядженні цілий день.
> note: Dativ: Ihnen. Результат; причина: zur Verfügung stellen. stehen → stand → hat/ist gestanden (північ DE hat; південь DE, AT, CH ist).

## Типові помилки українців

> [!pitfall] Кальки з «робити» і «приймати»
> ~~eine Entscheidung machen~~, ~~eine Entscheidung nehmen~~ → eine Entscheidung **treffen**; ~~eine Frage geben~~ → eine Frage **stellen**; ~~Kritik machen~~ → Kritik **üben**; ~~Maßnahmen nehmen~~ → Maßnahmen **ergreifen**; ~~einen Beschluss nehmen~~ → einen Beschluss **fassen**. Дієслово в FVG не вгадаєш за значенням: вчи сполуку цілком.

> [!pitfall] Прийменник, відмінок і артикль
> ~~zu Verfügung stehen~~ → **zur** Verfügung stehen; ~~im Kraft treten~~ → **in** Kraft treten; ~~Kritik üben über den Plan~~ → Kritik üben **an** dem Plan; ~~Einfluss nehmen über die Wahl~~ → Einfluss nehmen **auf** die Wahl; ~~Stellung nehmen für das Thema~~ → Stellung nehmen **zu** dem Thema. Прийменник є частиною сполуки.

> [!pitfall] Забагато номінального стилю
> У листі до Behörde *zur Kenntnis nehmen* і *Folge leisten* — на місці, а друзям краще написати *Ich habe mich entschieden*, а не *Ich habe die Entscheidung zur Verlegung des Termins getroffen* (граматично правильно, але звучить канцелярськи). Коли в розмові багато FVG, мова звучить канцелярською. Обирай стиль під ситуацію.

> [!pitfall] Пасив і зворотне не завжди можливі
> *Das Gesetz **tritt** in Kraft*, але ~~Das Gesetz wird in Kraft getreten~~. Каузативна форма — *Das Gesetz wird **in Kraft gesetzt***. Не всі FVG переносять пасив: *Einfluss wird genommen* звучить штучно. Якщо не впевнений, використай однослівне дієслово: *beeinflusst werden*.

## Landeskunde: Wie ein Gesetz in Kraft tritt

> [!example] Vom Beschluss zum Gesetz
> Wenn in Deutschland ein neues Gesetz gelten soll, muss es mehrere Stationen durchlaufen. Zuerst bringt die Bundesregierung, eine Gruppe von Abgeordneten oder der Bundesrat einen Entwurf in den Bundestag ein. Der Bundestag diskutiert den Entwurf und fasst am Ende einen Beschluss. Auch der Bundesrat wirkt mit, denn die Länder haben bei vielen Gesetzen ein Mitspracherecht: Bei Zustimmungsgesetzen muss er zustimmen, bei anderen Gesetzen kann er Einspruch einlegen. Wenn alle Schritte abgeschlossen sind, unterschreibt der Bundespräsident das Gesetz, und es wird im Bundesgesetzblatt verkündet. Das Grundgesetz sagt dazu, dass jedes Gesetz den Tag des Inkrafttretens bestimmen soll. Fehlt eine solche Angabe, tritt das Gesetz am vierzehnten Tag nach Ablauf des Tages in Kraft, an dem das Bundesgesetzblatt ausgegeben wurde. Viele Gesetze nennen aber ein festes Datum, zum Beispiel den ersten Januar. Wer sich informieren will, kann das Bundesgesetzblatt oder die Webseite des Bundestages nutzen. Dort stehen die Texte zur Verfügung. Die Sprache der Gesetze benutzt besonders viele feste Verbindungen, etwa „Beschluss fassen“, „Anwendung finden“ oder „Stellung nehmen“. Solche Texte sollen knapp und genau sein, wirken auf Menschen ohne juristische Ausbildung aber oft schwer. Deshalb wird seit Jahren über eine verständlichere Amtssprache diskutiert. Ein Gesetz bleibt so lange in Kraft, bis es geändert oder außer Kraft gesetzt wird. In Zeitungen liest man deshalb oft Sätze wie „Das Gesetz tritt zum 1. Januar in Kraft“ oder „Die Regelung kommt ab Juli zur Anwendung“.

> [!quiz] Nach dem Text: Wann tritt ein Gesetz in Kraft, wenn kein Datum genannt wird?
> level: B2 · type: single · id: de-b2-nvv-q02
> - [ ] sofort nach der Unterschrift
> - [x] am vierzehnten Tag nach Ablauf des Tages der Ausgabe des Bundesgesetzblattes
> - [ ] am ersten Januar des nächsten Jahres
> - [ ] nach der Entscheidung des Bundesrates
>
> **Пояснення:** у тексті: *Fehlt eine solche Angabe, tritt das Gesetz am vierzehnten Tag nach Ablauf des Tages in Kraft, an dem das Bundesgesetzblatt ausgegeben wurde.* (Art. 82 Abs. 2 GG).

> [!quiz] Nach dem Text: Wer unterschreibt das Gesetz?
> level: B2 · type: single · id: de-b2-nvv-q03
> - [ ] der Bundeskanzler
> - [x] der Bundespräsident
> - [ ] der Bundestagspräsident
> - [ ] der Bundesrat
>
> **Пояснення:** *unterschreibt der Bundespräsident das Gesetz, und es wird im Bundesgesetzblatt verkündet.*

> [!quiz] Was stimmt laut Text? Wähle alle richtigen Aussagen.
> level: B2 · type: multi · id: de-b2-nvv-q04
> - [x] Viele Gesetze nennen ein festes Datum für das Inkrafttreten.
> - [x] Das Gesetz bleibt in Kraft, bis es geändert oder außer Kraft gesetzt wird.
> - [ ] Der Bundesrat entscheidet allein über jedes Gesetz.
> - [ ] Ein Gesetz tritt immer sofort nach der Unterschrift in Kraft.
>
> **Пояснення:** з тексту: *Viele Gesetze nennen aber ein festes Datum*; *bis es … außer Kraft gesetzt wird*. Закон набуває чинності не «негайно після підпису», а Бундесрат не вирішує сам: за текстом він бере участь, а для законів, що потребують згоди (Zustimmungsgesetze), мусить погодитися (Art. 77 GG).

## Практика

> [!quiz] Яка сполука означає «ухвалити постанову»?
> level: B2 · type: single · id: de-b2-nvv-q05
> - [ ] einen Beschluss nehmen
> - [x] einen Beschluss fassen
> - [ ] einen Beschluss machen
> - [ ] einen Beschluss stellen
>
> **Пояснення:** *einen Beschluss fassen* — стійка сполука. З іншими дієсловами вона не вживається.

> [!quiz] Який прийменник правильний: «Він впливає на рішення»?
> level: B2 · type: single · id: de-b2-nvv-q06
> - [ ] Er nimmt Einfluss über die Entscheidung.
> - [x] Er nimmt Einfluss auf die Entscheidung.
> - [ ] Er nimmt Einfluss an die Entscheidung.
> - [ ] Er nimmt Einfluss für die Entscheidung.
>
> **Пояснення:** *Einfluss nehmen **auf + Akk***. Прийменники *über, an, für* до цієї сполуки не належать.

> [!quiz] Які з наведених виразів є Funktionsverbgefüge? Обери всі.
> level: B2 · type: multi · id: de-b2-nvv-q07
> - [x] in Kraft treten
> - [ ] einen Brief schreiben
> - [x] zur Verfügung stehen
> - [ ] in die Schule gehen
> - [x] unter Druck stehen
>
> **Пояснення:** FVG — абстрактний іменник + «слабке» дієслово: *in Kraft treten, zur Verfügung stehen, unter Druck stehen*. *Einen Brief schreiben* і *in die Schule gehen* — звичайні словосполучення, у яких дієслово зберігає значення.

> [!quiz] Заповни пропуски: прийменник і артикль
> level: B2 · type: fill · id: de-b2-nvv-q08
>
> ```text fill
> Der Raum steht Ihnen [[zur]] Verfügung.
> Das Gesetz tritt morgen [[in]] Kraft.
> Er kommt für die Stelle nicht [[in]] Frage.
> Wir nehmen die Kosten [[in]] Kauf.
> ```
>
> **Пояснення:** *zur Verfügung* (= zu + der), *in Kraft, in Frage, in Kauf* — усі з *in* і без артикля. Форми *~~zu Verfügung~~* і *~~im Kraft~~* неправильні.

> [!quiz] Заповни пропуски: Partizip II
> level: B2 · type: fill · id: de-b2-nvv-q09
>
> ```text fill
> Sie hat eine schwere Entscheidung [[getroffen]] (treffen).
> Der Verband hat scharfe Kritik [[geübt]] (üben).
> Die Stadt hat Maßnahmen [[ergriffen]] (ergreifen).
> Das Team hat sein Können unter Beweis [[gestellt]] (stellen).
> ```
>
> **Пояснення:** *treffen → getroffen; üben → geübt; ergreifen → ergriffen (без ge-); stellen → gestellt.* Ці форми треба знати з сполукою.

> [!quiz] Склади речення: «Закон набуває чинності першого січня.»
> level: B2 · type: order · id: de-b2-nvv-q10
>
> ```text order
> Das Gesetz
> tritt
> am 1. Januar
> in Kraft.
> im Kraft ✗
> ```
>
> **Пояснення:** дієслово на другому місці, *in Kraft* — наприкінці (дужка речення). Форма *im Kraft* помилкова: сполука без артикля, *in Kraft*.

> [!quiz] Склади речення: «Команда довела свою кваліфікацію.»
> level: B2 · type: order · id: de-b2-nvv-q11
>
> ```text order
> Das Team
> hat
> sein Können
> unter Beweis
> gestellt.
> gesetzt ✗
> ```
>
> **Пояснення:** *unter Beweis stellen* → *hat gestellt*. Дієслово *setzen* (*gesetzt*) тут не пасує: *unter Beweis setzen* не вживається.

> [!quiz] Яке з речень виражає КІНЕЦЬ дії?
> level: B2 · type: single · id: de-b2-nvv-q12
> - [ ] Das Gesetz tritt am 1. Januar in Kraft.
> - [ ] Das Gesetz ist seit Jahren in Kraft.
> - [x] Die Regierung setzt die Verordnung außer Kraft.
> - [ ] Das Gesetz kommt ab Juli zur Anwendung.
>
> **Пояснення:** *außer Kraft setzen* — кінець чинності. *In Kraft treten* — початок, *in Kraft sein* — стан, *zur Anwendung kommen* — початок застосування.

> [!quiz] «Man legt ihm Betrug zur Last.» Що це означає?
> level: B2 · type: single · id: de-b2-nvv-q13
> - [x] Його звинувачують у шахрайстві.
> - [ ] Йому дають тягар обовʼязків.
> - [ ] Йому пробачили шахрайство.
> - [ ] Він сам визнав шахрайство.
>
> **Пояснення:** *jemandem etwas zur Last legen* — ставити за провину. Дієслово тут не про «покласти» вантаж.

> [!quiz] Яке речення природніше для повідомлення другові?
> level: B2 · type: single · id: de-b2-nvv-q14
> - [x] Ich habe mich entschieden, nach Berlin zu ziehen.
> - [ ] Ich habe in Erwägung gezogen, einen Umzug nach Berlin in Betracht zu nehmen.
> - [ ] Ich habe zur Kenntnis genommen, dass ich nach Berlin ziehe.
> - [ ] Ich habe den Entschluss zum Umzug zum Ausdruck gebracht.
>
> **Пояснення:** другові пишуть просто: *Ich habe mich entschieden*. Інші варіанти — канцелярські й частково нелогічні (*in Betracht zu nehmen* — змішання двох FVG).

## Фішки

> [!reel] 📜 Чотирнадцять днів до чинності
> Якщо в німецькому законі не названо дату набрання чинності, він починає діяти на чотирнадцятий день після виходу *Bundesgesetzblatt* — так сказано в статті 82 Основного закону. Тож вираз *in Kraft treten* має цілком конкретний юридичний зміст.

> [!reel] 🛗 Три дієслова, три фази
> *Stehen — stellen*, *kommen — bringen*, *sein — setzen*: ці пари працюють як «стан — спричинення»: *zur Verfügung stehen — zur Verfügung stellen*, *zur Anwendung kommen — zur Anwendung bringen*, *in Kraft sein — in Kraft setzen*. Вивчи одну пару, і другу побудуєш сам.

> [!reel] 🎯 «Вживай, але не зловживай»
> FVG типові для мови установ, законів і преси: вони звучать офіційно й точно. Для твого B2 це означає: розпізнавай їх у листах і новинах, а в усній мові частіше вживай просте дієслово.

> [!important] Підсумок
> - *Funktionsverbgefüge* = абстрактний іменник + «слабке» дієслово; значення несе іменник. Вчи сполуку цілком: *eine Entscheidung treffen, Kritik üben, in Frage kommen, zur Verfügung stehen*.
> - Склад стійкий: дієслово, прийменник, відмінок і артикль (*zur*, *in Kraft*) не міняємо; прийменник береться від іменника (*Kritik **an**, Einfluss **auf**, Stellung **zu***).
> - Дієслово показує фазу: *in Kraft treten* (початок), *in Kraft sein* (стан), *außer Kraft setzen* (кінець); пари *stehen — stellen, kommen — bringen*.
> - Калька з «робити / приймати» — головна помилка: *treffen, fassen, stellen, üben, ergreifen*, а не ~~machen / nehmen / geben~~.
> - FVG — стиль Behörde, закону, газети; у розмові з друзями краще просте дієслово.
