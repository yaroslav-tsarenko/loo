# Мовні звороти B1 — думка, згода, незгода

> [!success] Після цієї теми ти зможеш
> - висловити власну думку кількома способами: *Meiner Meinung nach…, Ich bin der Meinung, dass…, Ich finde, dass…*;
> - погодитися, частково погодитися й чемно заперечити: *Da stimme ich zu. Das stimmt nicht ganz. Das sehe ich anders.*;
> - перепитати й попросити пояснення: *Wie meinst du das? Was hältst du von…?*;
> - побудувати коротку аргументацію з «за» і «проти»: *Einerseits…, andererseits…, Ein Vorteil ist, dass…*

## Передбач

> [!quiz] Колега пропонує провести зустріч у пʼятницю. Ти не згоден і хочеш відповісти чемно. Що сказати?
> level: B1 · type: single · id: de-b1-redemittel-q01
> - [x] Das sehe ich etwas anders.
> - [ ] Das ist völliger Quatsch.
> - [ ] Ich stimme dich nicht zu.
> - [ ] Du bist falsch.
>
> **Пояснення:** *Das sehe ich anders* — нейтральна, чемна незгода; *etwas* робить її ще мʼякшою. *Quatsch* — невимушене й зневажливе слово («дурниця»). *zustimmen* вимагає Dativ (*dir*), а не ~~dich~~. *Du bist falsch* — калька з «ти неправий»; німецькою кажуть *Du hast unrecht* або *Das stimmt nicht*.

## Пояснення

### Думка, а не факт

У дискусії німці майже завжди позначають: «це моя думка». Для цього є кілька готових початків. Вони відрізняються порядком слів, і саме тут українці роблять помилки:

| Зворот | Порядок слів | Приклад |
|---|---|---|
| **Meiner Meinung nach** … | далі дієслово на **2-му** місці, перед підметом | Meiner Meinung nach ist das falsch. |
| **Ich bin der Meinung, dass** … | **dass** + дієслово в **кінці** | Ich bin der Meinung, dass das falsch ist. |
| **Ich finde, dass** … / **Ich finde,** … | з *dass* — дієслово в кінці; без *dass* — звичайний порядок | Ich finde, dass das eine gute Idee ist. / Ich finde, das ist eine gute Idee. |
| **Ich glaube / denke, dass** … | так само | Ich denke, dass das möglich ist. |
| **Ich bin davon überzeugt, dass** … | сильніше; dass-речення | Ich bin davon überzeugt, dass es funktioniert. |
| **Ich würde sagen, …** | мʼякше (Konjunktiv II) | Ich würde sagen, wir fangen früher an. |

Різниця в силі: *Ich finde* і *Ich denke* — нейтральні, *Ich bin überzeugt* — сильно, *Ich würde sagen* — обережно.

> [!tip] Meiner Meinung nach + дієслово
> Після *Meiner Meinung nach* стоїть **одна позиція** перед дієсловом, тому дієслово йде далі: *Meiner Meinung nach **ist** das falsch*, а не ~~Meiner Meinung nach das ist falsch~~. Те саме з *Erstens*, *Außerdem*, *Zum Beispiel*: після них — дієслово.

### Згода, часткова згода, незгода

Рівнів більше, ніж «так» і «ні». Шкала допомагає не звучати ні надто різко, ні надто слабко.

> [!diagram] Шкала: від повної згоди до незгоди
> ```yaml
> layout: compare
> columns: { a: "згода", b: "часткова згода", c: "незгода" }
> nodes:
>   - { id: a1, col: a, label: "сильна", text: "Genau! · Auf jeden Fall!", note: "Ich sehe das genauso.", tone: yellow }
>   - { id: a2, col: a, label: "нейтральна", text: "Da stimme ich zu.", note: "Da hast du recht. · Das sehe ich auch so.", tone: yellow }
>   - { id: b1, col: b, label: "з застереженням", text: "Das stimmt nicht ganz.", note: "Da ist etwas dran, aber …", tone: pink }
>   - { id: b2, col: b, label: "обережно", text: "Vielleicht hast du recht, aber …", note: "Ich verstehe deinen Standpunkt, aber …", tone: pink }
>   - { id: c1, col: c, label: "чемна", text: "Das sehe ich anders.", note: "Da bin ich anderer Meinung.", tone: gray }
>   - { id: c2, col: c, label: "сильна", text: "Das stimmt nicht. · Auf keinen Fall!", note: "Das überzeugt mich nicht.", tone: gray }
> steps:
>   - { focus: [a1, a2], note: "Згода: від емоційного Genau! до нейтрального Da stimme ich zu." }
>   - { focus: [b1, b2], note: "Часткова згода: визнай, що в словах співрозмовника «щось є», і додай aber." }
>   - { focus: [c1, c2], note: "Незгода: Das sehe ich anders — чемно й нейтрально. Das stimmt nicht — прямо. Auf keinen Fall — категорично." }
> ```
> Кольори тут лише розділяють три групи, значення мають слова.

> [!note] Сила слова
> У німецькій дискусії *Das stimmt nicht* зазвичай не сприймають як образу — важить зміст, а не тон. Але на роботі й з незнайомими краще починати з *Das sehe ich etwas anders* або *Vielleicht, aber…*. Те, що звучить нейтрально між друзями, на співбесіді може здатися різким.

### Розмова: запитати думку й перепитати

| Хочу… | Німецькою |
|---|---|
| спитати думку | Was hältst du von …? · Wie siehst du das? · Wie findest du …? |
| перепитати | Wie meinst du das? |
| попросити пояснити | Kannst du das bitte erklären? |
| сказати «залежить» | Das kommt darauf an. |
| підсумувати | Im Großen und Ganzen … · Zusammenfassend kann man sagen, dass … |

*halten von + Dativ*: *Was hältst du **von dem** Vorschlag?* — Що ти думаєш про пропозицію?

### Аргументація: за і проти

Коротка аргументація має простий ланцюжок: позиція → причина → приклад → ще одна сторона → висновок.

> [!diagram] Структура короткої аргументації
> ```yaml
> layout: flow
> nodes:
>   - { id: pos, label: "1. Позиція", text: "Ich finde, dass …", tone: yellow }
>   - { id: why, label: "2. Причина", text: "Ein Vorteil ist, dass …", tone: pink }
>   - { id: ex, label: "3. Приклад", text: "Zum Beispiel …", tone: pink }
>   - { id: con, label: "4. Інший бік", text: "Andererseits …", tone: gray }
>   - { id: end, label: "5. Висновок", text: "Im Großen und Ganzen …", tone: yellow }
> edges:
>   - { from: pos, to: why }
>   - { from: why, to: ex }
>   - { from: ex, to: con }
>   - { from: con, to: end }
> steps:
>   - { focus: pos, note: "Почни з позиції: Ich finde, dass Homeoffice sinnvoll ist." }
>   - { focus: [why, ex], note: "Дай причину й приклад: Ein Vorteil ist, dass man Zeit spart. Zum Beispiel braucht man keinen Weg zur Arbeit." }
>   - { focus: con, note: "Покажи й інший бік: Andererseits fehlt der Kontakt zu den Kollegen." }
>   - { focus: end, note: "Підсумуй: Im Großen und Ganzen überwiegen die Vorteile." }
> ```
> Для *Einerseits … andererseits …* головне — обидва речення мають звичайний порядок слів: *Einerseits **ist** das Auto bequem, andererseits **ist** es teuer.*

## Приклади

- Meiner Meinung nach ist das keine gute Idee. — На мою думку, це не дуже гарна ідея.
- Ich bin der Meinung, dass wir mehr Zeit brauchen. — Я вважаю, що нам потрібно більше часу.
- Ich finde, dass dieser Plan sehr gut ist. — Я вважаю, що цей план дуже хороший.
- Da stimme ich dir zu. — Тут я з тобою згоден.
- Das sehe ich auch so. — Я теж так бачу.
- Das stimmt nicht ganz. Ein Teil ist richtig. — Це не зовсім так. Частина правильна.
- Das sehe ich anders. Für mich ist die Zeit wichtiger. — Я бачу це інакше. Для мене важливіший час.
- Einerseits ist das Auto bequem, andererseits ist es teuer. — З одного боку, авто зручне, з іншого — дороге.
- Ein Vorteil ist, dass man schnell ankommt. — Перевага в тому, що швидко добираєшся.
- Was hältst du von dem Vorschlag? — Що ти думаєш про цю пропозицію?
- Wie meinst du das? Kannst du das bitte erklären? — Що ти маєш на увазі? Можеш, будь ласка, пояснити?
- Im Großen und Ganzen bin ich zufrieden. — Загалом я задоволений.

## Слова

> [!word] die Meinung
> ipa: /ˈmaɪ̯nʊŋ/ · pos: noun · level: A2 · id: de-b1-redemittel-w01
> uk: думка
> forms: die Meinungen
> example: Was ist deine **Meinung** dazu? — Яка твоя думка з цього приводу?
> note: «Висловити думку» — seine Meinung sagen / äußern. «Думати» — meinen, але не ~~eine Meinung machen~~.

> [!word] die Ansicht
> ipa: /ˈanzɪçt/ · pos: noun · level: B1 · id: de-b1-redemittel-w02
> uk: погляд, думка
> forms: die Ansichten
> example: Das ist meine persönliche **Ansicht**. — Це моя особиста думка.
> note: книжніше за Meinung. Також «вигляд» (картка з видом — die Ansichtskarte). Meiner Ansicht nach = Meiner Meinung nach.

> [!word] das Argument
> ipa: /aʁɡuˈmɛnt/ · pos: noun · level: B1 · id: de-b1-redemittel-w03
> uk: аргумент
> forms: die Argumente
> example: Das ist ein gutes **Argument**. — Це хороший аргумент.
> note: наголос на -ment. «Навести аргумент» — ein Argument nennen / anführen.

> [!word] Meiner Meinung nach…
> ipa: /ˈmaɪ̯nɐ ˈmaɪ̯nʊŋ naːx/ · pos: phrase · level: B1 · id: de-b1-redemittel-w04
> uk: на мою думку…
> example: **Meiner Meinung nach** ist das richtig. — На мою думку, це правильно.
> note: після звороту — дієслово на 2-му місці. Допустимо й nach meiner Meinung.

> [!word] Ich bin der Meinung, dass…
> ipa: /ɪç bɪn deːɐ̯ ˈmaɪ̯nʊŋ das/ · pos: phrase · level: B1 · id: de-b1-redemittel-w05
> uk: я вважаю, що…
> example: **Ich bin der Meinung, dass** wir mehr sparen sollten. — Я вважаю, що нам слід більше заощаджувати.
> note: дієслово dass-речення — в кінці. Дещо офіційніше за Ich finde.

> [!word] Ich finde, dass…
> ipa: /ɪç ˈfɪndə das/ · pos: phrase · level: A2 · id: de-b1-redemittel-w06
> uk: я вважаю, що…; мені здається…
> example: **Ich finde, dass** die Idee gut ist. — Я вважаю, що ідея хороша.
> note: без dass — звичайний порядок: Ich finde, die Idee ist gut. Питання: Wie findest du …?

> [!word] Ich glaube, dass…
> ipa: /ɪç ˈɡlaʊ̯bə das/ · pos: phrase · level: A2 · id: de-b1-redemittel-w07
> uk: я думаю, що…
> example: **Ich glaube, dass** es morgen regnet. — Я думаю, що завтра буде дощ.
> note: glauben + dass — «вважати», не про релігію. Віра в когось — glauben an + Akk.

> [!word] Ich denke, dass…
> ipa: /ɪç ˈdɛŋkə das/ · pos: phrase · level: A2 · id: de-b1-redemittel-w08
> uk: я думаю, що…
> example: **Ich denke, dass** das möglich ist. — Я думаю, що це можливо.
> note: denken, dass — «вважати»; думати про когось (згадувати) — denken an + Akk; мати думку про — denken über + Akk.

> [!word] Ich bin davon überzeugt, dass…
> ipa: /ɪç bɪn daˈfɔn yːbɐˈtsɔʏ̯kt das/ · pos: phrase · level: B1 · id: de-b1-redemittel-w09
> uk: я переконаний, що…
> example: **Ich bin davon überzeugt, dass** es funktioniert. — Я переконаний, що це спрацює.
> note: davon вказує вперед на dass-речення: überzeugt sein von.

> [!word] Meiner Erfahrung nach…
> ipa: /ˈmaɪ̯nɐ ɛɐ̯ˈfaːʁʊŋ naːx/ · pos: phrase · level: B1 · id: de-b1-redemittel-w10
> uk: з мого досвіду…
> example: **Meiner Erfahrung nach** dauert das länger. — З мого досвіду, це триває довше.
> note: корисне, коли йдеться про особистий досвід.

> [!word] Ich würde sagen, …
> ipa: /ɪç ˈvʏʁdə ˈzaːɡn̩/ · pos: phrase · level: B1 · id: de-b1-redemittel-w11
> uk: я б сказав…
> example: **Ich würde sagen,** wir treffen uns um acht. — Я б сказав, зустрічаймося о восьмій.
> note: Konjunktiv II робить думку мʼякшою (тема B1-14).

> [!word] Ich bin dafür.
> ipa: /ɪç bɪn daˈfyːɐ̯/ · pos: phrase · level: B1 · id: de-b1-redemittel-w12
> uk: я за.
> example: Sollen wir früher anfangen? — **Ich bin dafür.** — Почнемо раніше? — Я за.
> note: з dass: Ich bin dafür, dass wir früher anfangen.

> [!word] Ich bin dagegen.
> ipa: /ɪç bɪn daˈɡeːɡn̩/ · pos: phrase · level: B1 · id: de-b1-redemittel-w13
> uk: я проти.
> example: Ein neues Auto? **Ich bin dagegen.** — Нове авто? Я проти.
> note: у da-словах зазвичай наголос на другому складі: dagegen, dafür.

> [!word] Da stimme ich zu.
> ipa: /da ˈʃtɪmə ɪç tsuː/ · pos: phrase · level: B1 · id: de-b1-redemittel-w14
> uk: тут я згоден.
> example: **Da stimme ich dir zu.** — Тут я з тобою згоден.
> note: zustimmen + Dativ: Ich stimme dir zu (не ~~dich~~). Відокремлюване дієслово: zu в кінці.

> [!word] Da hast du recht.
> ipa: /da hast duː ʁɛçt/ · pos: phrase · level: A2 · id: de-b1-redemittel-w15
> uk: тут ти маєш рацію.
> example: **Da hast du recht.** Das war mein Fehler. — Тут ти маєш рацію. Це була моя помилка.
> note: recht haben (з малої). Протилежне — unrecht haben. Не ~~Du bist richtig~~.

> [!word] Das sehe ich auch so.
> ipa: /das ˈzeːə ɪç aʊ̯x zoː/ · pos: phrase · level: B1 · id: de-b1-redemittel-w16
> uk: я теж так вважаю.
> example: **Das sehe ich auch so.** — Я теж так бачу.
> note: auch so — «так само»; без заперечення означає згоду.

> [!word] Genau!
> ipa: /ɡəˈnaʊ̯/ · pos: phrase · level: A2 · id: de-b1-redemittel-w17
> uk: точно!; саме так!
> example: **Genau!** Das meine ich auch. — Саме так! Я теж так думаю.
> note: genau — також «точний»: eine genaue Uhr.

> [!word] Ich sehe das genauso.
> ipa: /ɪç ˈzeːə das ɡəˈnaʊ̯zoː/ · pos: phrase · level: B1 · id: de-b1-redemittel-w18
> uk: я бачу це так само.
> example: **Ich sehe das genauso** wie du. — Я бачу це так само, як і ти.
> note: сильніша згода, ніж Das sehe ich auch so.

> [!word] Da ist etwas dran.
> ipa: /da ɪst ˈɛtvas dʁan/ · pos: phrase · level: B1 · id: de-b1-redemittel-w19
> uk: у цьому щось є.
> example: **Da ist etwas dran,** aber nicht alles stimmt. — У цьому щось є, але не все правда.
> note: розмовна часткова згода. Також Da ist was dran.

> [!word] Auf jeden Fall!
> ipa: /aʊ̯f ˈjeːdn̩ fal/ · pos: phrase · level: A2 · id: de-b1-redemittel-w20
> uk: у будь-якому разі!; безумовно!
> example: Kommst du mit? — **Auf jeden Fall!** — Підеш з нами? — Безумовно!
> note: також в значенні «обовʼязково»: Das musst du auf jeden Fall sehen.

> [!word] Das sehe ich anders.
> ipa: /das ˈzeːə ɪç ˈandɐs/ · pos: phrase · level: B1 · id: de-b1-redemittel-w21
> uk: я бачу це інакше.
> example: **Das sehe ich anders.** Für mich ist die Qualität wichtiger. — Я бачу це інакше. Для мене якість важливіша.
> note: найчастіша чемна незгода.

> [!word] Da bin ich anderer Meinung.
> ipa: /da bɪn ɪç ˈandəʁɐ ˈmaɪ̯nʊŋ/ · pos: phrase · level: B1 · id: de-b1-redemittel-w22
> uk: тут я іншої думки.
> example: **Da bin ich anderer Meinung.** Das ist viel zu teuer. — Тут я іншої думки. Це занадто дорого.
> note: Genitiv: anderer Meinung sein. Також: der gleichen Meinung sein.

> [!word] Das stimmt nicht.
> ipa: /das ʃtɪmt nɪçt/ · pos: phrase · level: A2 · id: de-b1-redemittel-w23
> uk: це неправда.
> example: **Das stimmt nicht.** Ich war pünktlich. — Це неправда. Я прийшов вчасно.
> note: прямо, але допустимо. Мʼякше: Das stimmt nicht ganz.

> [!word] Das stimmt nicht ganz.
> ipa: /das ʃtɪmt nɪçt ɡants/ · pos: phrase · level: B1 · id: de-b1-redemittel-w24
> uk: це не зовсім так.
> example: **Das stimmt nicht ganz.** Ein Teil ist richtig. — Це не зовсім так. Частина правильна.
> note: часткова незгода — доречна на роботі.

> [!word] Da bin ich nicht sicher.
> ipa: /da bɪn ɪç nɪçt ˈzɪçɐ/ · pos: phrase · level: B1 · id: de-b1-redemittel-w25
> uk: тут я не впевнений.
> example: **Da bin ich nicht sicher.** Das müssen wir prüfen. — Тут я не впевнений. Це треба перевірити.
> note: сумнів, а не заперечення.

> [!word] Auf keinen Fall!
> ipa: /aʊ̯f ˈkaɪ̯nən fal/ · pos: phrase · level: B1 · id: de-b1-redemittel-w26
> uk: ні в якому разі!
> example: Ein Auto kaufen? **Auf keinen Fall!** — Купити авто? Ні в якому разі!
> note: категорично; keinen (Akk), як у Auf jeden Fall.

> [!word] Das überzeugt mich nicht.
> ipa: /das yːbɐˈtsɔʏ̯kt mɪç nɪçt/ · pos: phrase · level: B1 · id: de-b1-redemittel-w27
> uk: це мене не переконує.
> example: **Das überzeugt mich nicht.** Ich brauche mehr Argumente. — Це мене не переконує. Мені потрібно більше аргументів.
> note: überzeugen + Akk (mich). Наголос на -zeug-.

> [!word] Vielleicht hast du recht, aber…
> ipa: /fiˈlaɪ̯çt hast duː ʁɛçt ˈaːbɐ/ · pos: phrase · level: B1 · id: de-b1-redemittel-w28
> uk: можливо, ти маєш рацію, але…
> example: **Vielleicht hast du recht, aber** ich sehe es anders. — Можливо, ти маєш рацію, але я бачу це інакше.
> note: Aber відкриває контраргумент; після aber — звичайний порядок слів.

> [!word] Ich verstehe deinen Standpunkt, aber…
> ipa: /ɪç fɛɐ̯ˈʃteːə ˈdaɪ̯nən ˈʃtantpʊŋkt ˈaːbɐ/ · pos: phrase · level: B1 · id: de-b1-redemittel-w29
> uk: я розумію твою точку зору, але…
> example: **Ich verstehe deinen Standpunkt, aber** wir haben wenig Zeit. — Я розумію твою точку зору, але в нас мало часу.

## Вимова

Оформлюй думку інтонацією: у звичайному реченні голос падає ↘ в кінці. Перед *aber* зазвичай коротка пауза й голос тримається, а питання «так / ні» йде вгору ↗. Звуки: *ei* в *Meinung, einen, Seite* — [aɪ̯] («ай»); *-ng* в *Meinung* — один звук [ŋ], без «г»; *das* і *dass* звучать однаково [das]; їх розрізняють за позицією в реченні.

> [!speak] Скажи вголос
> level: B1 · id: de-b1-redemittel-s01
> text: Meiner Meinung nach ist das keine gute Idee.
> ipa: /ˈmaɪ̯nɐ ˈmaɪ̯nʊŋ naːx ɪst das ˈkaɪ̯nə ˈɡuːtə iˈdeː/
> tip: наголос на першому складі Mei-. Meinung: [ŋ] без [g]. Idee — наголос на кінці: «ідее».
> uk: На мою думку, це не гарна ідея.

> [!speak] Скажи вголос
> level: B1 · id: de-b1-redemittel-s02
> text: Da stimme ich dir zu.
> ipa: /da ˈʃtɪmə ɪç diːɐ̯ tsuː/
> tip: st- на початку = «шт»: «штіме». ich — [ç] (мʼяке «хь»). zu — наголошений, останній.
> uk: Тут я з тобою згоден.

> [!speak] Скажи вголос
> level: B1 · id: de-b1-redemittel-s03
> text: Das sehe ich anders.
> ipa: /das ˈzeːə ɪç ˈandɐs/
> tip: s перед голосним у sehe — дзвінке [z]. anders: наголос на an-, кінцеве -ers ≈ «ас».
> uk: Я бачу це інакше.

> [!speak] Скажи вголос
> level: B1 · id: de-b1-redemittel-s04
> text: Ich bin davon überzeugt, dass es funktioniert.
> ipa: /ɪç bɪn daˈfɔn yːbɐˈtsɔʏ̯kt das ɛs fʊŋktsi̯oˈniːɐ̯t/
> tip: überzeugt — наголос на -zeugt; eu = [ɔʏ̯] («ой»). funktionieren: наголос на -ie-, ti = [tsi̯]. Кінцеве -t оглушене.
> uk: Я переконаний, що це працює.

## Типові помилки українців

> [!pitfall] Дієслово не в кінці dass-речення
> Українською порядок вільний, а німецькою після *dass* дієслово йде в кінець: *Ich finde, dass das eine gute Idee **ist**.* Помилка: ~~Ich finde, dass das ist eine gute Idee~~. Без *dass* порядок звичайний: *Ich finde, das **ist** eine gute Idee.* Проте після *Meiner Meinung nach* дієслово стоїть одразу: *Meiner Meinung nach **ist** das falsch.*

> [!pitfall] ~~Ich stimme dich zu~~ — Dativ
> Дієслово *zustimmen* вимагає Dativ: *Ich stimme **dir** zu.* Зворот *recht haben* без Dativ: *Da hast du recht.* А *überzeugen* — Akk: *Das überzeugt **mich** nicht.* Такі керування вчи разом зі зворотом.

> [!pitfall] Ich glaube / Ich denke — не про віру й не про «думати над»
> *Ich glaube, dass …* означає «я вважаю», і нічого з релігією не повʼязано. А «вірити в когось» — *glauben an + Akk*. «Думати про когось» (згадувати) — *denken an + Akk*: *Ich denke an dich.* «Мати думку про когось» — *denken über + Akk*: *Was denkst du über ihn?* Для «вважаю» після *denke* стоїть *dass*: *Ich denke, dass …*

> [!pitfall] Різкість: Quatsch, Unsinn, Du hast unrecht
> *Das ist Quatsch* — невимушене й зневажливе, на роботі його краще не вживати. Для чемної незгоди: *Das sehe ich anders, weil …* або *Da bin ich nicht sicher.*

## Landeskunde: Diskutieren in Deutschland

> [!example] Meinung sagen und diskutieren
> Diskutieren gehört in Deutschland zum Alltag. Schon in der Schule lernen die Schüler, ihre Meinung zu begründen: Im Deutschunterricht schreiben sie eine Erörterung, in vielen Fächern halten sie ein Referat und diskutieren danach in der Klasse. Auch am Arbeitsplatz sagt man oft offen, was man denkt. Wer in einer Besprechung widerspricht, gilt meistens nicht als unhöflich, wenn er sachlich bleibt. Wichtig ist, dass man Gründe nennt. „Ich sehe das anders, weil …“ klingt besser als nur „Das ist falsch“. Viele Menschen mögen es außerdem, wenn man zuerst etwas Positives sagt: „Die Idee ist interessant, aber …“. Die Freiheit, seine Meinung zu sagen, steht in Artikel 5 des Grundgesetzes. Das heißt aber nicht, dass man alles sagen darf, denn es gibt Grenzen, zum Beispiel bei Beleidigungen. In einer Diskussion hört man deshalb aufmerksam zu und lässt den anderen ausreden. Wer aus einem anderen Land kommt, wundert sich manchmal über die Direktheit. Sie ist aber oft nicht persönlich gemeint, sondern sachlich.

> [!quiz] Nach dem Text: Wo steht die Meinungsfreiheit?

> - [ ] in der Schulordnung
> - [x] in Artikel 5 des Grundgesetzes
> - [ ] in jedem Arbeitsvertrag
>
> **Пояснення:** у тексті: *Die Freiheit, seine Meinung zu sagen, steht in Artikel 5 des Grundgesetzes.* Deutschunterricht — місце, де вчаться обґрунтовувати думку; Arbeitsvertrag у тексті не згаданий.

> - [ ] Konflikte zu vermeiden

> **Пояснення:** *Schon in der Schule lernen die Schüler, ihre Meinung zu begründen.* Тексту про те, щоб ніколи не заперечувати, немає: навпаки, у зборах заперечення — нормально, якщо тримати тон по суті.

## Практика

> [!quiz] Обери правильне речення
> level: B1 · type: single · id: de-b1-redemittel-q05
> - [x] Ich finde, dass dieser Plan sehr gut ist.
> - [ ] Ich finde, dass dieser Plan ist sehr gut.
> - [ ] Ich finde, dass ist dieser Plan sehr gut.
> - [ ] Ich finde dass sehr gut ist dieser Plan.
>
> **Пояснення:** після *dass* дієслово стоїть у кінці: *… dass dieser Plan sehr gut **ist***. Інші варіанти — порядок «як в українській».

## Фішки

> [!reel] 🔄 Чому «nach» стоїть після слова
> В *meiner Meinung nach* прийменник **nach** стоїть **після** іменника, а не перед ним, як зазвичай (*nach dem Unterricht*). Така «постпозиція» трапляється лише з небагатьма прийменниками й сталими виразами, і *meiner Meinung nach* — найвідоміший. Допустимо й *nach meiner Meinung*.

> [!reel] 🤏 Ich würde sagen: мʼяко, не жорстко
> *Ich würde sagen, …* — це Konjunktiv II у ролі «помʼякшувача». Порівняй: *Das ist falsch* — констатація; *Ich würde sagen, das ist nicht ganz richtig* — обережна оцінка. Цей прийом застосовують на зборах, у листах і на співбесідах.

> [!reel] 😬 Quatsch — не для начальника
> *Quatsch!* — невимушене слово «дурниця». Між друзями воно буває звичайним, але на роботі прозвучить зневажливо. Словник DWDS позначає його як «salopp» (невимушене) і «abwertend» (зневажливо). Для чемної форми: *Das sehe ich anders* або *Da bin ich nicht sicher*.

> [!important] Підсумок
> - Думка: *Meiner Meinung nach ist…*, *Ich bin der Meinung, dass…*, *Ich finde, dass…* — із dass дієслово в кінці.
> - Згода: *Da stimme ich dir zu / Da hast du recht / Das sehe ich auch so*; незгода: *Das sehe ich anders / Das stimmt nicht ganz*.
> - Перепитати: *Wie meinst du das? Was hältst du von…?*; залежність: *Das kommt darauf an.*
> - Аргументи: *Einerseits… andererseits…*, *Ein Vorteil / Nachteil ist, dass…*, *Im Großen und Ganzen…*
> - *zustimmen + Dativ*; *glauben dass* = «вважати»; прямоту чемно помʼякшуй (*etwas, vielleicht, Ich würde sagen*).
