# Аудіювання — лекції й конспект

> [!success] Після цієї теми ти зможеш
> - слідкувати за структурою короткої лекції за сигнальними словами (*zunächst, im Folgenden, dem stehen … gegenüber, abschließend*);
> - робити конспект (*Mitschrift*) ключовими словами та скороченнями, а не повними реченнями;
> - працювати з форматом Goethe-Zertifikat B2 Hören, зокрема Teil 4 («короткий Vortrag»: 8 завдань a / b / c, текст звучить двічі);
> - відрізнити головну тезу від прикладу та уточнення, не гублячись у деталях.

## Передбач

> [!quiz] На Goethe B2 Hören, Teil 4 ти чуєш короткий Vortrag двічі. Що найкраще зробити *до* першого прослуховування?
> level: B2 · type: single · id: de-b2-hoeren-vortraege-q01
> - [ ] нічого: слухати без підготовки, щоб не відволікатися
> - [ ] перекласти завдання на українську
> - [x] прочитати завдання 23–30: так ти знаєш, що саме слухати
> - [ ] записувати все, що чуєш, слово в слово
>
> **Пояснення:** на іспиті перед кожною частиною є час, щоб прочитати завдання (у моделі для Teil 4 — 90 секунд). Завдання вказують тему й поділ лекції: ти слухаєш цілеспрямовано. Записувати все слово в слово неможливо: думка йде швидше за руку.

## Формат модуля Hören: Goethe-Zertifikat B2

Модуль Hören триває близько 40 хвилин і складається з **чотирьох частин, 30 завдань**. Після прослуховування є 5 хвилин, щоб перенести відповіді на бланк. Словники й телефони заборонені.

| Частина | Що чуєш | Скільки разів | Завдання |
|---|---|---|---|
| Teil 1 | пʼять коротких розмов і висловлювань | один раз | 10: до кожного тексту два (Richtig / Falsch та a / b / c) |
| Teil 2 | радіоінтервʼю, наприклад із науковцем | двічі | 6, a / b / c |
| Teil 3 | радіорозмова кількох осіб | один раз | 6: «Wer sagt das?» (хто це каже) |
| Teil 4 | короткий Vortrag (лекція) | двічі | 8, a / b / c |

Завдання до лекції зазвичай йдуть **у порядку тексту**: перше запитання стосується початку, останнє — кінця. Також у моделі: 90 секунд на прочитання завдань для Teil 2 і Teil 4, 60 секунд для Teil 3.

Іспит telc Deutsch B2 має інший формат: Hörverstehen з трьох частин, близько 20 хвилин (перевір на [telc.net](https://www.telc.net/en/language-examinations/certificate-exams/german/telc-german-b2/)). Стратегії з цієї теми підходять для обох.

## Як побудована лекція

Короткий Vortrag має чотири етапи, а **сигнальні слова** (*Signalwörter*, *Redemittel*) показують, де ти зараз. Знаючи їх, ти не втрачаєш нитку, навіть коли пропустив слово.

> [!diagram] Структура лекції і сигнальні слова
> ```yaml
> layout: flow
> nodes:
>   - { id: e, label: "1 · Einleitung", text: "Thema, Gliederung", tone: yellow }
>   - { id: h, label: "2 · Hauptteil", text: "Aspekte, Beispiele", tone: pink }
>   - { id: g, label: "3 · Gegenposition", text: "Nachteile, Kritik", tone: yellow }
>   - { id: s, label: "4 · Schluss", text: "Fazit, Appell", tone: gray }
> steps:
>   - { focus: e, note: "Вступ: Ich möchte heute über … sprechen. Ich habe meinen Vortrag in drei Teile gegliedert." }
>   - { focus: h, note: "Основна частина: Zunächst … · Erstens … zweitens … · Ein weiterer Aspekt … · Beispielsweise …" }
>   - { focus: g, note: "Протиставлення: Dem stehen allerdings … gegenüber · Andererseits … · Es gibt jedoch auch Kritik …" }
>   - { focus: s, note: "Висновок: Zusammenfassend lässt sich sagen … · Abschließend möchte ich betonen … · Kurz gesagt …" }
> ```
> Кольори тут лише розділяють етапи лекції; значення мають сигнальні слова.

| Функція | Redemittel |
|---|---|
| Назвати тему | *Ich möchte heute über … sprechen. · Mein Thema lautet … · Es geht um …* |
| Оголосити план | *Ich habe meinen Vortrag in drei Teile gegliedert. · Im Folgenden zeige ich …* |
| Перша частина | *Zunächst … · Beginnen wir mit … · Erstens …* |
| Додати | *Außerdem … · Hinzu kommt … · Ein weiterer Punkt …* |
| Навести приклад | *Beispielsweise … · Das zeigt sich zum Beispiel … · Nehmen wir den Fall …* |
| Протиставити | *Dem stehen … gegenüber · allerdings · jedoch · andererseits* |
| Перехід | *Damit komme ich zu … · Ich komme nun zum zweiten Teil.* |
| Підсумувати | *Zusammenfassend lässt sich sagen … · Abschließend … · Kurz gesagt …* |

> [!warning] Після «allerdings» і «dagegen» часто міняється позиція
> Лектор спершу озвучує одну думку, а потім говорить: *Dem stehen allerdings Nachteile gegenüber.* Завдання в Teil 4 нерідко запитують саме про те, що **після** такого слова. Відповідь на питання «Що думає автор?» — часто друга думка, а не перша.

## Конспект (Mitschrift)

Конспект — це не стенограма. Ти записуєш тільки те, що потім потрібно для відповіді, і користуєшся скороченнями.

| Скорочення | Значення | Приклад |
|---|---|---|
| z. B. | zum Beispiel | z. B. Homeoffice |
| d. h. | das heißt | d. h. täglich üben |
| u. a. | unter anderem | u. a. Schlaf |
| ca. | circa, ungefähr | ca. 15 Min. |
| → | führt zu, deshalb | Stress → Fehler |
| ↑ ↓ | mehr / weniger | Kosten ↓ |
| + / − | Vorteil / Nachteil | + flexibel, − Kontakt |
| vs. | im Gegensatz zu | Büro vs. Homeoffice |

> [!diagram] Як розкласти конспект на сторінці
> ```yaml
> layout: compare
> columns: { a: "Thema", b: "Hauptpunkte", c: "Fazit" }
> nodes:
>   - { id: a1, col: a, label: "заголовок", text: "Homeoffice", note: "одне слово або фраза: про що лекція", tone: yellow }
>   - { id: b1, col: b, label: "1-й пункт", text: "+ Zeit, flexibel", note: "плюси, числа, приклади — ключові слова", tone: pink }
>   - { id: b2, col: b, label: "2-й пункт", text: "− Kontakt ↓, Grenze", note: "мінуси; стрілка показує причину й наслідок", tone: pink }
>   - { id: c1, col: c, label: "підсумок", text: "2–3 Tage Büro", note: "компроміс або висновок лектора", tone: gray }
> steps:
>   - { focus: a1, note: "Зверху — тема. Записуй її на початку, коли чуєш Mein Thema lautet…" }
>   - { focus: [b1, b2], note: "Посередині — основні пункти: плюси й мінуси, числа, імена. Скорочуй і використовуй стрілки." }
>   - { focus: c1, note: "Внизу — висновок. Його дає останній абзац: Zusammenfassend, Abschließend." }
> ```
> Кольори тут лише розділяють колонки.

> [!tip] Що писати, а що ні
> Пиши: **числа, імена, терміни, причини й наслідки, висновок.** Не пиши: слова-звʼязки (*und, aber, also*), повторення, вступні фрази. Якщо чуєш незнайоме слово, запиши його звучання кирилицею чи латиницею й іди далі.

## Приклади

- Mein Thema lautet heute: Lernen im Erwachsenenalter. — Моя тема сьогодні: навчання в дорослому віці.
- Ich habe meinen Vortrag in drei Teile gegliedert. — Я поділив свою доповідь на три частини.
- Zunächst möchte ich auf die Situation eingehen. — Спершу я хотів би розглянути ситуацію.
- Im Folgenden zeige ich Ihnen drei Methoden. — Далі я покажу вам три методи.
- Dem stehen allerdings auch Nachteile gegenüber. — Однак є й недоліки.
- Das lässt sich am Beispiel des Homeoffice zeigen. — Це можна показати на прикладі роботи з дому.
- Damit komme ich zum zweiten Teil. — Цим я переходжу до другої частини.
- Zusammenfassend lässt sich sagen, dass Wiederholung wichtig ist. — Підсумовуючи, можна сказати, що повторення важливе.
- Abschließend möchte ich betonen: Es gibt keine Lösung für alle. — На завершення хочу наголосити: єдиного рішення для всіх нема.
- Der Redner verweist auf eine aktuelle Studie. — Доповідач посилається на нове дослідження.

> note: невідокремлюване; після ver- голосний a починається з твердого приступу: ver|anschaulichen. Прикметник — anschaulich.

> [!word] anschaulich
> ipa: /ˈanʃaʊ̯lɪç/ · pos: adj · level: C1 · id: de-b2-hoeren-vortraege-w20
> uk: наочний, зрозумілий (про виклад)
> example: Sie erklärt das Thema sehr **anschaulich**. — Вона пояснює тему дуже наочно.
> note: -ich у кінці — [ɪç]. Протилежне — abstrakt, unanschaulich.

> [!word] im Folgenden
> ipa: /ɪm ˈfɔlɡn̩dn̩/ · pos: phrase · level: B2 · id: de-b2-hoeren-vortraege-w21
> uk: далі, нижче (у подальшому викладі)
> example: **Im Folgenden** stelle ich drei Methoden vor. — Далі я представлю три методи.
> note: сигнальна фраза: оголошує те, що буде нижче. Іменник Folgendes (без артикля) — «наступне»: Ich sage Folgendes: …

> [!word] abschließend
> ipa: /ˈapʃliːsn̩t/ · pos: adv · level: B2 · id: de-b2-hoeren-vortraege-w22
> uk: на завершення, насамкінець
> example: **Abschließend** möchte ich betonen: Übung macht den Meister. — На завершення хочу наголосити: практика робить майстра.

## Типові помилки українців

> [!pitfall] Записуєш усе слово в слово
> Лектор говорить швидше, ніж ти пишеш. Якщо кожне слово записувати, пропустиш наступну думку. Пиши лише ключові слова, числа, імена й причини; скорочуй (*z. B., d. h., →*). Конспект перевіряють на змісті, а не на повноті речень.

> [!pitfall] Зависаєш на одному невідомому слові
> Чуєш незнайоме *Ebbinghaus* чи *Zeitersparnis* і застрягаєш, а лектор уже в наступному пункті. Занотуй слово «як почув» і йди далі. Часто слово можна розібрати: *Zeit* + *Ersparnis* підказує сенс.

> [!pitfall] Ігноруєш сигнальні слова
> *Dem stehen allerdings … gegenüber*, *hinzu kommt*, *abschließend* — це дорожні знаки. Без них ти не знаєш, чи лектор додає, протиставляє чи підсумовує. Тому завдання «Що вважає доповідач?» часто мають відповідь після *allerdings* чи *jedoch*, а не перед ним.

> [!pitfall] Відповідаєш «за здоровим глуздом»
> Дистрактори в a / b / c майже завжди правдоподібні: «Man lernt am besten nachts» звучить цілком розумно. Але в лекції цього не сказано. Обирай те, що **прозвучало**, а не те, з чим згоден. Важливо й те, що дистрактор може повторювати слово з тексту, але змінювати його зміст.

> level: B2 · type: order · id: de-b2-hoeren-vortraege-q11
>
> ```text order
> Zunächst
> möchte
> ich
> auf
> die
> Situation
> eingehen.
> eingeht ✗
> ```
>
> **Пояснення:** після *Zunächst* стоїть дієслово *möchte*, потім підмет *ich*. Інфінітив *eingehen* — наприкінці з *auf + Akk*. *eingeht* — форма третьої особи, тут не підходить.

> [!quiz] Склади речення: «Доповідач посилається на нове дослідження»
> level: B2 · type: order · id: de-b2-hoeren-vortraege-q12
>
> ```text order
> Der
> Redner
> verweist
> auf
> eine
> aktuelle
> Studie.
> verwiesen ✗
> ```
>
> **Пояснення:** *verweisen auf + Akk*: *auf eine aktuelle Studie*. У Präsens дієслово стоїть на другому місці: *verweist*, а *verwiesen* — Partizip II.

## Фішки

> [!reel] 🏛️ Hörsaal — «зал слухання»
> Лекційну аудиторію німці називають *Hörsaal*, буквально «зал, де слухають»: *hören* + *Saal*. Той самий корінь у слові *Hörverstehen* («розуміння на слух») і в слові *der Gasthörer* — вільний слухач, який ходить на лекції без офіційного запису. Мова виділяє те, що в лекції головне — слухати.

> [!reel] ✍️ Три слова, що працюють у кожному Vortrag
> *Zunächst, außerdem, abschließend*: якщо ти памʼятаєш лише їх, то вже бачиш скелет будь-якої доповіді німецькою. На Goethe B2 Sprechen, Teil 1, від тебе теж очікують вступ, основну частину і висновок — тож ці слова корисні і при слуханні, і при говорінні.

> [!reel] ⏭️ Пропустив відповідь — не зупиняйся
> Завдання до лекції зазвичай йдуть у тому ж порядку, що й сам Vortrag. Якщо ти не встиг відповісти на питання 24, лектор уже говорить про питання 25. Залиш пропуск, зосередься на наступному й повернися до пропущеного під час другого прослуховування: текст у Teil 4 звучить двічі.

> - Goethe B2 Hören: чотири частини, 30 завдань, близько 40 хвилин; у Teil 4 — короткий Vortrag, 8 завдань a / b / c, текст звучить двічі.

> - Сигнальні слова (*zunächst, im Folgenden, dem stehen … gegenüber, abschließend*) показують структуру: вступ, основні пункти, контраргумент, висновок.
