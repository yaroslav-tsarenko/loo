# Підсумок A1 — тест рівня

> [!success] Після цієї теми ти зможеш
> - перевірити себе з усієї граматики A1: *sein, haben, Präsens, V2, Akkusativ, kein, Plural, Modalverben, Imperativ, Perfekt*;
> - розрізняти на слух числа, час і мінімальні пари (*Staat / Stadt, schon / schön*);
> - записати під диктовку німецькі речення й відповісти вголос на типові питання;
> - позначити в чеклісті «я вмію», що вже працює, а що ще варто повторити.

Це тема без нового матеріалу. Нових слів тут немає: усе, що трапляється, ти вже вивчив(ла) у темах A1-01…29. Якщо щось не виходить — поруч підказка, у якій темі це розібрано.

> [!diagram] Карта граматики A1: чотири типи речення
> ```yaml
> layout: flow
> nodes:
>   - { id: s, label: "1-ше місце", text: "Ich", tone: mint }
>   - { id: v, label: "2-ге місце · дієслово", text: "lerne", tone: orange }
>   - { id: r, label: "решта", text: "heute Deutsch.", tone: gray }
>   - { id: e, label: "кінець речення", text: "—", tone: gray }
> steps:
>   - { focus: [s, v, r], note: "Präsens (A1-07): Ich lerne heute Deutsch. Дієслово — на 2-му місці (A1-09)." }
>   - { set: { v: "muss", e: "lernen" }, focus: [v, e], note: "Модальне дієслово (A1-19): Ich muss heute Deutsch lernen. Змінюване дієслово — друге, інфінітив — у кінці." }
>   - { set: { v: "stehe", r: "um sieben Uhr", e: "auf" }, focus: [v, e], note: "Відокремлюване дієслово (A1-16): Ich stehe um sieben Uhr auf. Префікс іде в кінець." }
>   - { set: { v: "habe", r: "gestern Deutsch", e: "gelernt" }, focus: [v, e], note: "Perfekt (A1-26): Ich habe gestern Deutsch gelernt. Допоміжне дієслово — друге, Partizip II — у кінці." }
> ```
> Правило одне: **змінюване дієслово — на 2-му місці**, а все «друге» (інфінітив, префікс, Partizip) — у кінці. Це «дужка речення».

## Блок 1. Особи, числа, час

> [!quiz] Обери форму sein: «Ihr ___ pünktlich.»
> level: A1 · type: single · id: de-a1-review-q01
> - [ ] ist
> - [ ] sind
> - [x] seid
> - [ ] bist
>
> **Пояснення:** *ihr* → **seid** (*ich bin, du bist, er ist, wir sind, ihr seid*). Тема A1-03.

> [!quiz] Як ввічливо спитати незнайомого дорослого, звідки він?
> level: A1 · type: single · id: de-a1-review-q02
> - [ ] Woher kommst du?
> - [x] Woher kommen Sie?
> - [ ] Woher kommt ihr?
> - [ ] Woher kommen sie?
>
> **Пояснення:** до однієї незнайомої людини — *Sie* (з великої) + *kommen*. Тема A1-02.

> [!quiz] Яке число — «vierunddreißig»?
> level: A1 · type: single · id: de-a1-review-q03
> - [ ] 43
> - [x] 34
> - [ ] 40
> - [ ] 14
>
> **Пояснення:** одиниці перед десятками: *vier* (4) + *und* + *dreißig* (30) = 34. Тема A1-04.

> [!quiz] Скільки це: «Es ist halb drei»?
> level: A1 · type: single · id: de-a1-review-q04
> - [ ] 3:30
> - [x] 2:30
> - [ ] 3:00
> - [ ] 2:00
>
> **Пояснення:** *halb drei* = «пів на третю», тобто 2:30, а не 3:30. Тема A1-12.

> [!quiz] Яке речення про вік правильне?
> level: A1 · type: single · id: de-a1-review-q05
> - [ ] Ich habe 25 Jahre.
> - [x] Ich bin 25 Jahre alt.
> - [ ] Mir ist 25 Jahre.
> - [ ] Ich bin 25 Jahre habe.
>
> **Пояснення:** вік — через *sein*. Теми A1-04 та A1-11.

## Блок 2. Іменник: рід, множина, присвійні

> [!quiz] Який артикль у слова «Zeitung»?
> level: A1 · type: single · id: de-a1-review-q06
> - [ ] der
> - [x] die
> - [ ] das
> - [ ] den
>
> **Пояснення:** слова на **-ung** — *die* (без винятків). Тема A1-06.

> [!quiz] Які слова мають правильний артикль?
> level: A1 · type: multi · id: de-a1-review-q07
> - [x] das Mädchen
> - [x] die Freiheit
> - [ ] das Tür
> - [x] der Frühling
> - [ ] der Zeitung
>
> **Пояснення:** *das Mädchen* (-chen), *die Freiheit* (-heit), *der Frühling* (пора року). Правильно: *die Tür*, *die Zeitung*.

> [!quiz] Які форми множини правильні?
> level: A1 · type: multi · id: de-a1-review-q08
> - [x] die Kinder
> - [x] die Autos
> - [x] die Frauen
> - [ ] die Kinds
> - [ ] die Tischen
>
> **Пояснення:** *das Kind → die Kinder*, *das Auto → die Autos*, *die Frau → die Frauen*, *der Tisch → die Tische*. Тема A1-15.

> [!quiz] Заповни пропуски присвійними артиклями
> level: A1 · type: fill · bank: sein, seinen, ihre · id: de-a1-review-q09
>
> ```text fill
> Sie liebt [[ihren]] Mann.
> Er liebt [[seine]] Frau.
> Wir lieben [[unseren]] Hund.
> ```
>
> **Пояснення:** *sein / ihr* — за власником: вона → *ihr-*, він → *sein-*. *der Mann*, *der Hund* в Akkusativ → *-en*; *die Frau* → *-e*. Тема A1-21.

## Блок 3. Дієслово

> [!quiz] Яка форма правильна: «Du ___ viel.» (arbeiten)
> level: A1 · type: single · id: de-a1-review-q10
> - [ ] arbeitst
> - [x] arbeitest
> - [ ] arbeiten
> - [ ] arbeitet
>
> **Пояснення:** основа на **-t** → між основою і *-st* вставляємо **-e-**. Тема A1-07.

> [!quiz] Яка форма правильна: «Er ___ gern Brot.» (essen)
> level: A1 · type: single · id: de-a1-review-q11
> - [ ] esst
> - [ ] esset
> - [x] isst
> - [ ] essen
>
> **Пояснення:** *essen* змінює голосний **e → i** у *du isst* та *er / sie / es isst*. Тема A1-14.

> [!quiz] Заповни пропуск: «Ich ___ heute arbeiten.»
> level: A1 · type: single · id: de-a1-review-q12
> - [ ] musst
> - [x] muss
> - [ ] müssen
> - [ ] muß
>
> **Пояснення:** *ich muss* (модальне без закінчення), другий інфінітив *arbeiten* — у кінці. Тема A1-19.

> [!quiz] Що означає «Du musst nicht kommen»?
> level: A1 · type: single · id: de-a1-review-q13
> - [ ] Тобі не можна приходити.
> - [x] Тобі не потрібно приходити.
> - [ ] Ти не хочеш приходити.
> - [ ] Ти не вмієш приходити.
>
> **Пояснення:** *nicht müssen* = «не треба», а *nicht dürfen* = «не можна». Тема A1-19.

> [!quiz] Яка форма Imperativ для «du» від nehmen?
> level: A1 · type: single · id: de-a1-review-q14
> - [ ] Nehm!
> - [x] Nimm!
> - [ ] Nehmt!
> - [ ] Nehmen Sie!
>
> **Пояснення:** сильні дієслова з **e → i** зберігають зміну в Imperativ du: *Nimm den Bus!* *Nehmt* — для ihr, *Nehmen Sie* — для Sie. Тема A1-24.

> [!quiz] Обери допоміжне дієслово: «Wir ___ nach Köln gefahren.»
> level: A1 · type: single · id: de-a1-review-q15
> - [ ] haben
> - [x] sind
> - [ ] waren
> - [ ] werden
>
> **Пояснення:** дієслова руху (*fahren, gehen*) утворюють Perfekt із *sein*. Тема A1-26.

> [!quiz] Заповни пропуски Partizip II
> level: A1 · type: fill · bank: geesst, gefahrt, gearbeit · id: de-a1-review-q16
>
> ```text fill
> Gestern habe ich Pizza [[gegessen]].
> Wir sind nach Berlin [[gefahren]].
> Er hat in Köln [[gearbeitet]].
> ```
>
> **Пояснення:** *essen → gegessen*, *fahren → gefahren*, *arbeiten → gearbeitet* (з **-et**, бо основа на -t). Тема A1-26.

## Блок 4. Речення, питання, заперечення

> [!quiz] Яке речення правильне?
> level: A1 · type: single · id: de-a1-review-q17
> - [ ] Morgen ich fahre nach Wien.
> - [x] Morgen fahre ich nach Wien.
> - [ ] Ich morgen fahre nach Wien.
> - [ ] Morgen nach Wien fahre ich.
>
> **Пояснення:** дієслово — на 2-му місці (V2). Теми A1-09 та A1-16.

> [!quiz] Обери питальне слово: «___ fährst du? — Nach Wien.»
> level: A1 · type: single · id: de-a1-review-q18
> - [ ] Wo
> - [ ] Woher
> - [x] Wohin
> - [ ] Wann
>
> **Пояснення:** *nach Wien* — відповідь про напрям руху → *wohin*. Тема A1-09.

> [!quiz] Відповідь на «Hast du keine Zeit?», якщо час є
> level: A1 · type: single · id: de-a1-review-q19
> - [ ] Ja, ich habe Zeit.
> - [x] Doch, ich habe Zeit.
> - [ ] Nein, ich habe Zeit.
> - [ ] Doch, ich habe keine Zeit.
>
> **Пояснення:** на заперечне питання «так, навпаки» кажуть *doch*. Тема A1-09.

> [!quiz] Яке речення правильне?
> level: A1 · type: single · id: de-a1-review-q20
> - [ ] Ich habe ein Bruder.
> - [x] Ich habe einen Bruder.
> - [ ] Ich habe eine Bruder.
> - [ ] Ich habe Bruder.
>
> **Пояснення:** *der Bruder* в Akkusativ → *einen*. Тема A1-11.

> [!quiz] Які речення із запереченням правильні?
> level: A1 · type: multi · id: de-a1-review-q21
> - [x] Ich arbeite nicht.
> - [x] Ich habe keinen Hund.
> - [ ] Ich habe nicht Hund.
> - [x] Das Auto ist nicht neu.
> - [ ] Ich habe kein Zeit.
>
> **Пояснення:** *nicht* — для дієслова й прикметника, *kein-* — для іменника (*keinen Hund*, *keine Zeit*). Тема A1-11.

> [!quiz] Заповни пропуски: den, einen, keine
> level: A1 · type: fill · bank: ein, der, kein · id: de-a1-review-q22
>
> ```text fill
> Ich brauche [[einen]] Stift.
> Siehst du [[den]] Mann?
> Sie hat [[keine]] Zeit.
> ```
>
> **Пояснення:** *der Stift* → *einen*; *der Mann* → *den*; *die Zeit* → *keine*. Теми A1-11 та A1-14.

> [!quiz] Заповни пропуски прийменниками
> level: A1 · type: fill · bank: in, an, auf · id: de-a1-review-q23
>
> ```text fill
> Ich stehe [[um]] sieben Uhr auf.
> [[Am]] Montag arbeite ich.
> [[Im]] Mai fahre ich nach Wien.
> ```
>
> **Пояснення:** година → *um*, день → *am*, місяць → *im*. Тема A1-25.

> [!quiz] Що правильно: «Я пʼю чай радше, ніж каву»?
> level: A1 · type: single · id: de-a1-review-q24
> - [ ] Ich trinke gern Tee als Kaffee.
> - [x] Ich trinke lieber Tee als Kaffee.
> - [ ] Ich trinke am liebsten Tee als Kaffee.
> - [ ] Ich trinke mehr Tee gern.
>
> **Пояснення:** порівняння «радше» — *lieber … als*. *gern* — просто «охоче», *am liebsten* — «найохочіше». Тема A1-27.

## Блок 5. Вимова

> [!quiz] Як читається кінцева буква в слові «Hund»?
> level: A1 · type: single · id: de-a1-review-q25
> - [ ] [d]
> - [x] [t]
> - [ ] [g]
> - [ ] [n]
>
> **Пояснення:** дзвінкий приголосний у кінці слова оглушується: *Hund* [hʊnt], а множина *Hunde* — знову [d]. Тема A1-23.

> [!quiz] Які пари слів розрізняються довжиною голосного?
> level: A1 · type: multi · id: de-a1-review-q26
> - [x] Staat / Stadt
> - [x] Miete / Mitte
> - [ ] Wein / Wien
> - [x] Ofen / offen
> - [ ] schon / schön
>
> **Пояснення:** *Staat* [ʃtaːt] — *Stadt* [ʃtat], *Miete* [iː] — *Mitte* [ɪ], *Ofen* [oː] — *offen* [ɔ]. *Wein / Wien* — різні дифтонги, *schon / schön* — різні голосні (o / ö). Теми A1-05 і A1-10.

## Блок 6. Складіть речення

> [!quiz] Склади речення: «Вчора я їв піцу»
> level: A1 · type: order · id: de-a1-review-q27
>
> ```text order
> Gestern
> habe
> ich
> Pizza
> gegessen.
> bin ✗
> ```
>
> **Пояснення:** Perfekt: *Gestern* (1-ше) + *habe* (2-ге) + підмет + додаток + Partizip у кінці. *bin* — для руху. Тема A1-26.

> [!quiz] Склади речення: «Я сьогодні мушу працювати»
> level: A1 · type: order · id: de-a1-review-q28
>
> ```text order
> Ich
> muss
> heute
> arbeiten.
> arbeite ✗
> ```
>
> **Пояснення:** модальне дієслово — 2-ге, інфінітив — у кінці. Тема A1-19.

> [!quiz] Склади речення: «Я встаю о сьомій»
> level: A1 · type: order · id: de-a1-review-q29
>
> ```text order
> Ich
> stehe
> um
> sieben
> Uhr
> auf.
> aufstehe ✗
> ```
>
> **Пояснення:** відокремлюване дієслово: *stehe … auf*, префікс — у кінці. Тема A1-16.

> [!quiz] Склади вказівку: «Йдіть прямо!»
> level: A1 · type: order · id: de-a1-review-q30
>
> ```text order
> Gehen
> Sie
> geradeaus!
> Geh ✗
> ```
>
> **Пояснення:** Imperativ ввічливої форми: дієслово + *Sie*. *Geh* — форма для *du*. Тема A1-24.

## Мінімальні пари

> [!pair] Staat /ʃtaːt/ — Stadt /ʃtat/
> level: A1 · id: de-a1-review-p01
> say: Stadt
> tip: Staat — довге [aː], Stadt — коротке [a].

> [!pair] Miete /ˈmiːtə/ — Mitte /ˈmɪtə/
> level: A1 · id: de-a1-review-p02
> say: Mitte
> tip: ie — довге [iː], подвоєне tt — перед ним голосний короткий [ɪ].

> [!pair] schon /ʃoːn/ — schön /ʃøːn/
> level: A1 · id: de-a1-review-p03
> say: schön
> tip: ö — губи «о», язик «е». Не «йо».

> [!pair] Wein /vaɪ̯n/ — Wien /viːn/
> level: A1 · id: de-a1-review-p04
> say: Wien
> tip: ei = «ай», ie = довге «і».

> [!pair] Bett /bɛt/ — Beet /beːt/
> level: A1 · id: de-a1-review-p05
> say: Beet
> tip: Bett — коротке [ɛ], Beet — довге [eː] (подвійна голосна).

## Говоріння

> [!speak] Скажи вголос
> level: A1 · speed: slow · id: de-a1-review-s01
> text: Ich komme aus der Ukraine und wohne in Köln.

> [!speak] Скажи вголос

## Типові помилки, які ще трапляються

> [!pitfall] Український порядок слів
> ~~Heute ich lerne~~, ~~Ich kann schwimmen gut~~, ~~Ich rufe an dich~~ — це три різні помилки з однієї причини: українська мова вільна, німецька — ні. Змінюване дієслово **завжди на 2-му місці**, а інфінітив / префікс / Partizip — **у кінці**: *Heute lerne ich. Ich kann gut schwimmen. Ich rufe dich an.*

> [!pitfall] Забуті артиклі й Akkusativ
> ~~Ich habe Auto~~, ~~Ich habe ein Bruder~~, ~~Ich habe nicht Zeit~~ → *Ich habe **ein** Auto. Ich habe **einen** Bruder. Ich habe **keine** Zeit.* Навіть коли ти знаєш правило, перевіряй три речі: чи є артикль, чи це чоловічий рід у додатку, чи правильно вибрано *kein / nicht*.

> [!pitfall] Калькований вік, холод і «йти»
> ~~Ich habe 20 Jahre~~ → *Ich bin 20.* ~~Ich habe kalt~~ → *Mir ist kalt.* ~~Ich gehe mit dem Bus~~ → *Ich **fahre** mit dem Bus.* Так само ~~sein Mann~~ про жінку → *ihr Mann*.

> [!pitfall] du чи Sie і великі літери
> В установі, в лікаря, у шефа — **Sie** з великої: *Wie heißen Sie? Wie geht es Ihnen?* Іменники — завжди з великої: *die Tür, das Essen, am Montag*. Прикметник національності — з малої: *ukrainisch*.

## Чекліст «я вмію»

Познач, що вже виходить. Незнайомі пункти — повтори відповідні теми.

**Вимова та алфавіт (A1-01, 05, 10, 17, 23)**
- [ ] Я можу назвати літери німецького алфавіту й продиктувати своє імʼя та email.
- [ ] Я розрізняю довгі й короткі голосні (*Staat / Stadt*) та вимовляю ü, ö, ei, eu, au.
- [ ] Я вимовляю ich-Laut [ç], ach-Laut [x], горлове r і не читаю h як «г».
- [ ] Я читаю кінцеві *b, d, g* глухо (*Hund*, *Tag*) і sp-, st- як «шп», «шт».

**Слова й ситуації (A1-02, 04, 08, 12, 18, 20, 22, 24, 27)**
- [ ] Я вітаюся, прощаюся й знайомлюся, розрізняю *du* і *Sie*.
- [ ] Я рахую до 100, кажу вік і номер телефону.
- [ ] Я кажу час, день, місяць і дату.
- [ ] Я замовляю в кафе, питаю ціну в магазині, питаю дорогу.
- [ ] Я розповідаю про сімʼю, квартиру, хобі й погоду простими реченнями.

**Граматика (A1-03, 06, 07, 09, 11, 14, 15, 16, 19, 21, 24, 25, 26, 27)**
- [ ] Я відмінюю *sein*, *haben*, правильні дієслова й дієслова з чергуванням (*fahren, essen*).
- [ ] Я знаю три роди й артиклі та вчу іменники з артиклем і множиною.
- [ ] Я ставлю дієслово на 2-ге місце й будую питання; відповідаю *doch* на заперечне питання.
- [ ] Я розрізняю Nominativ і Akkusativ (*der → den, ein → einen*) і заперечую через *kein / nicht*.
- [ ] Я будую речення з модальними дієсловами, відокремлюваними дієсловами, Imperativ, Perfekt.
- [ ] Я користуюся прийменниками *am, um, im, von … bis* та присвійними *mein, dein, sein, ihr*.

**Аудіювання, читання, письмо (A1-13, 28, 29)**
- [ ] Я розумію короткі діалоги, числа, час і ціни на слух.
- [ ] Я читаю вивіски й оголошення та заповнюю формуляр.
- [ ] Я пишу коротку записку на ≈ 30 слів із привітанням і прощанням.

Якщо ти позначив(ла) більшість пунктів і набрав(ла) ≈ 80 % у тесті вище, ти готовий(а) до рівня A2.

## Фішки

> [!reel] 🫏 Eselsbrücke — «ослячий місток»
> Німецька «шпаргалка для памʼяті» називається *Eselsbrücke* — буквально «ослячий міст». За словником DWDS, слово відоме з XVI століття і означає «спрощену підпору для памʼяті». Для A1 такі містки: *ie — довге і, doch — «навпаки», den — лише чоловічий рід*.

> [!reel] 📘 Twain про дієслово в кінці
> Марк Твен написав про німецьку мову жартівливе есе «The Awful German Language» (додаток до книги *A Tramp Abroad*, 1880), де скаржиться на дієслово в кінці речення. Тобі це вже не страшно: на A1 ти знаєш дужку речення — інфінітив, префікс і Partizip у кінці.

> [!reel] 🎓 Що далі: A2
> На A2 ти додаси Dativ (*mit dem Bus, mir ist kalt*), придаткові речення (*weil, dass*), більше минулого й порівняння прикметників. Основа — те, що ти щойно повторив(ла): рід, відмінок і порядок слів.

> [!important] Підсумок
> - Змінюване дієслово — **на 2-му місці**, друга частина (інфінітив, префікс, Partizip) — **у кінці**.
> - Рід, множину й артикль вчимо разом зі словом; Akkusativ змінює лише чоловічий рід.
> - *kein* — для іменників, *nicht* — для решти; *doch* — «навпаки, так».
> - Вік — через *sein*, час доби — *um / am / im*, минуле розмовне — Perfekt.
> - Якщо тест виконано на ≈ 80 % — переходь до A2; решту повтори за номерами тем.
