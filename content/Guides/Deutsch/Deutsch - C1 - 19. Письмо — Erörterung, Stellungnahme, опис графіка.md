# Письмо — Erörterung, Stellungnahme, опис графіка

> [!success] Після цієї теми ти зможеш
> - назвати формат письма на **Goethe-Zertifikat C1** (допис на форумі ≈ 230 слів + e-mail ≈ 120 слів, 75 хв), **telc Deutsch C1 Hochschule** (Erörterung / Stellungnahme від 350 слів, 70 хв) і **TestDaF** (аргументативний текст від 200 слів + підсумок тексту й графіка ≈ 100–150 слів);
> - побудувати **лінійну** й **діалектичну** Erörterung і чітко відрізнити її від **Stellungnahme**;
> - описати графік чи таблицю: тип, джерело, головна тенденція, деталі, висновок — без помилок *Prozent / Prozentpunkt*;
> - звʼязати текст на рівні C1: тези, обмеження, зважування аргументів, власна позиція.

## Передбач

> [!quiz] Частка людей, які працюють удома, зросла з 10 % до 15 %. Яке речення правильне?
> level: C1 · type: single · id: de-c1-schreiben-q01
> - [ ] Der Anteil ist um 5 Prozent gestiegen.
> - [x] Der Anteil ist um 5 Prozentpunkte gestiegen.
> - [ ] Der Anteil ist auf 5 Prozentpunkte gestiegen.
> - [ ] Der Anteil hat sich verdoppelt.
>
> **Пояснення:** різниця між двома відсотками — це **Prozentpunkte**: 15 − 10 = 5 Prozentpunkte. У відсотках зростання становить 50 % (5 від 10). *Um 5 Prozent* — типова помилка в описі графіка, *auf* означає кінцеве значення (*auf 15 Prozent*), а «подвоїлася» — було б 20 %.

Goethe оцінює, **наскільки точно опрацьовано змістові пункти**, **коректність** і **звʼязність** речень та абзаців. Пропустиш пункт — втратиш бали за виконання завдання, навіть якщо мова бездоганна. Для DSH (частина *Textproduktion*) кожен університет складає власне завдання, але типи ті самі: аргументація й опис даних.

### Erörterung і Stellungnahme: у чому різниця

| | **Erörterung** | **Stellungnahme** |
|---|---|---|
| питання | відкрите: *Sollte …? Ist … sinnvoll?* | конкретна теза, цитата чи рішення |
| мета | зважити аргументи й дійти висновку | висловити й обґрунтувати **власну** позицію |
| будова | аргументи «за» і «проти» → висновок | позиція → обґрунтування → відповідь на контраргумент → висновок |
| тон | виважений, позицію видно в кінці | позицію видно з першого абзацу |
| ключові звороти | *einerseits … andererseits, wägt man … ab, im Ergebnis* | *Ich vertrete die Auffassung, dass … · Dem ist entgegenzuhalten, dass …* |

**Лінійна Erörterung** розглядає лише один бік (наприклад, тільки причини явища), аргументи йдуть від слабшого до найсильнішого. **Діалектична (Pro-und-Kontra-)Erörterung** розглядає обидва боки й закінчується зваженим висновком. На іспитах майже завжди очікують діалектичну.

> [!diagram] Діалектична Erörterung: порядок «сендвіч»
> ```yaml
> layout: flow
> nodes:
>   - { id: e, label: "1 · Einleitung", text: "Anlass + Leitfrage", note: "актуальність, без позиції", tone: yellow }
>   - { id: g, label: "2 · Gegenseite", text: "Argumente, die du NICHT teilst", note: "від сильного до слабкого", tone: gray }
>   - { id: u, label: "3 · Überleitung", text: "Dem ist jedoch entgegenzuhalten …", note: "поворот", tone: pink }
>   - { id: p, label: "4 · eigene Seite", text: "deine Argumente", note: "від слабшого до найсильнішого", tone: yellow }
>   - { id: f, label: "5 · Fazit", text: "Abwägung + eigene Position", note: "можливо, компроміс", tone: pink }
> edges:
>   - { from: e, to: g }
>   - { from: g, to: u }
>   - { from: u, to: p }
>   - { from: p, to: f }
> steps:
>   - { focus: e, note: "Вступ: чому тема актуальна і яке питання ти розглядаєш. Наприклад: In vielen Städten wird darüber diskutiert, ob … Es stellt sich die Frage, ob …" }
>   - { focus: g, note: "Спершу — аргументи протилежної сторони, від сильного до слабкого. Так читач бачить, що ти розумієш опонента." }
>   - { focus: u, note: "Явний поворот: Dem ist jedoch entgegenzuhalten, dass … / Diese Argumente greifen allerdings zu kurz." }
>   - { focus: p, note: "Власні аргументи — від слабшого до найсильнішого: останній аргумент запамʼятовується найкраще." }
>   - { focus: f, note: "Висновок: зважування (Wägt man die Argumente ab, …) і позиція. Нових аргументів тут уже не додають." }
> ```
> Блоки розрізнено номером і назвою; кольори лише чергуються, щоб відділити сусідні кроки.

### Аргумент на рівні C1

На B2 вистачало моделі «теза — пояснення — приклад». На C1 до неї додають **обмеження** й **зважування**:

| Крок | Звороти C1 | Приклад |
|---|---|---|
| теза | *Ein gewichtiges Argument für … ist … · Hinzu kommt, dass …* | *Ein gewichtiges Argument für das Homeoffice ist die Zeitersparnis.* |
| пояснення | *Dies liegt vor allem daran, dass … · Ausschlaggebend ist dabei, dass …* | *Ausschlaggebend ist dabei, dass Pendelzeiten entfallen.* |
| приклад / дані | *Dies belegen Zahlen des Statistischen Bundesamtes … · Exemplarisch sei … genannt.* | *Exemplarisch sei die Region München genannt.* |
| обмеження | *Dies gilt allerdings nur, sofern … · Einschränkend muss man sagen, dass …* | *Einschränkend muss man sagen, dass nicht jeder Beruf dafür geeignet ist.* |
| зважування | *Wägt man die Argumente gegeneinander ab, so … · Unterm Strich überwiegen …* | *Unterm Strich überwiegen aus meiner Sicht die Vorteile.* |

> [!tip] Звʼязність замість «по-перше, по-друге»
> *Erstens … zweitens … drittens* — зрозуміло, але механічно. На C1 краще: *Zunächst … Hinzu kommt … Schwerer wiegt jedoch … Nicht zuletzt …* А відсилання на попереднє речення (*Dieser Umstand …, Letzteres …*) — з теми [[Deutsch - C1 - 08. Звʼязність тексту — конектори, відсилання, wobei]].

### Опис графіка: пʼять кроків

> [!diagram] Grafikbeschreibung: від загального до деталей
> ```yaml
> layout: flow
> nodes:
>   - { id: a, label: "1 · Thema & Quelle", text: "Das Schaubild zeigt … laut …", note: "тип, джерело, рік", tone: yellow }
>   - { id: b, label: "2 · Einheit", text: "in Prozent / in Millionen", note: "що на осях", tone: pink }
>   - { id: c, label: "3 · Haupttendenz", text: "Insgesamt ist … gestiegen", note: "одне речення", tone: yellow }
>   - { id: d, label: "4 · Details", text: "Höchststand, Tiefststand, Ausreißer", note: "2–3 числа, не всі", tone: pink }
>   - { id: e, label: "5 · Fazit", text: "Daraus lässt sich schließen …", note: "обережно, без вигадок", tone: gray }
> edges:
>   - { from: a, to: b }
>   - { from: b, to: c }
>   - { from: c, to: d }
>   - { from: d, to: e }
> steps:
>   - { focus: a, note: "Тип графіка, тема, джерело й час: Das Säulendiagramm zeigt, wie sich … zwischen 2015 und 2025 entwickelt hat. Die Daten stammen vom Statistischen Bundesamt." }
>   - { focus: b, note: "Одиниці: Die Angaben erfolgen in Prozent / in Tausend. Без цього читач не зрозуміє чисел." }
>   - { focus: c, note: "Головна тенденція одним реченням: Insgesamt ist die Zahl kontinuierlich gestiegen." }
>   - { focus: d, note: "Деталі: найвищий і найнижчий пункт, різкі зміни. Не переписуй усі числа — обирай важливі." }
>   - { focus: e, note: "Висновок лише з даних: Daraus lässt sich schließen, dass … Причин, яких немає в графіку, не вигадуй — або познач як припущення (vermutlich, möglicherweise)." }
> ```
> Пʼять кроків пронумеровано; кольори лише розділяють сусідні блоки.

| Функція | Звороти |
|---|---|
| вступ | *Das Schaubild / Das Säulendiagramm / Die Tabelle zeigt / veranschaulicht … · Die Daten stammen aus …* |
| зростання | *steigen, ansteigen, zunehmen, sich verdoppeln · ein Anstieg / Zuwachs um … · einen Höchststand erreichen* |
| спад | *sinken, zurückgehen, abnehmen, sich halbieren · ein Rückgang um … · rückläufig sein · einen Tiefststand erreichen* |
| без змін | *stagnieren, gleich bleiben, konstant bleiben, schwanken (zwischen … und …)* |
| сила зміни | *geringfügig, leicht – deutlich, erheblich – sprunghaft, kontinuierlich* |
| порівняння | *im Vergleich zu …, gegenüber dem Vorjahr, während …, wohingegen …* |
| частки | *knapp die Hälfte, mehr als ein Drittel, der Anteil liegt bei …, jeder vierte Befragte* |

**Прийменники — головна пастка:** *um* — на скільки (*um 5 Prozentpunkte*), *auf* — до якого рівня (*auf 15 Prozent*), *von … auf …* — від і до (*von 10 auf 15 Prozent*), *bei* — рівень (*Der Anteil liegt bei 15 Prozent*).

### Зразок 1: допис на форумі (Goethe C1, Teil 1, ≈ 230 слів)

Завдання (власне, у форматі іспиту): *Ein Tag Homeoffice pro Woche für alle?* Поясни, від чого залежить, чи підходить робота вдома; аргументуй на прикладі однієї професії; назви аргументи проти; запропонуй альтернативу.

> [!example] Diskussionsbeitrag: Homeoffice für alle?
> Kaum ein Thema hat die Arbeitswelt in den letzten Jahren so verändert wie das Homeoffice. Ob ein fester Tag zu Hause für alle sinnvoll ist, hängt allerdings vor allem von der Art der Tätigkeit ab: Wer überwiegend am Computer arbeitet und sich gut selbst organisieren kann, profitiert in der Regel davon.
>
> Exemplarisch sei die Arbeit in der Buchhaltung genannt. Hier fallen viele Aufgaben an, die konzentriertes Arbeiten erfordern. Zu Hause entfallen nicht nur Pendelzeiten, sondern auch Störungen durch Telefonate im Großraumbüro. Ausschlaggebend ist dabei, dass die Ergebnisse leicht überprüfbar sind.
>
> Dennoch gibt es gewichtige Gegenargumente. Zum einen leidet der informelle Austausch: Viele Ideen entstehen eher zufällig in der Kaffeeküche als in geplanten Videokonferenzen. Zum anderen fällt es manchen Beschäftigten schwer, Arbeit und Freizeit zu trennen. Nicht zuletzt lässt sich ein solcher Tag in Pflege, Handwerk oder Einzelhandel schlicht nicht umsetzen: Eine Krankenschwester kann ihre Patienten nicht per Video versorgen, und auch im Verkauf braucht man Kundschaft vor Ort. Eine Pauschalregel wäre deshalb ungerecht.
>
> Statt einer starren Vorgabe halte ich ein flexibles Modell für sinnvoller: Teams vereinbaren selbst, an welchen Tagen alle vor Ort sind, und für Berufe ohne Homeoffice-Möglichkeit könnte es einen Ausgleich geben, etwa flexiblere Arbeitszeiten.
>
> Unterm Strich überwiegen für Büroberufe aus meiner Sicht die Vorteile, eine Pflicht für alle lehne ich jedoch ab.

Розбір: усі чотири пункти завдання є (критерії → *hängt … ab*; приклад → *Exemplarisch sei … genannt*; проти → *Dennoch gibt es gewichtige Gegenargumente*; альтернатива → *Statt einer starren Vorgabe …*). Абзаци = пункти, позиція чітка в кінці, звʼязки різні (*allerdings, dabei, zum einen … zum anderen, nicht zuletzt, unterm Strich*).

### Зразок 2: підсумок тексту й графіка (TestDaF, Aufgabe 2, ≈ 120 слів)

> [!example] Zusammenfassung: Fahrradnutzung in einer Großstadt
> Der Text und das Liniendiagramm beschäftigen sich mit der Fahrradnutzung in einer deutschen Großstadt. Das Diagramm zeigt den Anteil der Wege, die mit dem Rad zurückgelegt wurden, zwischen 2016 und 2024. Insgesamt ist dieser Anteil deutlich gestiegen, und zwar von 12 auf 19 Prozent, also um 7 Prozentpunkte. Während er bis 2019 nur geringfügig zunahm, verzeichnete die Stadt 2020 einen sprunghaften Anstieg. Danach stagnierte der Wert auf hohem Niveau. Der Text nennt als mögliche Ursache neue Radwege, weist jedoch darauf hin, dass der Ausbau in den Außenbezirken rückläufig ist. Daraus lässt sich schließen, dass weiteres Wachstum vor allem von der Infrastruktur am Stadtrand abhängt.

Розбір: тема й тип графіка → одиниці → головна тенденція (*Insgesamt … deutlich gestiegen*) → деталі (*geringfügig, sprunghaft, stagnierte*) → звʼязок із текстом → обережний висновок. Числа вигадані для тренування.

## Приклади

- *Es stellt sich die Frage, ob ein Tempolimit auf Autobahnen sinnvoll ist.* — Постає питання, чи доцільне обмеження швидкості на автобанах.
- *Ein gewichtiges Argument dafür ist die Verkehrssicherheit.* — Вагомий аргумент на користь цього — безпека руху.
- *Dem ist jedoch entgegenzuhalten, dass die Kosten erheblich wären.* — Цьому, однак, можна заперечити, що витрати були б значними.
- *Einschränkend muss man sagen, dass die Daten nur eine Stadt betreffen.* — Слід зробити застереження: дані стосуються лише одного міста.
- *Wägt man die Argumente gegeneinander ab, überwiegen die Vorteile.* — Якщо зважити аргументи, переважають переваги.
- *Das Säulendiagramm veranschaulicht die Entwicklung der Mieten seit 2015.* — Стовпчикова діаграма показує, як змінювалися орендні ціни з 2015 року.
- *Die Zahl der Befragten, die täglich lesen, ist um 8 Prozentpunkte zurückgegangen.* — Кількість опитаних, які читають щодня, зменшилася на 8 відсоткових пунктів.
- *Im Jahr 2020 erreichte der Wert seinen Tiefststand.* — У 2020 році показник досяг найнижчого рівня.
- *Die Preise schwankten zwischen 1,50 und 2,10 Euro.* — Ціни коливалися між 1,50 і 2,10 євро.
- *Die Zahl der Anmeldungen hat sich innerhalb von fünf Jahren verdoppelt.* — За пʼять років кількість реєстрацій подвоїлася.
- *Der Anteil liegt bei knapp einem Drittel.* — Частка становить майже третину.

## Типові помилки українців

> [!pitfall] Prozent замість Prozentpunkte і плутанина um / auf
> ~~Der Anteil ist um 5 Prozent gestiegen~~ (з 10 % до 15 %) → **um 5 Prozentpunkte** (або *um 50 Prozent*). ~~Die Zahl stieg um 15 Prozent~~ (маючи на увазі кінцевий рівень) → **auf 15 Prozent**. *um* — різниця, *auf* — новий рівень, *bei* — поточний рівень (*Der Anteil liegt bei 15 Prozent*).

> [!pitfall] «Вигадані» причини в описі графіка
> Графік показує **що**, а не **чому**. ~~Die Zahl stieg, weil die Menschen umweltbewusster wurden~~ — якщо цього немає в джерелі, це домисел. Пиши обережно: *Ein möglicher Grund könnte … sein* або бери причину з тексту, який додано до графіка (TestDaF, Aufgabe 2).

> [!pitfall] Stellungnahme без позиції або Erörterung, де позиція з першого речення
> У *Stellungnahme* позиція потрібна відразу: *Ich vertrete die Auffassung, dass …* У діалектичній *Erörterung* вступ лише ставить питання (*Es stellt sich die Frage, ob …*), а позиція зʼявляється у висновку. Учні часто пишуть «середнє»: позицію в першому реченні й потім рівноважні аргументи без висновку.

> [!pitfall] Кальки з українського есе
> ~~In meinem Aufsatz möchte ich betrachten~~ → *Im Folgenden möchte ich erörtern / untersuchen, ob …*; ~~Auf meinen Blick~~ → **Aus meiner Sicht**; ~~Man muss sagen, dass~~ на початку кожного абзацу → різні вступи (*Hinzu kommt …, Schwerer wiegt …*). І ніякої «води» про важливість теми «в сучасному світі»: німецький оцінювач чекає на перший аргумент у другому абзаці.

> audio: A: Also soll ich meine Meinung erst am Ende sagen?
> audio: B: Genau. In der Einleitung nur die Frage, im Fazit Ihre Abwägung und Ihre Position.
> - [x] Прибрати позицію зі вступу й залишити її для висновку.
> - [ ] Додати позицію ще й у кожен абзац.
> - [ ] Переписати текст як Stellungnahme з трьома позиціями.
> - [ ] Скоротити висновок до одного слова.
>

Переклад: — Я маю написати Erörterung. Мій вступ нормальний? — Ви вже в першому реченні пишете, що ви за. Це більше пасує до Stellungnahme. — Тобто свою думку казати лише в кінці? — Саме так. У вступі — лише питання, у висновку — ваше зважування і ваша позиція.

## Landeskunde: Studieren — und zwar meistens in der Nähe

> [!example] Studieren — und zwar meistens in der Nähe
> Wer in Deutschland ein Studium beginnt, zieht dafür oft nicht weit weg. Das zeigt eine Auswertung des Statistischen Bundesamtes (Destatis), die im Oktober 2026 zum Start des Wintersemesters veröffentlicht wurde. Untersucht wurde, ob Studienanfängerinnen und -anfänger in dem Bundesland studieren, in dem sie ihre Hochschulreife erworben haben.
>
> Das zentrale Ergebnis lässt sich in einem Satz zusammenfassen: Im Wintersemester 2025/26 blieben 69 Prozent der Erstsemester zum Studium im eigenen Bundesland. Gut zwei Drittel entschieden sich also gegen einen Umzug in ein anderes Land. Der höchste Wert wurde in Nordrhein-Westfalen verzeichnet: Dort blieben 82 Prozent der Studienanfänger nach dem Abitur im Land. Ausschlaggebend dürfte das breite Angebot sein, denn das bevölkerungsreichste Bundesland hat besonders viele Hochschulstandorte. Destatis nennt als weitere Gründe die Attraktivität der Lebensumstände und die räumliche Nähe.
>
> Wer das Bundesland doch wechselt, geht häufig in ein benachbartes Land. So kamen 17 Prozent der Personen, die im Wintersemester 2025/26 in Hamburg ein Studium aufnahmen, aus Schleswig-Holstein und weitere 16 Prozent aus Niedersachsen. Einen Sonderfall bildet Thüringen: Dort ist eine große private Hochschule ansässig, die vor allem Fernstudiengänge anbietet. Wer sich dort einschreibt, muss also nicht nach Thüringen ziehen, was die Zahlen für dieses Land verzerrt.
>
> Betrachtet man die Herkunft der rund 308 000 Erstsemester mit deutscher Hochschulzugangsberechtigung, so hatte ein Viertel die Hochschulreife in Nordrhein-Westfalen erworben. Es folgen Baden-Württemberg mit 14 und Bayern mit 11 Prozent. Studierende, die ihre Zugangsberechtigung im Ausland erworben haben, sind in diesen Werten nicht enthalten.
>
> Für das Schreiben auf C1-Niveau ist ein solcher Bericht ein gutes Modell. Er nennt zuerst Quelle und Thema, dann die Haupttendenz, danach ausgewählte Details und schließlich mögliche Ursachen. Dabei unterscheidet er sorgfältig zwischen Daten und Deutung: Was die Zahlen zeigen, wird als Tatsache formuliert, mögliche Gründe werden vorsichtiger ausgedrückt. Genau diese Trennung erwarten Prüferinnen und Prüfer auch in einer Grafikbeschreibung beim TestDaF oder bei der DSH. Hilfreich sind dabei Formulierungen wie „Dies dürfte vor allem daran liegen, dass …“ oder „Eine mögliche Erklärung wäre …“. Sie zeigen, dass man eine Vermutung äußert, ohne sie als gesicherte Erkenntnis auszugeben. Ebenso wichtig ist, Einschränkungen der Daten zu nennen, etwa, wer in einer Statistik nicht erfasst ist. Wer nur Zahlen aneinanderreiht, beschreibt; wer die wichtigsten auswählt und vorsichtig deutet, argumentiert.

> [!quiz] Nach dem Text: Welche Aussage gibt das Hauptergebnis richtig wieder?
> level: C1 · type: single · id: de-c1-schreiben-q02
> - [ ] Die meisten Erstsemester ziehen für das Studium in ein weit entferntes Bundesland.
> - [x] Gut zwei Drittel der Erstsemester studieren in dem Land, in dem sie die Hochschulreife erworben haben.
> - [ ] In allen Bundesländern bleiben 82 Prozent der Erstsemester im eigenen Land.
> - [ ] Der Anteil ist gegenüber dem Vorjahr um 69 Prozentpunkte gestiegen.
>
> **Пояснення:** 69 % — це *gut zwei Drittel*, які лишаються у своїй землі. 82 % — лише Nordrhein-Westfalen. Порівняння з попереднім роком у тексті немає, тож останній варіант — вигадана тенденція.

> level: C1 · type: single · id: de-c1-schreiben-q03
> - [ ] Dort gibt es keine Hochschulen.
> - [x] Eine dort ansässige Hochschule bietet vor allem Fernstudiengänge an, sodass man nicht umziehen muss.
> - [ ] Alle Studierenden dort kommen aus dem Ausland.
> - [ ] Dort ist das Studium besonders teuer.
>
> **Пояснення:** у тексті: *eine große private Hochschule …, die vor allem Fernstudiengänge anbietet. Wer sich dort einschreibt, muss also nicht nach Thüringen ziehen.* Тому цифри для цієї землі *verzerrt* — спотворені.

> [!quiz] Nach dem Text: Wie trennt ein guter Bericht Daten und Deutung? Wähle alle richtigen Aussagen.
> level: C1 · type: multi · id: de-c1-schreiben-q04
> - [x] Was die Zahlen zeigen, wird als Tatsache formuliert.
> - [x] Mögliche Gründe werden vorsichtiger ausgedrückt.
> - [ ] Ursachen werden immer als sicher dargestellt.
> - [ ] Man sollte möglichst alle Zahlen nennen.
>
> **Пояснення:** *Was die Zahlen zeigen, wird als Tatsache formuliert, mögliche Gründe werden vorsichtiger ausgedrückt.* Перелічувати всі числа текст якраз не радить: *wer die wichtigsten auswählt …, argumentiert.* Помітно це й у самому тексті: *Ausschlaggebend dürfte … sein* — *dürfte* позначає припущення.

## Практика

> [!quiz] Що правда про Goethe-Zertifikat C1, модуль Schreiben? Обери всі.
> level: C1 · type: multi · id: de-c1-schreiben-q05
> - [x] Модуль триває 75 хвилин і має дві частини.
> - [x] У Teil 1 пишуть допис для онлайн-форуму приблизно на 230 слів.
> - [x] У Teil 2 пишуть (напів)формальне повідомлення приблизно на 120 слів.
> - [ ] Обидві частини — формальні листи по 200 слів.
> - [ ] Треба описати графік.
>
> **Пояснення:** за чинним *Modellsatz*: Teil 1 — *Diskussionsbeitrag* ≈ 230 слів (рекомендовано 50 хв), Teil 2 — e-mail ≈ 120 слів (25 хв). Графік описують на TestDaF, а не на Goethe C1.

> [!quiz] Який мінімальний обсяг тексту в telc Deutsch C1 Hochschule (Schriftlicher Ausdruck)?
> level: C1 · type: single · id: de-c1-schreiben-q06
> - [ ] ≈ 120 слів
> - [ ] ≈ 230 слів
> - [x] щонайменше 350 слів
> - [ ] 100–150 слів
>
> **Пояснення:** за *Handbuch* telc C1 Hochschule — одне завдання з двох (*Erörterung, Stellungnahme* тощо), *mindestens 350 Wörter*, 70 хвилин. 120 і 230 слів — Goethe C1, 100–150 — TestDaF, Aufgabe 2.

> [!quiz] Упорядкуй частини діалектичної Erörterung (модель «сендвіч»).
> level: C1 · type: order · id: de-c1-schreiben-q07
>
> ```text order
> Einleitung mit Leitfrage
> Argumente der Gegenseite
> Überleitung: Dem ist jedoch entgegenzuhalten …
> eigene Argumente, das stärkste zuletzt
> Fazit mit Abwägung und Position
> Grußformel ✗
> ```
>
> **Пояснення:** вступ → чужі аргументи → поворот → власні аргументи (найсильніший останнім) → висновок. *Grußformel* — частина листа, а не Erörterung.

> [!quiz] Заповни пропуски: прийменники в описі графіка
> level: C1 · type: fill · bank: zu, an · id: de-c1-schreiben-q08
>
> ```text fill
> Der Anteil stieg [[von]] 12 [[auf]] 19 Prozent.
> Das ist ein Anstieg [[um]] 7 Prozentpunkte.
> Heute liegt der Wert [[bei]] 19 Prozent.
> ```
>
> **Пояснення:** *von … auf …* — від і до; *um* — величина зміни; *liegen bei* — поточний рівень. *zu* і *an* у цих позиціях (*steigen von … auf / um*) не вживають (не ~~steigen zu~~).

> [!quiz] Заповни пропуски: дієслова зміни
> level: C1 · type: fill · bank: verdreifacht, gestiegen · id: de-c1-schreiben-q09
>
> ```text fill
> Von 40 auf 20 Euro: Der Preis hat sich [[halbiert]].
> Von 3 auf 6 Millionen: Die Zahl hat sich [[verdoppelt]].
> Zehn Jahre lang immer 25 Prozent: Der Wert ist [[gleich geblieben|konstant geblieben|stabil geblieben]].
> ```
>
> **Пояснення:** 40 → 20 — *sich halbieren*; 3 → 6 — *sich verdoppeln*; без змін — *gleich / konstant bleiben* (Perfekt із *sein*). *Verdreifacht* не підходить до жодного рядка (потроєння), а *gestiegen* не поєднується з *hat sich*.

> [!quiz] Яке формулювання найкраще для висновку з графіка, якщо причин у джерелі немає?
> level: C1 · type: single · id: de-c1-schreiben-q10
> - [ ] Die Zahl stieg, weil alle Menschen umweltbewusster geworden sind.
> - [x] Ein möglicher Grund für den Anstieg könnte das höhere Umweltbewusstsein sein.
> - [ ] Es ist sicher, dass Umweltbewusstsein der einzige Grund ist.
> - [ ] Über Gründe darf man in einer Grafikbeschreibung nie sprechen.
>
> **Пояснення:** причину, якої немає в даних, подаємо як **припущення**: *Ein möglicher Grund könnte … sein*. Перший і третій варіанти видають домисел за факт. Четвертий — надто категоричний: обережне припущення в кінці доречне.

> [!quiz] Яке речення — типовий вступ до Stellungnahme (а не до Erörterung)?
> level: C1 · type: single · id: de-c1-schreiben-q11
> - [ ] Es stellt sich die Frage, ob Studiengebühren sinnvoll sind.
> - [x] Ich vertrete die Auffassung, dass Studiengebühren abgeschafft werden sollten.
> - [ ] Im Folgenden werden Pro- und Kontra-Argumente zu Studiengebühren abgewogen.
> - [ ] Studiengebühren werden in vielen Ländern kontrovers diskutiert.
>
> **Пояснення:** *Stellungnahme* відкриває **власна позиція**: *Ich vertrete die Auffassung, dass …* Решта варіантів — нейтральні вступи до Erörterung: питання, план, актуальність.

> [!quiz] Склади речення: «Цьому, однак, можна заперечити, що витрати були б значними.»
> level: C1 · type: order · id: de-c1-schreiben-q12
>
> ```text order
> Dem ist
> jedoch
> entgegenzuhalten,
> dass die Kosten
> erheblich wären.
> zu entgegenhalten ✗
> ```
>
> **Пояснення:** *sein + zu + Infinitiv*: у відокремлюваному дієслові *zu* стоїть усередині — *entgegen**zu**halten*. Тому *zu entgegenhalten* — помилка. У підрядному з *dass* дієслово *wären* — у кінці.

> [!quiz] Обери всі звороти, які доречні для зважування аргументів у висновку.
> level: C1 · type: multi · id: de-c1-schreiben-q13
> - [x] Wägt man die Argumente gegeneinander ab, so …
> - [x] Unterm Strich überwiegen aus meiner Sicht …
> - [x] Alles in allem halte ich … für sinnvoll.
> - [ ] Ein weiteres neues Argument ist …
> - [ ] Sehr geehrte Damen und Herren,
>
> **Пояснення:** у *Fazit* підсумовують і зважують: *Wägt man … ab*, *Unterm Strich*, *Alles in allem*. Нових аргументів у висновку не додають, а звертання *Sehr geehrte …* належить до листа.

> [!quiz] Яке речення описує графік: 2019 — 30 %, 2020 — 45 %, 2021–2024 — 45–46 %?
> level: C1 · type: single · id: de-c1-schreiben-q14
> - [ ] Der Anteil ist kontinuierlich gesunken.
> - [x] Nach einem sprunghaften Anstieg 2020 stagnierte der Anteil.
> - [ ] Der Anteil hat sich jedes Jahr verdoppelt.
> - [ ] Der Anteil schwankte stark zwischen 30 und 45 Prozent.
>
> **Пояснення:** 30 → 45 % за рік — *sprunghafter Anstieg*, далі 45–46 % — практично без змін, тобто *stagnieren*. Подвоєння не було, а *schwanken* означає рух угору й униз, якого тут немає.

## Фішки

> [!reel] ⚖️ Чому Erörterung закінчується найсильнішим аргументом
> У німецькій шкільній традиції аргументи ставлять «за зростанням ваги»: читач краще запамʼятовує те, що прочитав останнім. Тому найсильніший аргумент — перед *Fazit*, а найслабший — на початку своєї частини. Те саме з аргументами опонента, але в зворотному порядку: від сильного до слабкого, щоб перейти до свого.

> [!reel] 📊 Prozent і Prozentpunkt
> Частка виросла з 2 % до 3 %? Це **+1 Prozentpunkt**, але **+50 Prozent**. Обидва речення правдиві, і в новинах обирають те, що звучить ефектніше. Хто пише опис графіка на іспиті, мусить розрізняти ці поняття, інакше припуститься фактичної помилки.

> [!reel] ✍️ Schreibzentrum
> У багатьох німецьких університетах є *Schreibzentrum* — центр письма, де тьютори безкоштовно консультують студентів щодо курсових (*Hausarbeit*) і рефератів. Вони не виправляють помилки замість тебе, а показують, як покращити структуру й аргументацію. Пошукай на сайті свого вишу.

> [!important] Підсумок
> - **Формати:** Goethe C1 — допис ≈ 230 + e-mail ≈ 120 слів за 75 хв; telc C1 Hochschule — Erörterung / Stellungnahme ≥ 350 слів за 70 хв; TestDaF — аргументативний текст ≥ 200 слів + підсумок тексту й графіка 100–150 слів.
> - **Erörterung** зважує обидва боки (позиція — у висновку), **Stellungnahme** обстоює власну позицію з першого абзацу.
> - **Аргумент C1:** теза → пояснення → приклад / дані → обмеження → зважування; найсильніший аргумент — останнім.
> - **Графік:** тема й джерело → одиниці → головна тенденція → 2–3 деталі → обережний висновок. *um* — різниця, *auf* — новий рівень, *bei* — рівень; **Prozentpunkte** ≠ Prozent.
> - Причини, яких немає в даних, — лише як припущення: *Ein möglicher Grund könnte … sein*.
