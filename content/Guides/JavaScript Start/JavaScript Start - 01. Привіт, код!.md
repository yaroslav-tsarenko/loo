# Привіт, код!

> [!success] 🎯 Після цього розділу ти зможеш
> - пояснити своїми словами, що таке програма і що робить JavaScript;
> - запустити свій перший рядок коду в консолі браузера, у Node.js або в онлайн-пісочниці;
> - вивести будь-що на екран через `console.log`;
> - залишати коментарі для себе й «вимикати» рядки коду;
> - спокійно прочитати червоне повідомлення про помилку і знайти, де вона.

## 🤔 Передбач

Ще нічого не читай — просто спробуй вгадати. Помилитися тут не страшно, а навіть корисно: мозок краще запам'ятовує відповідь, коли спершу «спіткнувся».

> [!quiz] Що виведе код?
> level: junior · type: output · id: jss-01-quiz-01
>
> ```js
> console.log('2 + 2')
> console.log(2 + 2)
> ```
>
> **Відповідь:** `2 + 2` `4`
>
> **Пояснення:** у лапках — це **текст**, і JavaScript друкує його буква в букву: `2 + 2`. Без лапок — це **вираз**, який JavaScript спершу обчислює, а потім друкує результат: `4`. Лапки — ніби табличка «не чіпай, просто покажи».

## 🧒 Простими словами

Програма — це **рецепт**, а комп'ютер — дуже старанний, але зовсім не кмітливий кухар. Він виконує кроки **по черзі, згори донизу, буквально**. Напишеш «посоли» замість «посолити трохи» — посолить усю пачку. Пропустиш крок — не здогадається сам.

JavaScript — одна з мов, якою ми пишемо такі рецепти. Головна суперсила: він уже живе **в кожному браузері**. Тобі не треба нічого встановлювати, щоб почати, — відкрий будь-яку сторінку, і кухня готова.

## 🔬 Як це працює

### 🧾 Що таке програма

Програма — це текст, складений із **інструкцій** (їх ще називають *statements*). Комп'ютер читає їх по одній, згори донизу:

```js
console.log('Крок 1: закип\'ятити воду')
console.log('Крок 2: кинути макарони')
console.log('Крок 3: чекати 10 хвилин')
```

Кожен рядок тут — окрема інструкція «надрукуй це». Порядок важливий: переставиш рядки — зміниться і результат.

```text
  твій код (текст)          рушій JavaScript             результат
 ┌──────────────────┐      ┌──────────────────┐      ┌──────────────┐
 │ console.log(...) │ ───► │ читає рядок за   │ ───► │ текст у      │
 │ console.log(...) │      │ рядком і виконує │      │ консолі      │
 └──────────────────┘      └──────────────────┘      └──────────────┘
```

Програму, яка «читає й виконує» JavaScript, називають **рушієм** (*engine*). У Chrome і Node.js це V8, у Firefox — SpiderMonkey, у Safari — JavaScriptCore. Як саме рушій це робить, детально розібрано в [[JavaScript - 01. Як JS виконує код]] — але туди варто йти після цього курсу.

> - [ ] Спершу найважливіші, потім решту
> - [x] По черзі, згори донизу
> - [ ] Усі одночасно
> - [ ] Знизу догори
>
> **Пояснення:** звичайний код виконується послідовно — рядок за рядком, згори донизу. Пізніше ти побачиш винятки (умови, цикли, функції), але вони лише **керують** цим порядком, а не скасовують його.

### 🖥️ Де запускати JavaScript

Є три зручні місця — обери будь-яке.

| Де | Як відкрити | Коли зручно |
|---|---|---|
| **Консоль браузера** (DevTools) | Chrome/Edge: `F12` або `Ctrl+Shift+J` (Mac: `Cmd+Option+J`) → вкладка **Console** | спробувати один-два рядки просто зараз |
| **Node.js** | встанови з nodejs.org, створи файл `hello.js`, у терміналі: `node hello.js` | писати програми у файлах, без браузера |
| **Онлайн-пісочниця** | CodePen, JSFiddle, StackBlitz — відкрив сайт і пишеш | поділитися кодом з другом чи ментором |

Найшвидший старт — консоль. Відкрий її просто зараз на цій сторінці, введи рядок і натисни `Enter`:

> [!figure] devtools-console
> scenario: hello-console
>
> Консоль виконує рядок одразу після `Enter` і друкує результат під ним.

> [!tip] Сіра стрілочка `undefined` — це нормально
> Після `console.log('Привіт')` консоль покаже `Привіт`, а під ним — сіре `undefined`. Це не помилка: консоль завжди показує ще й **результат** самої інструкції, а `console.log` нічого не повертає. Просто ігноруй.

### 📢 console.log — твій перший інструмент

`console.log(...)` друкує в консоль те, що ти передав у дужках. Це головний спосіб «подивитися всередину» програми — ним користуються і новачки, і сеньйори.

```js
console.log('Привіт, світ!') // → Привіт, світ!
console.log(42)              // → 42
console.log(10 * 3)          // → 30
console.log('Мені', 25, 'років') // → Мені 25 років
```

Розберемо по шматочках:

```text
console . log ( 'Привіт' )
───┬───   ─┬─   ────┬───
   │       │        └── що надрукувати (в дужках)
   │       └── дія «надрукувати» (log = «записати в журнал»)
   └── об'єкт «консоль» — місце, куди пишемо
```

- **Текст** (рядок, *string*) береться в лапки: `'одинарні'`, `"подвійні"` — обидва варіанти працюють, головне, щоб відкривна й закривна були однакові.
- **Числа** пишуться без лапок: `42`, `3.14`.
- Кілька значень через кому — надрукуються через пробіл.

### 💬 Коментарі — нотатки для людей

Коментар — це текст, який рушій **повністю ігнорує**. Він для тебе і твоїх колег.

```js
// Однорядковий коментар: усе після // до кінця рядка
console.log('Видно') // коментар може стояти і після коду

/*
  Багаторядковий коментар:
  усе між відкривною і закривною позначками ігнорується
*/

// console.log('Не видно') ← цей рядок «вимкнено»
```

Два головні застосування:

1. **Пояснити «чому»**. Не «тут ми додаємо 1» (це й так видно), а «додаємо 1, бо люди рахують з одиниці, а не з нуля».
2. **Тимчасово вимкнути рядок**, не видаляючи його. У більшості редакторів: виділи рядок і натисни `Ctrl+/` (Mac: `Cmd+/`).

> [!quiz] Що виведе код?
> level: junior · type: output · id: jss-01-quiz-06
>
> ```js
> // console.log('A')
> console.log('B') // console.log('C')
> /* console.log('D') */
> ```
>
> **Відповідь:** `B`
>
> **Пояснення:** рядок з `A` повністю закоментований. Після `console.log('B')` усе від `//` — коментар, тож `C` не виконується. `D` усередині `/* */`. Лишається тільки `B`.

> [!quiz] Заповни пропуски: зроби обидва рядки коментарями
> level: junior · type: fill · id: jss-01-quiz-07
>
> ```js fill
> [[//]] Однорядковий коментар
> /* Багаторядковий
>    коментар [[*/]]
> ```
>
> **Пояснення:** `//` — до кінця рядка; `/*` відкриває, а `*/` закриває багаторядковий коментар.

### 🚨 Помилки — це нормально

Ти **будеш** бачити червоні повідомлення. Щодня. Навіть через десять років. Помилка — це не вирок, а **підказка від рушія**: «ось тут я не зрозумів».

```text
Uncaught SyntaxError: Invalid or unexpected token     ← ЩО сталося
    at hello.js:3:13                                  ← ДЕ: файл:рядок:символ
```

Як читати помилку за 3 кроки:

1. **Тип помилки** — перше слово: `SyntaxError` (написано «не по граматиці»: забута лапка чи дужка), `ReferenceError` (звертаєшся до чогось, чого не існує — часто одруківка), `TypeError` (робиш з значенням те, чого воно не вміє).
2. **Повідомлення** — після двокрапки. Скопіюй і загугли, якщо незрозуміло.
3. **Місце** — номер рядка. Йди туди й дивись на рядок **і на рядок вище** (часто проблема там).

```js
consol.log('Привіт') // ReferenceError: consol is not defined — одруківка!
```

> - [ ] У змінній неправильне значення
>
> **Пояснення:** `SyntaxError` — рушій навіть не зміг прочитати код, бо він порушує правила мови. Шукай незакриті лапки, дужки й зайві символи в зазначеному рядку.

## ⚠️ Пастки

> [!pitfall] Різні лапки на початку і в кінці
> Відкрив `'`, а закрив `"` — рушій шукає закривну `'` до кінця рядка і не знаходить.
>
> ```text
> console.log('Привіт")  ❌ SyntaxError
> console.log('Привіт')  ✅
> ```

> [!pitfall] Апостроф усередині одинарних лапок
> Українське «п'ять» містить апостроф, і він «закриває» рядок раніше. Візьми подвійні лапки або екрануй апостроф зворотною скісною `\`.
>
> ```js
> console.log("п'ять") // → п'ять
> console.log('п\'ять') // → п'ять
> ```

> [!pitfall] Розумні лапки з Word чи Telegram
> Скопіював код із месенджера, а там `‘криві’` або `«ялинки»`? Для JavaScript це не лапки. Набирай код у редакторі коду, а не в текстовому редакторі.

## ⚡ Фішки

> [!reel] 🕰️ JavaScript написали за 10 днів
> У 1995 році Брендан Айк створив перший прототип мови для браузера Netscape приблизно за 10 днів. Назву «JavaScript» обрали з маркетингових причин — з Java у неї майже нічого спільного.

> [!reel] 🌍 Консоль є в кожному браузері
> Натисни `F12` на будь-якому сайті — і в тебе повноцінне середовище для JavaScript. Ніяких установок: компілятор, редактор і «пісочниця» вже вбудовані.

> [!reel] 🔠 console ≠ Console
> JavaScript розрізняє регістр літер. `console.log` працює, `Console.log` — `ReferenceError`. Одна з найчастіших помилок новачків.

> [!reel] 🧯 Помилка — це підказка, а не вирок
> Червоний текст каже три речі: **що** сталося (тип), **чому** (повідомлення) і **де** (файл:рядок). Читай знизу вгору — і ти вже на пів дороги до виправлення.

> [!reel] 💬 Найкращий коментар пояснює «чому»
> `// додаємо 1` — шум. `// +1, бо місяці в Date рахуються з нуля` — золото. Код показує «що», коментар — «навіщо».

## 🛠️ Практика

Задачі виконуються прямо в апці: пишеш код — натискаєш «Запустити» — тести кажуть, чи вийшло. Не лякайся слова `function` у заготовках: це просто «коробочка», яка **повертає** (`return`) значення. Детально про функції — у [[JavaScript Start - 06. Функції]]. Поки що змінюй лише те, що просить умова.

> [!task] Привіт, світ!
> level: junior · difficulty: easy · id: jss-01-task-01 · tags: basics, strings
>
> Зроби так, щоб функція `hello()` повертала рядок `'Привіт, світ!'` — саме з комою і знаком оклику.
>
> ```js starter
> function hello() {
>   return '' // впиши текст між лапками
> }
> ```
>
> ```js tests
> test('повертає привітання', () => { expect(hello()).toBe('Привіт, світ!') })
> test('це рядок', () => { expect(typeof hello()).toBe('string') })
> ```
>
> > [!hint]- Підказка 1
> > Текст має бути **між** двома одинарними лапками: `'...'`.
>
> > [!hint]- Підказка 2
> > Перевір кожен символ: кома після «Привіт», пробіл, знак оклику в кінці.
>
> > [!solution]- Рішення
> > ```js
> > function hello() {
> >   return 'Привіт, світ!'
> > }
> > ```
> >
> > Тести порівнюють рядки посимвольно, тож навіть зайвий пробіл — це вже інший рядок.

> [!task] Полагодь лапку
> level: junior · difficulty: easy · id: jss-01-task-02 · tags: errors, strings
>
> Цей код падає з `SyntaxError`. Знайди й виправ помилку, щоб `motto()` повертала `'Я вчу JavaScript'`.
>
> ```js starter
> function motto() {
>   return 'Я вчу JavaScript
> }
> ```
>
> ```js tests
> test('повертає девіз', () => { expect(motto()).toBe('Я вчу JavaScript') })
> ```
>
> > [!hint]- Підказка 1
> > Натисни «Запустити» і прочитай помилку: який рядок вона називає?
>
> > [!hint]- Підказка 2
> > Рядок відкрито лапкою `'`, а де закривна?
>
> > [!solution]- Рішення
> > ```js
> > function motto() {
> >   return 'Я вчу JavaScript'
> > }
> > ```
> >
> > Рушій бачив відкривну лапку і шукав закривну до кінця рядка — не знайшов, тому `SyntaxError`.

> [!task] Хвилини в добі
> level: junior · difficulty: easy · id: jss-01-task-03 · tags: numbers, basics
>
> Нехай JavaScript порахує за тебе: функція `minutesInDay()` має повертати кількість хвилин у добі. Не рахуй у голові — напиши **вираз** із множенням `*`.
>
> ```js starter
> function minutesInDay() {
>   return 0 // заміни 0 на вираз: годин у добі * хвилин у годині
> }
> ```
>
> ```js tests
> test('у добі 1440 хвилин', () => { expect(minutesInDay()).toBe(1440) })
> test('повертає число, а не текст', () => { expect(typeof minutesInDay()).toBe('number') })
> ```
>
> > [!hint]- Підказка 1
> > У добі 24 години, у годині 60 хвилин.
>
> > [!hint]- Підказка 2
> > Не бери вираз у лапки — інакше вийде текст `'24 * 60'`, а не число.
>
> > [!solution]- Рішення
> > ```js
> > function minutesInDay() {
> >   return 24 * 60
> > }
> > ```
> >
> > `24 * 60` без лапок — вираз, рушій обчислює його в `1440`. З лапками це був би рядок.

> [!task] Вимкни зайвий рядок коментарем
> level: junior · difficulty: easy · id: jss-01-task-04 · tags: comments
>
> Функція `answer()` має повертати число `42`, але перший `return` спрацьовує раніше. **Не видаляй** рядок — закоментуй його.
>
> ```js starter
> function answer() {
>   return 'ще не знаю' // закоментуй цей рядок
>   return 42
> }
> ```
>
> ```js tests
> test('повертає 42', () => { expect(answer()).toBe(42) })
> ```
>
> > [!hint]- Підказка 1
> > `return` завершує функцію одразу — до другого рядка справа не доходить.
>
> > [!hint]- Підказка 2
> > Постав `//` на самому початку першого рядка з `return`.
>
> > [!solution]- Рішення
> > ```js
> > function answer() {
> >   // return 'ще не знаю'
> >   return 42
> > }
> > ```
> >
> > Закоментований рядок рушій пропускає, і першим виконується `return 42`. Так зручно «вимикати» код під час експериментів.

> [!important] Підсумок
> - Програма — це інструкції, які рушій виконує по черзі, згори донизу, буквально.
> - JavaScript можна запустити в консолі браузера (`F12`), у Node.js (`node файл.js`) або в онлайн-пісочниці.
> - `console.log(...)` друкує значення; текст пишемо в лапках, числа й вирази — без.
> - `//` і `/* */` — коментарі: рушій їх ігнорує, вони для людей і для «вимикання» рядків.
> - Помилка = тип + повідомлення + місце. Читай її спокійно — це підказка, а не вирок.
