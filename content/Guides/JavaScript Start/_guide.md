# JavaScript: старт з нуля

Цей курс — для тих, хто **ніколи не писав код**. Не треба знати математику, англійську чи «як працює комп'ютер». Потрібні лише браузер, 20–40 хвилин на розділ і готовність помилятися (це частина навчання, чесно).

## Як працювати з курсом

1. **🤔 Передбач** — кожен розділ починається з питання, на яке ти ще не знаєш відповіді. Вгадуй сміливо: спроба до пояснення допомагає запам'ятати краще.
2. **📖 Читай маленькими шматками** — аналогія з життя, потім код. Кожен приклад запускай у консолі браузера (`F12`) — так знання переходять із голови в пальці.
3. **✅ Перевір себе** — після кожної секції короткий тест: обрати відповідь, скласти код зі шматків або заповнити пропуски. Не підглядай угору.
4. **🛠️ Практика з автотестами** — 4–5 задач від крихітних до трохи більших. Пишеш код → тиснеш «Запустити тести» → бачиш, що вийшло. Підказки відкривай по одній і лише після власної спроби.
5. **🧠 Картки** — потрапляють у розклад повторень. Повертайся до них щодня по 5 хвилин — це працює краще, ніж годину раз на тиждень.

Проходь розділи **по порядку**: кожен спирається на попередні. Застряг — перечитай секцію, відкрий підказку або загляни в [[JavaScript Start - 10. Як думати як програміст|розділ 10]] про те, як шукати допомогу.
