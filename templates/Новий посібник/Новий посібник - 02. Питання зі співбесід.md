# Новий посібник - 02. Питання зі співбесід

## 🟢 Junior

> [!question]- Що таке замикання?
> *дуже часто · теорія* · `new-02-001`
>
> Функція разом із лексичним оточенням, у якому її створили.
>
> ```js
> function counter() {
>   let n = 0
>   return () => ++n
> }
> ```

## 🟡 Middle

> [!question]- Чим `Promise.all` відрізняється від `Promise.allSettled`?
> *часто · порівняння* · `new-02-002`
>
> `all` відхиляється на першій помилці, `allSettled` завжди чекає всі проміси і повертає статуси.

## 🔴 Senior

> [!question]- Як знайти memory leak у Node.js?
> *іноді · практика* · `new-02-003`
>
> Порівняти heap snapshots під навантаженням, шукати ростучі retained-обʼєкти.

## 🟣 Tech Lead

> [!question]- Як ви впроваджуєте код-рев'ю стандарти в команді?
> *рідко · практика* · `new-02-004`
>
> Домовленості письмово, автоматизація (lint, format), чекліст рев'ю, приклади.
