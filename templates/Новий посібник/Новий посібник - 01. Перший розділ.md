> [!quiz] Що виведе код?
> level: middle · type: output · id: new-01-quiz-03
>
> ```js
> console.log(1)
> setTimeout(() => console.log(2))
> Promise.resolve().then(() => console.log(3))

>

> [!quiz] Склади функцію `sum`, що додає всі аргументи
> level: junior · type: order · id: new-01-quiz-04
>
> ```js order
> function sum(...nums) {
>   let total = 0
>   for (const n of nums) {
>     total += n
>   }
>   return total
> }
> return nums.length // ✗
> ```
>
> **Пояснення:** rest-параметр збирає аргументи в масив; зайвий `return` до циклу обірвав би функцію.

> [!quiz] Заповни пропуски, щоб `once` працював
> level: junior · type: fill · bank: const, false · id: new-01-quiz-05
>
> ```js fill
> function once(fn) {
>   [[let|var]] called = false
>   return function (...args) {
>     if ([[called]]) return
>     called = [[true]]
>     return fn.apply(this, args)
>   }
> }
> ```
>
> **Пояснення:** прапорець живе в замиканні й переживає виклики обгортки.

## Задача

> [!task] Реалізуй `once`
> level: middle · difficulty: easy · id: new-01-task-01 · tags: closures
>
> Функція `once(fn)` повертає обгортку, яка викликає `fn` лише першого разу, а далі повертає збережений результат.
>
> > [!hint]- Підказка 1
> > Результат треба десь зберегти між викликами.
>
> > [!hint]- Підказка 2
> > Замикання + прапорець `called`.
>
> > [!solution]- Еталонне рішення
> > ```js
> > function once(fn) {
> >   let called = false
> >   let result
> >   return function (...args) {
> >     if (!called) {
> >       called = true
> >       result = fn.apply(this, args)
> >     }
> >     return result
> >   }
> > }
> > ```

> [!task] Реалізуй `debounce`
> level: middle · difficulty: medium · id: new-01-task-02 · tags: timers, closures
>
> `debounce(fn, ms)` повертає обгортку, яка викликає `fn` лише через `ms` мс після **останнього** виклику — з останніми аргументами.
>
> ```js starter
> function debounce(fn, ms) {
>   // твій код
> }
> ```
>
> ```js tests
> test('викликає один раз після паузи', () => {
>   vi.useFakeTimers()
>   const spy = vi.fn()
>   const run = debounce(spy, 100)
>   run(1)
>   run(2)
>   vi.advanceTimersByTime(99)
>   expect(spy).toHaveBeenCalledTimes(0)
>   vi.advanceTimersByTime(1)
>   expect(spy).toHaveBeenCalledTimes(1)
> })
>
> test('передає останні аргументи', () => {
>   vi.useFakeTimers()
>   const calls = []
>   const run = debounce((x) => calls.push(x), 50)
>   run('a')
>   run('b')
>   vi.advanceTimersByTime(50)
>   expect(calls).toEqual(['b'])
> })
>
> test('працює з реальними таймерами', async () => {
>   let count = 0
>   const run = debounce(() => count++, 20)
>   run()
>   await sleep(40)
>   expect(count).toBe(1)
> })
> ```
>
> > [!hint]- Підказка 1
> > Збережи id таймера в замиканні.
>
> > [!hint]- Підказка 2
> > Кожен новий виклик робить `clearTimeout` попереднього.
>
> > [!solution]- Еталонне рішення
> > ```js
> > function debounce(fn, ms) {
> >   let timer
> >   return function (...args) {
> >     clearTimeout(timer)
> >     timer = setTimeout(() => fn.apply(this, args), ms)
> >   }
> > }
> > ```
